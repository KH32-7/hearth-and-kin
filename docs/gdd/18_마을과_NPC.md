# 18. 마을, NPC, 스토리 진행

## 18-1. 마을 지도: 애쉬포드

- **끊김 없는 한 장의 지도** (심즈 3 오픈 월드). 로딩 없이 집 밖으로 걸어 나가 장터, 교회, 여관, 성까지 이동
- 크기 목표: 약 **200 × 150 타일** (32px 기준 6400 × 4800px). 구역(청크) 16×16 타일 단위로 로드/렌더
- 부지(lot): 주거 부지 30개 이상 (크기 소/중/대/저택), 공공 부지 12종, 빈 부지 10개 이상 (새로 짓기)
- 지형: 강(다리 2개), 숲, 언덕, 영주 밭, 목초지, 길(흙길, 돌길)

### 공공 장소 12종

| 장소 | 기능 |
| --- | --- |
| 장터 광장 | 노점(식료품, 옷감, 도구, 가축), 흥정, 소문 전파, 축제 무대, 공개 처벌대 |

| 영주의 성 | 대전(탄원, 재판), 안뜰(마상시합 연습), 신분 제한 출입 |

| 우물가 | 물 긷기, 수다 (소문 전파 높음) |
| 수도원 | 수도원 학교, 약초원, 순례, 고아원 |

| 마상시합장 (축제 때 설치) | 마상시합, 활쏘기 대회 |

- 공공 장소 안은 래빗홀(직장/학교)과 달리 **안이 보이고 직접 행동함**. 래빗홀은 성 집무실, 방앗간 내부 작업, 원거리 여정 같은 곳만

## 18-2. 마을 사람들

- 시작 인구 **약 120명** (가문 25~35개). 새 게임마다 절차적으로 생성하거나, 미리 만든 이야기 가문 12개로 시작 선택
- **미리 만든 가문 예시** (각자 이야기 훅이 있음)
  - 영주 가문 (노영주와 두 아들의 상속 경쟁)
  - 대장장이 가문 (길드장 자리를 노리는 두 형제)
  - 여관 주인 과부와 수상한 투숙객
  - 사생아 소문이 도는 상인 가문
  - 농노 대가족 (해방금을 모으는 중)
  - 교구 사제 (비밀 연인이 있음)
- 모든 NPC는 플레이어 가문과 **같은 규칙**(욕구, 특성, 관계, 생애)을 따름. 조작 가문을 바꾸면 누구든 플레이 가능

### 일과표

- NPC마다 직업/신분/특성으로 만든 **일과표**: 기상, 식사, 일, 교회(일요일), 장날(화요일, 금요일), 여관(저녁, 특성), 잠. 직업 16개 + NPC 역할 직업 10종(17-2)으로 만듦
- 일과표는 목표일 뿐, 실제 행동은 자율 AI가 욕구와 함께 판단 (배고프면 일과 중간에 먹음)
- 날씨, 축제, 역병이 일과를 바꿈 (비 오면 장터 한산, 역병이면 문 닫음)
- 교회 종: 새벽 기도, 정오, 저녁 기도 시각에 종소리 → 시계 역할 + 일과 전환 신호

## 18-3. 스토리 진행과 생애 판정기 (심즈 3)

플레이어가 조작하지 않는 가문도 **자기 인생을 삶**. 모든 인물(조작 가문 포함, LOD와 무관)의 인생 사건은 **생애 판정기** 하나가 하루 1회(자정 정산 뒤) 같은 식으로 굴림. 전체 LOD 인물은 판정 입력(관계, 건강, 돈, 동침 횟수, 성과)을 실제 행동에서 얻고, 간이/요약 인물은 일과표 기대값에서 얻음 (13-6)

- 조작 가문의 명시적 행동(청혼 수락, 약혼, 승급 카드 선택, 해방금 지불)은 판정기가 아니라 그 행동의 결과로 즉시 처리. 판정기는 같은 사건을 그날 다시 굴리지 않음
- 사고, 전투, 화재 사망은 월드에서 직접 일어남. 화면 밖이면 같은 확률식의 간이 판정 (32-2 간이 전투)

| 진행 | 판정 입력 | 기본 식 (수치는 `story.json`) |
| --- | --- | --- |
| 연애, 혼인 | 적합한 독신 쌍(나이, 신분 차, 관계, 가문 관계, 지참금) | 쌍별 하루 약혼 확률. 적령기 독신의 청년 단계 끝까지 혼인률 70~85% (29-1)가 나오게 조정. 혼인 사건은 마을 소식으로 알림, 초대받으면 참석 가능 |
| 임신과 출산 | 부부의 나이, 건강, 아이 원함 설정, 동침 횟수(전체 LOD) 또는 기대값(간이/요약) | 하루 임신 확률 = 동침 1회당 확률(29-2) × 동침 횟수 × 인구 피드백 배수 (아래). 유산/사산/조산은 15-1 |
| 취업, 승급, 해고 | 스킬, 성과 | 직업 공석 + 스킬 조건 → 확률. NPC 역할 직업(17-2) 포함 |
| 이사, 분가, 새 집 짓기 | 가정 인원(15-8 상한), 재산 | 가정 인원 상한 초과 또는 혼인 자녀 → 분가 확률 |
| 사망 | 나이, 건강, 질병, 사망 설정 행렬(20-7) | 노환 곡선(29-2) + 질병 진행 + 굶주림/추위 |
| 신분 변화 | 재산, 명성, 혼인, 16-2 신분 규칙 | 해방금 보유 농노의 해방, 파산 하락 등 |
| 원한과 동맹 | 관계 변화 | 우정 −60 이하 원한, 혼인 동맹 |
| 이주 | 마을 인구 | 인구 90 미만이면 외지인 가족 이주, 180 초과면 가족 하나가 마을을 떠남 (인구 80~200 유지) |

### 인구 피드백 제어

- 대체 수준: 하루 출생 목표 = 마을 인구 / 평균 생존 일수 (기본 약 92일, 사망 설정에 따라 다름). 120명이면 약 1.3명/일
- 간이/요약 부부의 임신 확률에 배수를 곱함: 배수 = clamp(1 + 2 × (목표 인구 − 현재 인구) / 목표 인구, 0.5, 2.0). 목표 인구 기본 120 (마을 설정)
- 혼인 쌍 확률에도 같은 배수의 제곱근을 곱함
- 조작 가문의 임신 확률에는 배수를 곱하지 않음 (플레이어 선택을 존중)
- 이주는 피드백으로 못 메우는 급감(역병, 전쟁) 때만 쓰는 안전판. 104일 동안 순유입은 시작 인구의 10% 이하 (29-1)

- 설정: 스토리 진행 끔 / 느림 / 보통 / 빠름. 특정 가문 "진행 정지" 지정 가능 (진행 정지 가문도 사망과 노화는 판정)
- **마을 소식**: 전령이 광장에서 외치는 연출 + 소식 목록 UI ("대장장이 가문 둘째가 방앗간 딸과 약혼했다")

## 18-4. 영주 정책 (마을 전체를 흔드는 규칙)

인조이 도시 편집의 중세판. 영주 가문이 정하고, **플레이어 가문이 영주가 되면 직접 정함**. 영주가 아니면 탄원으로 영향

| 정책 | 선택지 | 효과 |
| --- | --- | --- |
| 세율 | 낮음 / 보통 / 높음 | 가문 수입, 영주 금고, 민심 |
| 장터 규칙 | 자유 거래 / 길드 독점 | 물가, 장인 수입 |
| 사냥 | 금지 / 허가제 / 자유 | 밀렵 범죄, 고기 가격 |
| 치안 | 느슨 / 보통 / 엄격 | 범죄 확률, 처벌 무게, 민심 |
| 역병 대응 | 없음 / 격리 / 도시 봉쇄 | 전파 속도, 경제 타격 |
| 축제 지원 | 없음 / 보통 / 성대 | 축제 규모, 민심, 영주 금고 |

- **민심**: 마을 전체 수치 (0~100, 16-4 평판 표). 낮으면 폭동/반란 사건, 높으면 영주 가문 명예 +
- **영주 금고**: 영주 가문의 가문 재산과 분리된 계정. 수입 = 세금, 장터/방앗간 사용료의 50%, 재판 벌금. 지출 = 경비병 급여, 축제 지원, 곡물 배급(17-9), 전쟁. 금고 돈을 가문 재산으로 옮기면 "사적 유용": 민심 −10, 가문 명성 −30, 발각 시 소문. 플레이어 가문이 영주가 되면 가계부에 영주 금고 탭이 따로 생김
- 정책 효과의 방향과 최소 크기 목표는 29-4

## 18-5. 이동 수단과 외부

- 걷기 (기본), 말 타기 (이동 속도 2.5배, 22장), 수레 (짐 운반)
- 마을 밖: 원거리 교역, 순례, 전쟁 원정, 다른 도시 방문은 **여정**으로 처리하고 며칠 뒤 귀환. 여정 = **다일 래빗홀** (13-8): 여정 인물은 마을에서 빠지고 하루 모드는 계속 진행. 여정 사건 카드(여정당 2~4장, BitLife식)는 하루 최대 1장씩 알림 카드로 도착. 여정 지도(경로와 진행)는 보기 창으로 열람 (27-1). 여정 중 전투는 32-2 간이 전투로 즉시 계산하고 결과를 카드로 알림
- 이사: 마을 안 빈 집 구매/임대, 새 부지에 짓기 (23장). 마을 밖으로 이주하면 해당 인물은 "먼 곳의 친척"이 되어 편지로만 교류

## 18-6. 범죄와 재판

- 범죄: 절도, 밀렵, 폭행, 사기, 사치 금지법 위반, 이단, 불법 도박, 방화
- 발각: 목격자, 경비 순찰, 고발
- 재판: 영주 대전에서 재판 장면 (차단 장면, 27-7). 피고 변론 상호작용: 이야기(화술)/셈/신분/명예 판정, 증인 호출
- 처벌: 벌금, 칼 씌우기(광장 공개 망신), 태형, 감옥(강제 래빗홀 2~5일, `absolute`), 추방, 재산 몰수, 처형(중죄 판결). 처형은 사망 설정 행렬(20-7)의 "처형" 원인을 따름 (현실적 기본 켬, 꺼져 있으면 추방으로 대체). 고문은 다루지 않음
- 가족이 재판에 걸리면 "탄원하기", "뇌물", "증인 설득" 상호작용
