# 29. 밸런스 목표와 수치표

모든 수치는 `src/data/*.json`에 있고, 여기는 **목표와 기준값**. 헤드리스 시뮬레이터(`tools/sim-town.ts`, `tools/sim-lives.ts`)로 검증. 경제 수치는 코드 전에 `tools/econ-model`(표 계산 모델)로 먼저 맞춤 (17-10)

## 29-0. 기간 스케일 태그와 측정 기준

모든 기간/빈도 수치는 아래 태그 중 하나를 가짐. 데이터의 모든 기간 필드는 `scale` 필드가 필수 (30-2). 태그 없는 기간 수치는 check-data가 거부함

| 태그 | 뜻 | 설정에 따른 실제 값 | 쓰는 곳 |
| --- | --- | --- | --- |
| `absolute` | 게임일/게임분 고정 | 설정과 무관 | 하루 일과, 1주 7일, 부역 주 1일, 생선/고기/빵/우유 부패, 대출 이자(하루 단위), 감옥 일수, 여정 일수, 재등장 대기 |
| `season` | 달력 기준. 계절 7일일 때 값을 기준으로 계절 길이에 비례 | 기준값 × (계절 일수 / 7) | 달력 1년, 작물 성장, 계절을 넘기는 부패(채소, 치즈, 곡물, 보존 식품), 수확량, 장작 비축 기준, 축제 일수, 사순절, 세금 주기(가을 1회), 길드 회비 주기, 신분 하락 유예 |
| `lifespan` | 수명 배수에 비례 | 기간 필드: 기준값 × 수명 배수. 속도 필드(/일): 기준값 ÷ 수명 배수 | 생애 단계, 임신, 아기, 회복, 애도, 도제/직인 기간, 혼인 기간 조건, 큰 비용(한 인생 저축 기준, 17-4), 관계 자연 감소(속도), 스킬 경험치(속도), 노년 표시 나이 속도, 노환 위험 |
| `per_life` | 보통 수명 한 인생당 기대 횟수 | 하루 확률 = 기대 횟수 / (104 × 수명 배수) | 역병 유행, 전쟁, 혜성, 떠돌이 술사 방문, 괴물 조우, 가족당 사건 카드 장수 |

- **"년/연" 표기 규칙**: 규칙과 데이터에 "n년", "연 n%"를 기간으로 쓰지 않음. 달력은 "달력 1년"(= 4계절, `season`), 나이는 "표시 나이 n세"(연출용)로만 쓰고, 판정은 위 태그의 일수로 함
- **기준 측정 설정**: 보통 수명(×1), 계절 7일. 달력 1년 = 28일, 한 인생 = 3+7+13+13+24+24+노년 평균 20 = 104일 (달력 약 3.7년). 29-1의 모든 목표는 이 설정에서 측정
- **설정 조합 검사**: 수명 4종 × 계절 3종 = 12조합에서 핵심 지표가 기준 설정 대비 ±20% 이내. 핵심 지표: 신분별 한 인생 저축(17-4 목표 대비 비율), 한 세대 신분 상승률, 성인 평균 사망 나이, 인구 유지(104일 × 수명 배수 끝 인구 비율), 인생 목표 달성률, 가족당 한 인생 사건 카드 장수, 장년 끝(84일 × 수명 배수) 핵심 스킬 레벨, 파산 가문 비율

## 29-2. 기준 수치 모음

| 분류 | 값 | 스케일 |
| --- | --- | --- |
| 시간 | 게임 1분 = 실제 1초(1배). 속도 1/2/3배 = 1/3/10 게임분/초. 잠·일 가속 30배. 속도 우선순위는 27-7 | absolute |
| 생애 (보통 수명, 일) | 아기 3, 유아 7, 아동 13, 청소년 13, 청년 24, 장년 24, 노년 평균 20 | lifespan |
| 표시 나이 속도 | 단계 연수 / 단계 일수 (청년 0.5년/일, 장년 1.04년/일). 노년은 상수 0.6년/일 (평균 20일 → 약 67세) | lifespan (속도) |
| 노환 위험 | 노년 n일째 하루 사망 확률 h(n) = 0.010 × e^(0.1 × n) × 건강 보정(건강 80 이상 0.7, 30 미만 1.5) × 가계 보정(장수 가계 0.7, 병약 가계 1.3). n은 노년 경과 일수 ÷ 수명 배수, 확률도 ÷ 수명 배수 | lifespan |
| 계절 | 기본 7일. 1주 = 7일, 계절 첫날은 월요일 (19-1) | season |
| 욕구 감소 | 11장 표 | absolute |
| 온기 감소 | max(0, 15 − 체감 기온) × 0.53 × 옷 보정 (11-1) | absolute |
| 스킬 경험치 | 레벨 n → n+1 필요 100 × n^1.4. 기본 0.45 XP/분 (17-1). %보정은 경험치 속도 전용, 합산 후 상한 +100%, 하한 −50% | lifespan (속도) |
| 관계 자연 감소 | 우정 1/일, 로맨스 1.5/일 | lifespan (속도) |
| 스트레스 한계 | 100 | - |
| 무드렛 세기 → 감정 | 합 2 미만 무난, 2~2.9 기본, 3~5.9 강함, 6 이상 극단. 욕구 출처 합산 상한 2, 세기 3 부정 무드렛이 있으면 긍정 감정 억제 (11-3) | - |
| 화폐 | 1동화 = 4파딩, 1은화 = 12동화, 1금화 = 20은화 = 240동화. 내부는 파딩 정수 (17-4) | - |
| 신분별 일 순수입 / 한 인생 저축 | 17-4 표. 큰 비용은 전부 이 표에서 역산 | 저축: lifespan |
| 십일조 | 수입의 10%. 파딩 미만 잔액은 다음 수입으로 이월 | - |
| 세율 | 낮음 3% / 보통 5% / 높음 8%. 가을 세금 = 재산 평가액 × 세율 × (달력 1년 일수 / 28) | season |
| 해방금 | 8은화 (= 농노 한 인생 저축 144동화의 67%) | lifespan |
| 대출 이자 | 하루 0.5% 단리 (명예 단계에 따라 0.3~1.0%) | absolute |
| 가격 탄력성 | 식량 0.5, 그 밖 재화 0.3. 가격 배수 하한 0.5, 상한 3.0 (17-8) | - |
| 임신 | 동침 1회당 기본 18% (나이, 건강 보정) | - |
| 쌍둥이 | 3% (+10% 체질) | - |
| 질병 감염 | 접촉당 기본 5~40% (질병별) | - |
| 사건 카드 | 가족당 한 인생 150장 (보통). 하루 빈도 = 150 / (104 × 수명 배수) | per_life |
| 역병 유행 | 보통 설정 한 인생 0.4회 | per_life |
| 전쟁 소집 | 드묾 한 인생 0.3회, 보통 0.65회 | per_life |
| 혜성 | 한 인생 0.5~1회 | per_life |
| 떠돌이 술사 방문 | 마법 드묾 한 인생 1~2회, 보통 2~4회 | per_life |

## 29-3. 밸런스 조정 절차

1. 헤드리스 결과를 `BALANCE.md`에 기록 (날짜, 시드 수, 표, 신뢰구간)
2. 목표를 벗어난 항목마다 원인 가설 → 수치 조정 → 재실행. 경제 수치는 `tools/econ-model`을 먼저 고친 뒤 데이터에 반영
3. 조정 이력 누적. 수치를 바꾼 이유 한 줄
4. 사람이 플레이한 체감(개선 리스트 루프)과 헤드리스 수치가 충돌하면 체감을 우선하고 목표 자체를 수정
5. 기준 설정 목표를 맞춘 뒤 12개 설정 조합의 ±20% 검사 (29-0)

### 통계 기준

- 시드 50개 (500인생 목표는 인생 500회), 목표 범위가 95% 신뢰구간을 모두 포함해야 통과. 비율은 윌슨 구간, 평균은 t 구간
- 가속 세밀도(BRIEF 4장)로 측정하고, 마일스톤마다 시드 10개는 전체 세밀도로 돌려 같은 지표의 분포 차이가 10% 이내인지 비교
- 결과는 `BALANCE.md`에 표와 구간으로 기록
