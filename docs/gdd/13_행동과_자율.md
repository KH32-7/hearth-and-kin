# 13. 행동, 자율, 이동

## 13-1. 상호작용 정의

모든 행동은 데이터로 정의된 **상호작용**. 물건, 사람, 동물, 바닥(땅), 인물 자신에게 붙음

```
{
  id, 이름, 아이콘, 대상 종류,
  조건: { 생애단계, 신분, 특성, 감정, 스킬, 관계, 시간대, 계절, 재고, 기온, 인물 상태(13-8) },
  사용 슬롯: ["앞", "왼쪽 의자", ...],
  단계: [ {애니메이션, 시간(분), 욕구 변화/분, 스킬 경험치/분(기본 0.45, 17-1), 소리, 효과 스프라이트} ... ],
  결과: { 무드렛, 기억, 소문, 재고 변화, 물건 상태 변화, 연대기 트리거 },
  실패 판정: { 확률식, 실패 결과 },
  멀티태스킹: [동시에 할 수 있는 상호작용 분류],
  자율 광고: { 욕구별 광고값, 특성 배수, 감정 배수 },
  중단 가능 여부, 우선순위,
  부분 결과: { LOD 강등이나 중단 시 남은 시간 비율로 적용할 결과 }
}
```

- 목표 수량: 물건 상호작용 **350개 이상**, 사회 상호작용 **80개 이상**, 동물 상호작용 **40개 이상** (30장)

## 13-2. 원형 메뉴와 행동 대기열

- 대상을 클릭하면 **원형 메뉴**. 항목이 8개 넘으면 분류(친근/로맨스/짓궂음/특수/…)로 한 단계 들어감
- 조건이 안 맞는 항목은 회색으로 보이고, 마우스를 올리면 이유 표시 ("요리 스킬 3 필요", "밀가루 없음", "귀족만 가능", "지금 일터에 있음")
- 사회 상호작용은 성공 가능성을 "잘 될 것 같다 / 반반 / 위험하다"로 표시
- **대기열**: 인물당 최대 8칸. 화면 좌상단에 아이콘으로 표시, 클릭하면 취소, 끌어서 순서 변경
- 조작 중인 인물이 아닌 가족에게도 명령 가능 (초상화 선택 후 대상 클릭)
- **단축키** (27-5에서 전부 재설정 가능)
  - 가족 전환: **Space** = 같은 가정의 다음 조작 가능 인물, **Shift+Space** = 이전 인물 (심즈와 같음). 초상화 클릭으로도 전환. 유령 슬롯(20-6)도 순환에 포함, 여정/래빗홀 중 인물은 건너뜀
  - 속도: **0 또는 P** = 일시정지, **1 / 2 / 3** = 1배 / 2배 / 3배
  - 카메라 인물 추적: **F**
  - Space는 가족 전환 전용. 일시정지나 다른 기능에 쓰지 않음

## 13-3. 멀티태스킹

심즈 4처럼 한 행동 중에 다른 행동을 겹쳐 함

| 주 행동 | 겹칠 수 있는 것 |
| --- | --- |
| 식사 | 대화, 듣기, 책 읽기(문해력 있을 때) |
| 앉아서 쉬기 | 대화, 바느질, 악기 연주 듣기, 아기 안기 |
| 걷기 | 짧은 대화(나란히 걷기), 노래 흥얼거림 |
| 가내 작업(실잣기, 반죽) | 대화, 노래 |
| 누워 있기 | 대화(연인/부부), 기도 |

- 겹친 행동은 효과가 70%로 줄어듦 (둘 다). 스킬 경험치의 0.7배는 %보정 상한 계산 밖에서 곱함 (17-1)

## 13-4. 자율 행동 (유틸리티 AI)

대기열이 비었거나 자율 수준이 허락하면 인물이 스스로 할 일을 고름

### 점수식

```
점수(상호작용) =
  Σ_욕구 [ 긴급도(욕구값) × 광고값(욕구) ]
  × 특성 배수 × 덕/죄 규범 배수 × 감정 배수 × 호불호 배수 × 소원 보너스
  × 신분 적합도 × 날씨/시간대 배수
  ÷ (1 + 거리 비용 / 거리 기준)
  − 최근 반복 벌점
```

- **덕/죄 규범 배수**: 덕과 죄는 수치 효과를 갖지 않고 업보와 스트레스만 움직임 (12-2). 자율에서는 스트레스가 40 이상일 때 자기 덕/죄 규범에 맞는 해소 행동의 광고값을 높이는 방식으로만 작용
- **긴급도 곡선**: 욕구별로 다른 곡선. 예: 방광은 30 아래에서 급격히 오르고, 즐거움은 완만. `src/data/autonomy_curves.json`
- 점수 상위 5개 중에서 점수 비율로 무작위 선택 (항상 최적만 고르지 않아 사람처럼 보임)
- **자율 수준**: 끔 / 낮음(욕구 30 미만일 때만) / 보통 / 높음. 인물별, 가족 전체 설정
- **비상 우선순위**: 화재, 아기 울음(부모), 쓰러진 가족, 도둑, 유령 출현, 교회 종(미사 시간, 신앙 높은 인물)은 점수와 상관없이 끼어듦. 대상이 "가용" 또는 "무력(잠)" 상태일 때만 (13-8). 래빗홀/여정 중인 가족에게는 조기 귀가 선택 카드로 알림 (13-9)
- **일과**: 직업/학교 시간이 다가오면 "출근 준비" 자동 대기열 (옷 갈아입기 → 이동). 끌 수 있음
- **디버그 표시**: 개발 빌드에서 인물 위에 상위 5개 후보와 점수 표시

### 자율 행동의 사람다움 규칙

- 같은 물건을 연속 3번 고르면 벌점 (냉장고만 반복하는 심즈 문제 방지)
- 다른 사람이 쓰고 있는 슬롯은 기다리거나 대안을 고름. 기다리는 동안 "기다리는 중" 대기 애니메이션 (발 구르기, 팔짱)
- 가족 식사 시간(아침, 저녁)에는 같이 먹으려는 경향 가중치
- 밤에는 조명 있는 방 선호, 겁쟁이는 어두운 곳 기피

## 13-5. 이동과 길찾기

- **격자**: 타일 격자 위 A*. 대각선 이동 허용(벽 모서리 끼임 금지)
- **다층**: 계단 타일로 층을 연결. 층마다 별도 격자, 층간 연결 그래프
- **마을 규모**: 마을 전체를 구역(청크)으로 나눔. 먼 거리는 구역 단위 경로(상위 그래프) → 구역 안 세부 경로 (계층적 A*)
- **문**: 잠금 규칙 (가족만, 신분 이상만, 모두). 귀족 저택과 성은 신분 제한
- **사용 슬롯**: 물건마다 상호작용별 서는 위치와 방향. 예약제로 두 명이 같은 슬롯을 노리지 않음
- **군중 회피**: 좁은 복도에서 마주치면 한 명이 비켜 섬 (우선순위: 신분 높은 쪽, 급한 욕구 쪽)
- **실패 처리**: 경로가 없으면 속마음 "저기 못 가겠네…" + 대기열에서 제거 + 기록. 같은 목표로 3번 실패하면 해당 물건을 1시간 동안 자율 후보에서 제외
- **절대 안 되는 것**: 가구/벽 관통, 가구 위에 겹쳐 서기, 제자리 걷기 무한 반복, 문 앞에서 두 명이 서로 막고 정지

## 13-6. 시뮬레이션 세밀도 (LOD, 마을 전체를 돌리기 위해)

LOD는 **인물 단위** 상태. 가문 단위가 아님. 혼인, 출산, 사망, 취업, 신분 변화는 LOD와 상관없는 **생애 판정기**(18-3)가 하루 1회 모든 인물에게 같은 식으로 처리하고, LOD는 그 판정의 입력(관계, 건강, 돈, 성과)을 얼마나 정밀하게 공급하는지만 다름

| 등급 | 대상 | 방식 |
| --- | --- | --- |
| 전체 | 조작 가문 인물, 화면 안(카메라 영역 + 1청크 여유) 인물, 조작 가문과 같은 부지 인물, 조작 인물과 상호작용 중인 인물 | 욕구, 자율, 길찾기, 애니메이션 모두 매 틱 |
| 간이 | 화면 밖에서 집 밖 활동 중인 인물 | 일과표 기반 위치 이동(경로 없이 구역 단위), 욕구는 "일과표 기대 곡선" 값으로 보관, 사회는 소문 전파(14-6)와 관계 감소만. 게임 10분마다 갱신 |
| 요약 | 화면 밖에서 자기 부지 안에 있거나 밤(잠) 상태인 인물 | 하루 1회 정산(17-9)과 생애 판정기 입력만. 욕구는 기대 곡선 값 |

### 전환 규칙 (히스테리시스)

- **승급**: 전체 조건 중 하나라도 해당하면 즉시 전체. 요약 → 간이는 일과표상 집 밖 활동이 시작될 때
- **강등**: 전체 조건이 모두 풀린 뒤 게임 30분 지속되면 간이. 간이 → 요약은 자기 부지 안 또는 잠 상태가 게임 60분 지속될 때
- **강등 금지**: 교전, 사건 카드 대상, 장면(27-7) 참가자, 출산 진통 중인 인물은 끝날 때까지 강등하지 않음
- **승급 시 상태**: 욕구는 기대 곡선 값(식사 직후 높고 시간에 따라 감소, 정산에서 굶은 날이면 낮음)으로 시작. 현재 일과에 맞는 행동부터 시작하고 위치는 일과표 장소의 빈 슬롯 (1타일 이하 불연속, BRIEF M6)
- **강등 시 진행 중 상호작용**: 남은 시간 비율만큼 부분 결과를 적용하고 종료
- **조작 가문 교체**: 조작을 해제한 가문은 대기열을 비우고 현재 욕구 값을 유지한 채 위 규칙으로 등급이 정해짐. 새로 조작하는 가문은 전원 전체로 승급
- 회귀 테스트: 같은 시드에서 "전 인물 전체 강제"와 "전 인물 요약 강제"로 104일을 돌려 혼인률, 출생, 사망 원인 분포, 가문 순수입 분포 차이가 10% 이내

## 13-7. 집단 활동

- **가족 식사**: 식탁 슬롯 수만큼 모여 앉음. 한 명이 "식사 준비"하면 나머지에게 "식사하러 오기" 제안
- **잔치/연회**: 초대장(편지) → 손님 도착 → 음식 차리기, 음악, 춤, 건배 → 잔치 점수 → 명성과 관계. 16장 명예와 연결
- **미사**: 교회 좌석에 신분 순서로 앉음 (귀족 앞줄). 설교 중 졸기, 속삭이기 같은 상호작용
- **축제**: 광장 행사 (19장)
- **작업 돕기**: 가내 생산을 둘이 하면 속도 +60%, 관계 +

## 13-8. 인물 상태 기계

모든 인물은 LOD와 별개로 아래 상태 중 정확히 하나. 사건 카드, 상호작용, 비상 우선순위, 장면, 저장은 모두 이 상태를 읽음

| 상태 | 뜻 | 예 | 받을 수 있는 것 |
| --- | --- | --- | --- |
| 가용 | 마을 안에서 행동 가능 | 집안일, 산책, 현장형 직업 | 모든 상호작용, 카드, 장면 참가 |
| 래빗홀 | 건물 안에 들어가 보이지 않음 (하루 이내 또는 다일) | 래빗홀 직업, 교구 학교, 부역, 감옥, 수도원 기숙, 시동 파견 | 일터 카드, 조기 귀가 카드만 (13-9) |
| 여정 | 마을 밖, 여러 날 (다일 래빗홀) | 원거리 교역, 순례, 원정, 다른 도시 방문 | 여정 카드(하루 1장, 알림 카드로 도착), 편지 |
| 장면 중 | 장면 스택(27-7)의 장면 참가자 | 재판, 출산, 결투, 마상시합, 유언 공개, 교전 | 그 장면의 선택만 |
| 무력 | 스스로 행동 불가 | 잠, 기절, 진통, 쇠약 상태로 누움 | 잠은 깨우기 가능. 기절/진통은 돌봄 상호작용만 |
| 유령 | 법적으로 사망한 유령 (20-6) | 유령 | 유령 상호작용, 유령 대상 카드 |

- 전이: 가용 ↔ 래빗홀/여정/장면 중/무력. 무력(진통) → 장면 중(출산). 사망 → (조건 충족 시) 유령. 한 인물이 두 상태를 동시에 가지지 않음
- 여정은 **다일 래빗홀**로 통일. 여정 인물은 마을에서 빠지고 하루 모드는 계속 진행 (별도 화면이 하루 모드를 멈추지 않음). 여정 지도는 보기 창 (27-1)
- 가정 전원이 래빗홀/여정/무력(잠)이면 자동 가속 (27-7)

## 13-9. 래빗홀과 여정 중 욕구, 조기 귀가

- 래빗홀 중 욕구는 직업별 소모율 표(`careers.json`)로 감소. 기본값

| 욕구 | 래빗홀 중 배수 | 비고 |
| --- | --- | --- |
| 배고픔 | 0.5 | 일터 식사 1회 포함 (6시간 넘는 래빗홀) |
| 에너지 | 0.8~1.3 | 직업별 (방앗간, 부역 1.3) |
| 위생 | 0.5~2.0 | 직업별 (대장간, 밭일 2.0) |
| 방광 | 0 | 일터에서 해결 |
| 즐거움 | 0.5 | 태도 "농땡이"면 0 |
| 교류 | 0.3 | 동료와 교류 |
| 온기 | 0 | 실내 |
| 안락 | 0.5 | |

- 여정 중 욕구는 하루 1회 정산 (준비물, 여관, 여정 사건 결과로 결정). 굶주림/추위 결과는 사건 카드로 알림
- **조기 귀가 카드**: 집에 화재, 배우자 진통, 가족 사망 또는 위독(쓰러짐, 중환)이 생기면 래빗홀 인물에게 "지금 돌아간다 / 일을 마치고 간다" 선택 카드. 돌아가면 직업 성과 하락, 부역이면 영주 호의 하락. 여정 인물은 귀환까지 걸리는 날짜가 표시되고 선택하면 여정 조기 종료
