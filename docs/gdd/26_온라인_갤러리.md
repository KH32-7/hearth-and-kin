# 26. 온라인 갤러리

심즈 4 갤러리의 중세판. 집, 인물, 가문, 연대기를 올리고 내려받음

## 26-1. 공유 대상

| 대상 | 내용 | 내려받으면 |
| --- | --- | --- |
| 집 | 부지 크기, 건축, 가구 배치 | 빈 부지나 내 부지에 배치 |
| 방 | 방 하나 | 내 집에 붙여넣기 |
| 인물 | 외형, 특성, 덕/죄, 목표 | 캐릭터 만들기에서 불러오기, 마을에 이주민으로 추가 |
| 가문 | 구성원 전원 + 문장 + 가훈 (+ 집 선택) | 새 게임 시작 가문 또는 마을 이주 가문 |
| 연대기 | 삽화와 글 (읽기 전용) | 책으로 읽기만. 게임 데이터는 없음 |
| 문장 | 문장 디자인 | 문장 편집기에 불러오기 |

- 올릴 때 제목, 설명, 태그(신분, 시대 분위기, 크기), 대표 이미지(자동 캡처)
- 둘러보기: 인기순, 최신순, 태그, 검색, 제작자 팔로우
- 좋아요, 즐겨찾기, 댓글, 신고
- 오프라인이면 갤러리 버튼 비활성 + 내 컴퓨터의 로컬 라이브러리만 사용

## 26-2. 백엔드

- 구성: API 서버 + DB + 파일 저장소 (예: Cloudflare Workers + D1 + R2, 또는 Supabase. 구현 시 비용과 운영 편의로 결정하고 DECISIONS.md에 기록)
- 로그인: 데스크톱은 스팀 계정 연동, 브라우저는 OAuth(구글/디스코드). 로그인 없이 둘러보기 가능, 올리기/좋아요는 로그인
- 업로드 형식: 게임 데이터 JSON(버전 포함) + 대표 이미지 PNG. 서버에서 스키마 검증, 크기 제한(집 2MB, 연대기 20MB)
- **안전**
  - 업로드 데이터는 게임 스키마로만 해석 (코드 실행 불가)
  - 이름, 가훈, 설명의 금칙어 필터 + 신고 누적 시 자동 숨김 + 관리자 페이지
  - 사용자 입력 텍스트는 이스케이프해서 표시
  - 요청 속도 제한
- 게임 버전이 올라가도 옛 업로드를 읽을 수 있게 마이그레이션 함수

## 26-3. 모드 지원 (갤러리와 함께)

- 사용자 콘텐츠 폴더: 물건 스프라이트 + JSON 정의, 사건 카드 JSON, 이름 풀, 속마음 문장 풀
- 스키마 검증 통과한 것만 로드, 실패 시 오류 목록 표시
- 갤러리에서 모드가 필요한 업로드는 "필요한 모드" 표시
