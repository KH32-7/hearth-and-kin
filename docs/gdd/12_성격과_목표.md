# 12. 성격과 목표

인물의 내면은 네 층으로 이루어짐: **기질/특성 → 덕과 죄 → 좋아하는 것/싫어하는 것 → 인생 목표**. 앞의 셋이 행동을 만들고, 마지막이 방향을 정함

## 12-1. 특성 30개

성인은 3칸. 생애 단계별 칸 수는 10장. 모든 특성은 `src/data/traits.json`에 효과를 데이터로 정의 (자율 가중치 배수, 욕구 감소 배수, 스킬 경험치 %보정, 무드렛 트리거, 전용 상호작용, 사건 조건, 대화 주제, **대표 지표**와 **최소 배수**)

- **대표 지표**: 특성마다 헤드리스로 잴 수 있는 행동 지표 하나 (예: 깔끔함 = 청소 분/일, 사교적 = 대화 분/일, 겁쟁이 = 밤 외출 분/일, 반대 방향이면 배수 역수). **최소 배수**: 특성 없는 기준 인물 대비 차이 (기본 1.5배). M2 통과 조건 (29-1)
- 스킬 %보정은 경험치 속도 전용이고 합산 후 상한 +100% (17-1)
- **충돌**은 대칭 쌍 목록 하나로 데이터화 (`traits.json`의 `conflicts`). 쌍의 한쪽을 가지면 다른 쪽을 얻을 수 없음
  - 특성끼리: 쾌활함-우울한 기질, 다혈질-차분함, 겁쟁이-용감함, 낭만적-냉소적, 깔끔함-게으름, 게으름-부지런함, 사교적-내성적, 다정함-심술궂음, 야심가-겸손함, 정의로움-교활함
  - 층을 넘는 쌍: 바람기(특성)-정절(덕)

## 12-2. 덕과 죄

중세 기독교의 7덕과 7죄를 가져온 성격의 두 번째 축. 성인이 되면 **덕 1개, 죄 1개**를 가짐 (어느 쪽이든 "없음" 선택 가능). 한 덕과 그 대응 죄는 동시에 가질 수 없음

- **역할 분리**: 덕과 죄는 **행동 규범**이라 **업보와 스트레스만** 움직임. 스킬, 관계 감소, 감정 지속 같은 수치 효과는 특성(12-1)에만 둠. 그래서 비슷해 보이는 특성과 덕/죄(겸손함/겸손, 차분함/인내, 부지런함/근면, 게으름/나태)가 함께 있어도 수치가 중첩되지 않음
- 규범에 맞는 행동 → 업보 +, 스트레스 해소 / 규범을 어기는 행동 → 업보 −(죄를 따르는 행동) 또는 스트레스 +(덕을 어기는 행동)
- 자율에서는 스트레스 40 이상일 때 규범 해소 행동의 광고값을 높이는 방식으로만 작용 (13-4)

| 덕 (id) | 지키는 행동 → 업보 + / 어기면 스트레스 + | 대응 죄 (id) | 따르는 행동 → 스트레스 해소, 업보 − |
| --- | --- | --- | --- |
| 정절 `chastity` | 유혹 거절, 배우자에게만 로맨스 / 불륜, 동침 제안 | 색욕 `lust` | 작업 걸기, 불륜, 동침 |
| 절제 `temperance` | 소식, 금식 지키기 / 폭음, 과식 | 탐식 `gluttony` | 잔치, 과식, 폭음 |
| 관용 `charity` | 기부, 구휼 돕기 / 빚 독촉, 구걸 외면 | 탐욕 `greed` | 돈 세기, 고리 대출, 흥정 이득 |
| 근면 `diligence` | 일, 가내 생산 / 하루 종일 쉬기 | 나태 `sloth` | 뒹굴기, 농땡이 |
| 인내 `patience` | 모욕 참기, 화해 / 말다툼, 주먹질 | 분노 `wrath` (표시명 "분노(죄)") | 말다툼, 주먹질, 결투 신청 |
| 친절 `kindness` | 위로, 도움 상호작용 / 험담, 놀리기 | 질투 `envy` | 험담, 남의 성공 방해 |
| 겸손 `humility` | 신분 낮은 사람과 교류, 절하기 / 뽐내기 | 교만 `pride` | 뽐내기, 명령하기, 사치 |

- 죄 "분노"는 감정 "분노"(11-3), 특성 "다혈질"과 다른 것. 데이터 id는 `wrath`, 화면 표시명은 "분노(죄)"
- 덕과 죄는 **업보(카르마)**에 직접 영향 (20장). 교회 평판(21장)과 고해의 효과에 연결됨
- 덕과 죄는 사건으로 바뀔 수 있음 (회개 → 죄 제거, 타락 → 덕 상실)

## 12-3. 좋아하는 것 / 싫어하는 것

심즈 4의 호불호를 가져옴. 인물마다 좋아하는 것 3~5개, 싫어하는 것 2~3개

- 분류: 음식(빵, 스튜, 파이, 생선, 과일, 치즈, 꿀과자, 고기), 음악(류트, 백파이프, 성가, 민요), 활동(사냥, 낚시, 춤, 체스, 이야기, 바느질), 색(염료 색 10종), 계절, 동물
- 효과: 좋아하는 것을 하면 행복 1 무드렛, 즐거움 회복 +50%. 싫어하는 것은 분노 1
- 얻는 방법: 캐릭터 만들기에서 지정 / 활동을 여러 번 하면 확률로 생김 / 부모에게서 영향
- 대화 주제로 쓰임: 같은 것을 좋아하는 사람과 "취향 이야기" 성공률 +

## 12-4. 인생 목표 14개 (아래 12개 + 귀족 전용 2개는 16장. 아동 목표 4개는 따로)

심즈 4 열망처럼 **4단계 이정표**. 청소년부터 선택 가능, 언제든 바꿀 수 있음(진행도 일부 유지). 완료하면 전용 보상 특성과 연대기 특별 삽화

- **단계별 도달률 목표** (기본 설정, 그 목표를 고른 전략 봇, 29-4): 1단계 90%, 2단계 70%, 3단계 45%, 4단계 20~30%. 조건 수치는 이 목표에서 역산해 조정 (29-3)
- 기간 조건은 `lifespan` 일수, 금액은 17-4 한 인생 저축 목표 S 기준

| --- | --- | --- | --- | --- | --- |

## 12-5. 소원과 걱정, 행복 포인트

심즈 2의 소원/두려움 + 심즈 3의 약속한 소원

- 소원 칸 3개 (항상 보임) + 걱정 1~2개
- 소원은 게임 몇 시간마다 교체되고, 하나를 **고정**할 수 있음
- 소원 생성 재료: 특성, 덕과 죄, 호불호, 인생 목표 단계, 기억, 관계, 계절/축제, 현재 감정
- 소원 풀 **200개 이상**, 걱정 풀 **60개 이상**
  - 소원 예: "빵 굽기", "대장장이의 딸과 대화하기", "성탄 미사 참석", "새 옷 사기", "아들에게 류트 가르치기"
  - 걱정 예: "역병에 걸리기", "빚 독촉 받기", "배우자의 외도", "어둠 속 혼자 있기"(겁쟁이)
- 걱정이 현실이 되면 긴장 2 무드렛. 걱정을 해결하면(예: 빚을 갚음) 행복 포인트 소량
- **행복 포인트**: 소원 달성, 인생 목표 단계, 행복/환희 상태 지속으로 획득
- **보상 특성 20개** (포인트로 구매): 튼튼한 방광, 쪽잠 달인, 철의 위장, 설득의 달인, 추위에 강함, 빠른 학습자, 병에 강함, 부모의 달인, 이웃의 친구, 장수 등. 몇 개는 가보처럼 **자녀에게 물려줄 수 있음** (가문 보상, 16장)
