# 33. 마법과 괴물 (아주 약하게)

## 33-0. 원칙

- **낮은 판타지**. 마법은 드물고, 작고, 대가가 있고, 교회가 두려워함. 화염구, 소환술, 드래곤, 마왕 같은 하이판타지 요소는 없음
- 마을 사람 대부분은 평생 마법을 직접 볼 일이 없음. 괴물도 대부분 **소문과 전설**이고, 가끔 진짜가 나타남
- 마법과 괴물은 일상을 뒤흔드는 **양념**이지 게임의 중심이 아님. 중심은 여전히 가족과 일상
- 설정: 마법/괴물 빈도 **끔 / 드묾(기본) / 보통**. 조우 빈도 목표는 29-1 (위험한 괴물 직접 조우 드묾 한 인생 0.2~0.5회, 무해한 존재의 흔적 1~3회, 소문은 실제 조우의 3~5배)
- **허용 목록 밖 존재 금지**: 등장하는 괴물과 신비한 존재는 33-3 표의 9종뿐. 해골, 언데드, 코볼트, 레이스, 슬라임, 오크, 좀비, 흡혈귀 등은 쓰지 않음. 늑대, 곰, 멧돼지, 쥐, 박쥐는 괴물이 아니라 야생 동물 (22-4)
- **주문 효과 범위 규칙**: 주문 하나의 대상은 인물 1명 또는 물건/가축 우리/밭 구획 1개. 날씨는 확률 보정만 가능(직접 날씨를 정하지 않음). 마을 전체에 미치는 효과 금지. 사건 카드 내용, 미래 날짜 같은 메타 정보 공개 금지. 수명을 직접 늘리지 않음

## 33-2. 비술 스킬과 주문

- **비술** 스킬 (1~10): 금서 읽기(문해 필요), 스승에게 배우기, 마녀의 피
- **주문 20개** (예시). 모두 **재료 + 에너지 + 시간**이 들고, **실패/역효과** 확률이 있음

| 주문 | 레벨 | 효과 | 재료 |
| --- | --- | --- | --- |
| 등불 | 1 | 손끝에 작은 빛 (밤 이동, 겁쟁이 진정) | 없음 |
| 불씨 살리기 | 1 | 꺼진 화로에 불 | 없음 |
| 상처 봉합 | 2 | 부상 회복 +50% | 쐐기풀 |
| 열 내리기 | 3 | 열병 증상 완화 | 카모마일 |
| 동물 교감 | 3 | 동물 관계 +, 겁먹은 말 진정 | 없음 |
| 행운 부적 | 4 | 하루 동안 판정 소폭 + | 양초, 실 |
| 사랑의 묘약 (물약) | 4 | 로맨스 성공률 + (효과 끝나면 반동) | 장미, 꿀 |
| 망각의 차 | 5 | 기억 하나를 흐리게 (트라우마 치료, 악용 가능) | 양귀비 |
| 점치기 | 5 | 모호한 징조 문장 하나 (예: "물가에서 누군가 운다"). 카드 내용, 시점, 대상은 알려 주지 않음 | 촛불, 물그릇 |
| 우유 상하게 하기 (저주) | 5 | 상대 저장고의 우유/치즈 한 묶음 부패 | 없음 |
| 악몽 (저주) | 6 | 상대 수면 회복 -, 긴장 | 머리카락 |
| 집요정 부르기 | 6 | 브라우니 초대 (33-4) | 우유, 빵 |
| 비 부르기 | 7 | 밭 구획 1개의 가뭄 피해 방지 (물 대기 1회와 같은 효과) | 월광초 |
| 가축 치유 | 7 | 가축 병 치료 | 약초 |
| 유령과 대화 | 8 | 유령의 한 알아내기 (20장) | 양초 |
| 환영 | 8 | 자기 자신의 짧은 변장 (몇 시간 다른 외형). 신분, 이름, 관계 판정은 그대로 | 월광초 |
| 퇴마 | 9 | 유령 승천, 늑대인간 저주 해제 확률 | 성수 + 약초 |
| 저주 풀기 | 9 | 저주 해제 | 월광초 |
| 수명 약 | 10 | 노년 인물 1명의 건강 +30 회복과 긍정 노년 특성 1개 부여(지혜로움/온화해짐/이야기꾼 중). 역효과 확률 높음 (역효과 시 망령) | 희귀 재료 |
| 먹구름 부르기 | 10 | 다음날 비 확률 +30%p (가뭄 중이면 가뭄 해소 확률 +). 역효과 시 자기 밭에 우박. 의혹 최대 | 월광초 다량 |

- **역효과 예시**: 사랑의 묘약을 엉뚱한 사람이 마심, 등불이 커튼에 옮겨 붙음, 먹구름 부르기가 우박으로
- **전투에서 쓸 수 있는 주문 (허용 목록)**: 등불(상대 눈부시게: 상대의 다음 라운드 판정 −), 동물 교감(늑대/큰늑대/말 진정 시도: 성공하면 그 동물과의 교전 종료), 행운 부적(교전 전에 사용). 이 목록 밖 주문은 교전 중 쓸 수 없고, 공격 주문은 만들지 않음 (32-2)
- **의혹**: 주문을 쓰다 목격되면 소문(14장) "마녀/술사" → 교회 평판 하락 → 조사 → 재판 (21장). 교회의 퇴마와 비술 퇴마가 대비됨
- **연금술**: 연금 도구(물건)로 물약 12종 제조 (치유, 원기, 해독, 수면, 사랑, 용기, 투명한 목소리 등). 교회가 허용하는 쪽 기술로 의혹이 낮음

## 33-3. 괴물과 신비한 존재

**허용 목록** (이 표 밖 존재는 등장하지 않음, `creatures.json` 9종). 모두 **드물게**. 대부분 숲, 밤, 안개, 겨울, 특정 축일에 나타남. 위험한 존재(큰늑대, 거대 거미, 트롤)와 무해한 존재(고블린, 픽시, 집요정)의 조우 빈도는 29-1에서 따로 관리

| 존재 | 성격 | 게임 역할 |
| --- | --- | --- |
| 큰늑대 | 위험, 드묾 (겨울) | 가축 습격, 밤길 조우 → 전투(32장) 또는 도망 |
| 거대 거미 | 위험, 아주 드묾 (깊은 숲) | 약초 채집 중 조우, 거미줄 재료 |
| 고블린 | 짓궂음 | 밤에 곡식/닭 훔침, 덫이나 개로 쫓아냄. 가끔 잡혀서 흥정 사건 |
| 숲 요정 (픽시) | 장난, 호기심 | 물건 숨기기, 길 잃게 하기. 선물(꿀, 반짝이)을 두면 행운. 아이들만 볼 수 있다는 설정 (아이 인물의 속마음과 대화 주제) |
| 집요정 (브라우니) | 수줍음, 도움 | 우유 한 그릇을 두면 밤에 청소/수선을 해 줌. 옷을 선물하거나 모욕하면 떠나거나 장난꾸러기로 변함. **심즈식 집 생활에 딱 맞는 존재** |
| 트롤 | 무섭지만 협상 가능 | 다리 밑 전설. 아주 드물게 실제로 통행료 요구 사건 (수수께끼, 흥정, 도망, 싸움) |
| 늑대인간 저주 | 비극 | 큰늑대에게 물리면 아주 낮은 확률로 저주. 보름달 밤에 변신(조작 불가, 자율로 숲을 헤맴), 가족만 아는 비밀, 퇴마/저주 풀기로 치료. 가문 드라마 |
| 유령 | 20장 | |
| 성인의 기적 | 경건 | 극히 드문 치유/환시 사건 (21장) |

- 괴물 출현은 마을 소문으로 먼저 퍼짐 ("방앗간 뒤에서 큰 발자국을 봤대"). 진짜일 수도 헛소문일 수도 있음
- 괴물 퇴치는 명성과 연대기 대형 삽화. 퇴치 보상(영주 포상금)
- 괴물이 마을을 대규모로 습격하는 일은 없음

## 33-4. 집요정 상세 (대표 존재)

- 조건: 집이 깨끗하고 화로가 따뜻하며, 밤에 우유를 두면 확률로 입주
- 보이지 않음. 아침에 "누군가 설거지를 해 놓았다" 속마음 + 반짝이는 흔적
- 호감도: 우유/빵 공양 +, 시끄러움/지저분함 -, 옷 선물은 떠남(전설대로)
- 호감 높으면: 밤마다 청소, 고장 수리, 아기 돌봄(울음 달래기)
- 호감 낮으면: 물건 숨기기, 우유 엎기, 밤에 소리
- 마녀의 피나 아이 인물은 가끔 모습을 봄 (대화 상호작용)
