# 22. 동물

동물은 두 종류. **반려동물**(개, 고양이, 말)은 가족 구성원처럼 성격과 관계를 가짐. **가축**(닭, 염소, 소, 돼지, 양)은 살림의 일부. 어느 쪽도 농장 경영 루프가 아니라 **가족의 삶에 붙은 존재**로 다룸

## 22-1. 반려동물: 개, 고양이

| 항목 | 내용 |
| --- | --- |
| 얻기 | 장터에서 구입, 떠돌이 입양, 새끼 낳기, 선물 |
| 외형 | 품종 6~8종, 털색 팔레트 교체, 이름 |
| 생애 | 새끼 → 성체 → 노령 (사람보다 짧은 수명) |
| 욕구 | 배고픔, 에너지, 즐거움, 교류, 위생(개) |
| 성격 특성 2개 (12종) | 충직함, 게으름, 활발함, 겁 많음, 사나움, 영리함, 도둑고양이, 사냥꾼, 수다쟁이(짖음), 애교쟁이, 독립적, 호기심 |
| 관계 | 가족 인물 각각과 우정 (주인 인식) |
| 상호작용 | 쓰다듬기, 먹이 주기, 놀아주기(막대 던지기, 실뭉치), 훈련, 꾸짖기, 산책(개), 목욕 |
| 훈련 (개) | 앉아, 따라와, 지켜(도둑 경보), 사냥 보조. 훈련 수준 5단계 |
| 자율 행동 | 쥐 잡기(고양이 → 역병 전파 확률 감소!), 짖기, 주인 따라가기, 화롯가에서 자기, 음식 훔치기, 이웃 동물과 싸움 |

- 고양이의 쥐 잡기가 역병 모델(20장)에 실제로 영향
- 개는 밤에 도둑/유령에 반응
- 반려동물이 죽으면 가족 애도 무드렛, 마당 무덤

## 22-2. 말

- 이동 수단 (마을 이동 속도 2.5배, 여정 기간 단축)
- 마구간 필요 (건축 물건)
- 욕구: 배고픔, 에너지, 위생, 운동. 돌보지 않으면 병들고 주인과 관계 하락
- 상호작용: 타기, 솔질, 먹이, 편자 갈기(대장장이), 훈련(속도/지구력/마상시합)
- 마상시합 성과 = 기사 무예 + 승마 + 말 훈련도
- 신분 상징: 좋은 말은 명성 +

## 22-3. 가축

| 가축 | 산출 | 돌봄 |
| --- | --- | --- |
| 닭 | 달걀 (매일) | 모이, 닭장 청소, 여우 사건 |
| 염소 | 젖 → 치즈 | 먹이, 젖 짜기 |
| 소 | 젖, 쟁기질(영주 밭 성과 +) | 먹이, 젖 짜기, 외양간 |
| 돼지 | 도축 (가을) → 고기, 소시지 | 먹이(음식 찌꺼기 처리 역할) |
| 양 | 양털 (봄) → 실잣기 | 털 깎기, 목초지 |

- 가축은 **개체 단위**(이름 붙이기 가능)이지만 성격 특성은 1개만
- 가축 우리/닭장은 건축 물건. 부지 크기가 가축 수 상한을 정함
- **돌봄은 우리 단위**: 우리/닭장 물건에 거는 상호작용 1회(먹이 주기, 청소, 젖 짜기, 달걀 거두기)가 그 안의 개체 전체를 처리함. 개체마다 반복하는 돌봄 루프 없음. 개체 상호작용(쓰다듬기, 이름 붙이기)은 선택
- **일 맡기기**: 31-2 밭일처럼 "오늘의 가축 돌보기"를 가족, 하인, 아이에게 배정하면 자율로 처리
- 가축 돌보기는 "동물 돌보기" 스킬. 아이에게 맡기기 좋은 집안일
- 가을 도축은 선택 사건 (아이가 이름 붙인 돼지면 슬픔 무드렛)

## 22-4. 야생 동물 (마을 주변)

- 사슴, 토끼, 여우, 까마귀, 들쥐, 부엉이: 배경 생동감 + 사냥(허가) + 미신 징조
- 늑대: 겨울 숲에서 드물게. 가축 피해 사건, 밤 외출 위험. 조우하면 전투(32장) 또는 도망/쫓아내기. 큰늑대는 33장
