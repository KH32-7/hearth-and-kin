# 28. 아트와 오디오

에셋 상세와 라이선스는 `04_에셋_목록.md`

## 28-1. 아트 방향

- **세계 = Epic RPG World (사용자 보유) + LPC 보충, 사람 = LPC** (`04_에셋_목록.md`)
  - 둘 다 32px 격자, 화면 **2배**. 캐릭터 키는 타일 약 1.5칸
  - LPC 쪽 색을 Epic RPG World 톤에 맞추는 색 보정 (M0에서 확인)
  - Mana Seed는 보류 (`04M_ManaSeed_보류.md`)
- 탑다운 3/4 시점, 정수 배율, 최근접 필터. 흐릿한 픽셀은 결함
- 분위기 키워드: 따뜻한 화롯불, 흙과 나무, 양피지, 채색 필사본. 어둡고 음울한 다크 판타지 아님
- **섞지 않는 규칙**
  - Epic RPG World NPC(좌우 2방향)를 사람으로 쓰지 않음. 사람은 LPC만
  - LPC 생성기 캐릭터와 LPC Revised 캐릭터를 섞지 않음
  - 다른 픽셀 크기(16px 등) 에셋을 섞지 않음
- **팔레트 검사**: 세계 물건(지형, 건물, 가구, 소품) 직접 그림은 Epic RPG World 팔레트, 사람/동물/괴물 직접 그림은 LPC 생성기 팔레트 기준으로 스크립트 검사 (`npm run check:palette`, `tools/check-palette.ts`). 28-5 AI 가공도 같은 기준

## 28-2. 에셋에 없는 것과 제작 계획

- 목록과 방법: `04_에셋_목록.md` 4절 (사람 쪽 / 세계 쪽)
- 공통으로 만드는 것: 욕구 아이콘 8개, 감정 아이콘 11개, 영구 부상 레이어와 보조구(흉터, 절름발이 걸음, 안대, 목발/의족, 갈고리 의수. 20-4), 연대기 삽화 처리(캡처 → 필사본 팔레트 + 테두리 + 금박 머리글자), 유령(반투명 + 푸른 색조 셰이더), 잠 연출(침대 위 이불 + 베개 위 머리만 표시)
- 제작 방식: 코딩 에이전트가 **픽셀 편집 스크립트**로 만들고 확대 스크린샷으로 검수. 품질이 안 나오는 것(유아 몸 등)은 사람이 직접 찍거나 외주 (DECISIONS.md)
- 생성형 AI 사용 가능 (28-5)

## 28-3. 조명과 효과

- 시간대 색 보정: 새벽(푸른 회색) → 아침(따뜻한 노랑) → 낮(중립) → 해질녘(주황) → 밤(짙은 파랑)
- 광원: 화로, 촛불, 횃불, 등잔. 가산 광원 스프라이트 + 흔들림. 밤에 불 켜진 창문이 거리에서 보임
- 날씨 효과: 비, 눈, 안개, 번개, 바람에 날리는 잎 (화면 오버레이 + 바닥 물웅덩이/눈 쌓임 타일)
- 연기: 굴뚝 연기(집에 불 피우면), 대장간 연기
- 효과: 소원 달성 반짝, 스킬 상승, 무드렛 획득 아이콘 떠오름, 화재 불길, 역병 표시(문에 붉은 십자), 타격 시 피 튐(수위 설정에서 켬/끔, 27-5)

## 28-5. 생성형 AI 활용 (2026-09-25 사용자 허용)

힉스필드 mcp 활용하면 됨. 

### 쓰는 곳

| 용도 | 방식 | 품질 기준 |
| --- | --- | --- |
| 연대기 삽화, 사건 카드 삽화 (300장+) | 채색 필사본풍 일러스트 생성. 인물 이름/신분/장면을 프롬프트로 | 같은 스타일 프롬프트 고정, 한 번에 여러 장 뽑아 톤 통일 |
| 타이틀, 로딩, 메뉴 배경, 표지 | 일러스트 생성 | 게임 로고/문장과 색감 맞춤 |
| 인물 초상화 (정보 창, 가계도) | 생성 후 픽셀화 또는 필사본풍 초상 | 외형 레이어(머리색, 옷)와 일치하는지 확인 |
| UI 장식 (양피지, 테두리, 금박 머리글자) | 생성 후 9분할 가공 | 정수 배율에서 선명 |
| 아이콘 (욕구, 감정, 스킬, 직업) | 생성 → 16/32px로 줄이고 팔레트 양자화 | 작은 크기에서 알아볼 수 있어야 함 |
| **게임 안 스프라이트** (에셋에 없는 가구, 괴물, 아기/유아 등) | 생성 초안 → 32px 격자(사람/동물/괴물은 LPC 64×64 프레임)로 줄임 → 팔레트 양자화(세계 물건과 가구는 Epic RPG World 팔레트, 사람/동물/괴물은 LPC 팔레트) → 외곽선/음영 손질 → 확대 스크린샷 검수 | 옆에 놓이는 에셋(세계 물건은 Epic RPG World, 인물은 LPC)과 나란히 놓았을 때 튀지 않아야 함. 튀면 폐기하고 픽셀 편집 스크립트 방식으로 |
| 콘셉트 아트 | 방, 마을, 축제 장면 참고 이미지 | 작업 기준으로만 사용 |

### 규칙

- AI로 만든(또는 AI 초안을 손질한) 파일은 전부 `assets/AI_GENERATED.md`에 기록 (파일, 도구, 프롬프트 요약, 날짜, 게임 안 사용 위치)
- 생성 결과는 원본 해상도로 게임에 넣지 않음. 반드시 규격 크기로 가공하고 정수 배율로 표시
- 캐릭터 애니메이션처럼 프레임 간 일관성이 필요한 것은 AI 결과를 그대로 쓰지 말고, 한 프레임을 기준으로 삼아 나머지는 스크립트로 만듦
- 스팀에 출시하면 스팀의 AI 생성 콘텐츠 공개 항목에 기재
- Epic RPG World와 LPC는 AI와 함께 쓰는 것을 막지 않음. 보류한 Mana Seed를 다시 쓰게 되면 `assets/AI_GENERATED.md`의 모든 파일을 먼저 AI 없이 만든 것으로 바꿔야 함
