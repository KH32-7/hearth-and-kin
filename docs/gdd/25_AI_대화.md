# 25. AI 대화 (Claude API)

인조이 스마트 조이의 발상을 가져오되, 게임이 AI 없이도 완전히 돌아가게 설계. AI는 **문장만** 만들고, 게임 규칙(성공 판정, 수치 변화)은 항상 게임 로직이 정함

## 25-1. AI가 하는 일

| 기능 | 입력 | 출력 | 없을 때 대체 |
| --- | --- | --- | --- |
| 대화 말풍선 · 대사창 | 두 인물의 특성, 신분, 감정, 관계, 상호작용 종류, 판정 결과, 최근 기억 2개 | 지문 한 줄 + 각자 한 줄씩 대사 (최대 2왕복). 대사창(27-13)과 머리 위 대사 풍선에 씀 | 규칙 기반 지문 · 대사 풀 (27-13), 없으면 웅얼거림 + 주제 아이콘 |
| 속마음 | 인물 상태 요약 + 트리거 | 한 줄 속마음 | 규칙 기반 문장 풀 (11장) |
| 편지 본문 | 보내는 사람, 받는 사람, 목적, 관계 | 3~6문장 편지 | 문장 틀 조합 |
| 연대기 문장 | 사건 데이터, 관련 인물, 연도 | 1~2문장 연대기체 | 문장 틀 |
| 묘비명 후보 | 칭호, 기억, 목표 | 3개 | 틀 조합 |
| 대화 입력 (선택 기능) | 플레이어가 인물에게 직접 말을 거는 텍스트 | 인물의 대답 + **의도 태그** | 기능 숨김 |

- **대화 입력 기능**: 플레이어가 "대장장이에게 딸을 달라고 부탁해"처럼 입력하면 AI는 대답 문장과 함께 의도 태그(`{"intent":"청혼_요청","tone":"공손"}`)를 돌려줌. 게임은 태그를 실제 상호작용으로 바꿔 규칙대로 판정함. AI가 결과를 정하지 않음
- **결정론 규칙**: AI 문장은 규칙 판정의 입력으로 쓰지 않음 (표시, 기억, 연대기에만 저장). 게임 행동이 되는 것은 의도 태그뿐이고, 의도 태그는 반드시 **입력 로그**(30-3)를 거쳐 다음 틱 경계에서 플레이어 의도와 같은 방식으로 들어감. 스키마로 보장: AI 응답 타입에는 수치 필드가 없고, 의도 태그는 허용 목록 enum

## 25-2. 모델과 비용

- 기본 모델: 짧은 대사, 속마음은 `claude-haiku-4-5-20251001`, 연대기 문장과 편지는 `claude-sonnet-5` (설정에서 변경)
- **키 관리**
  - 데스크톱: 사용자가 자기 API 키 입력 → OS 자격 증명 저장소에 보관. 게임 파일에 평문 저장 금지
  - 브라우저 빌드: 키를 브라우저에 두지 않고, 우리 서버(26장 백엔드)의 프록시를 거침 (로그인 사용자, 하루 요청 한도)
- **비용 통제**: 하루(게임) 요청 상한, 월 예산 표시, 같은 상황 응답 캐시(상황 해시 → 문장), 배치 요청(하루 시작 때 가족 속마음 몇 개를 미리 생성), 시스템 프롬프트 캐싱
- 설정: AI 끄기 / 연대기만 / 대사+연대기 / 전부

## 25-3. 품질 규칙

- 시스템 프롬프트에 세계관 요약, 신분별 말투 표, 수위 기준, 금지 사항 (현대어, 노골적인 성적 묘사(19금), 실존 인물/종교 비방, 게임 수치 언급), 길이 제한
- **수위**: 17세 이용가 수준(00장 "수위와 톤")의 폭력, 부상, 죽음, 성적 암시와 농담, 불륜 묘사는 허용. 수위 설정(전연령 / 15세 / 17세, 기본 17세, 27-5)에 따라 시스템 프롬프트의 수위 문단과 출력 검증기의 금지어 목록이 바뀜
- 응답은 JSON 스키마로 받음. 스키마 위반, 길이 초과, 금지어 포함 시 폐기하고 규칙 기반 대체
- 지연: 응답이 1.5초 넘게 걸리면 규칙 기반 문장을 먼저 보여 주고, AI 문장이 오면 연대기/기억에만 저장. 모든 AI 결과는 `{요청 id, 요청 틱, 도착 틱, 결과}`로 입력 로그에 기록하고, 불러오기 후 재실행과 리플레이는 로그에서 읽음 (도착 틱이 실행마다 달라도 같은 저장 결과)
- 생성 문장은 인물 기억과 연대기에 저장되어 **같은 세계의 이야기**로 쌓임 (다음 요청에 요약 전달)
- 오프라인: 자동으로 규칙 기반

## 25-4. 테스트

- AI 응답을 녹화한 고정 픽스처(= 입력 로그)로 결정론 테스트 (실제 호출 없이). 같은 시드 + 같은 입력 로그 = 같은 월드 해시
- 수위 설정 3단계별 검증기 테스트
- 금지어/길이/스키마 검증기 유닛 테스트
- 실제 호출 스모크 테스트는 키가 있을 때만, 요청 5건 이내
