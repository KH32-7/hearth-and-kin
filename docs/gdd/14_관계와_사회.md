# 14. 관계와 사회

## 14-1. 관계 3축

| 축 | 범위 | 뜻 | 자연 감소 |
| --- | --- | --- | --- |
| 우정 | -100 ~ 100 | 좋아함/싫어함 | 0 쪽으로 하루 1 (가족 중심 특성은 가족에게 0.5) |
| 로맨스 | 0 ~ 100 | 연정 | 하루 1.5 (낭만적 특성은 배우자/연인에게 0.75) |
| 존중 | -100 ~ 100 | 상대를 어떻게 보는가. 신분, 명예, 스킬, 행동이 영향 | 감소 없음 (사건으로만 변함) |

- 자연 감소는 `lifespan` 속도 필드: 표의 값 ÷ 수명 배수 (29-0). 덕/죄는 감소 속도를 바꾸지 않음 (12-2)
- **존중**이 이 게임의 중세 축. 신분이 높아도 존중이 낮으면 "허울뿐인 나리", 신분이 낮아도 존중이 높으면 "존경받는 장인"
- 관계 수치에 따라 **관계 이름**이 붙음

| 이름 | 조건 |
| --- | --- |
| 원수 | 우정 -60 이하 |
| 앙숙 | 우정 -30 이하 |
| 아는 사이 | 한 번이라도 대화 |
| 친구 | 우정 30 이상 |
| 절친 | 우정 70 이상, 함께한 기억 5개 |
| 연인 | 로맨스 50 이상 + 고백 성공 |
| 약혼자, 배우자, 전 배우자 | 사건 |
| 스승/제자, 주인/하인, 영주/소작인 | 사건, 직업 |

- 가족 관계(부모, 자식, 형제, 조부모, 사촌, 인척, 대부모)는 따로 저장. 가계도 화면(16장)
- 관계 기록: 둘이 공유한 기억 목록, 마지막 상호작용 날짜

## 14-2. 첫인상

- 처음 만나면 첫인상 판정: 외모(선천 특성), 신분 차이, 옷차림(신분에 맞는가), 위생, 특성 궁합, 소문으로 들은 평판
- 결과로 시작 우정 -20 ~ +20, 존중 -30 ~ +30

## 14-3. 사회 상호작용 80개 이상

| 분류 | 예시 (각 분류 목표 개수) |
| --- | --- |
| 기본 (10) | 인사, 안부 묻기, 날씨 이야기, 소개하기, 작별 |
| 친근 (18) | 수다, 농담, 칭찬, 포옹, 고민 들어주기, 조언하기, 추억 이야기, 취향 이야기, 선물 주기, 노래 불러주기, 함께 기도 |
| 로맨스 (14) | 눈짓, 작업 걸기, 꽃 주기, 손 잡기, 고백, 입맞춤, 세레나데, 연서 보내기, 청혼, 동침 제안 |
| 짓궂음 (14) | 놀리기, 모욕, 말다툼, 험담, 비웃기, 따귀, 주먹질, 결투 신청, 저주하기(미신) |
| 신분 (10) | 절하기, 무릎 꿇기, 탄원하기, 명령하기, 하사하기, 꾸짖기, 축복 청하기, 보호 요청 |
| 거래 (6) | 흥정하기, 빚 요청, 빚 독촉, 뇌물, 동업 제안, 도제 받아주기 |
| 특수 (10+) | 특성, 덕/죄, 감정, 직업이 여는 것 (위로하기, 설교하기, 약 처방, 점 봐주기, 음모 꾸미기) |

### 성공 판정

```
성공 확률 = 기본값
  + 우정 × 0.3 + 로맨스(로맨스 분류일 때) × 0.4 + 존중 × 0.2
  + 이야기(화술) 스킬 × 3
  + 감정 보정(양쪽) + 특성 보정(양쪽) + 신분 차이 보정
  + 분위기 보정(장소, 시간, 주변 사람)
  (5% ~ 95%로 제한)
```

- 신분 규칙: 신분이 낮은 사람이 높은 사람에게 무례한 상호작용(모욕, 놀리기)을 하면 성공해도 존중 대신 **처벌 사건** 위험 (벌금, 태형, 감옥 하루). 높은 사람이 낮은 사람을 모욕하면 우정은 떨어지지만 처벌은 없고 "오만함" 소문
- **대화 주제 말풍선**: 대화 중 머리 위에 주제 아이콘 (날씨, 음식, 사랑, 일, 신앙, 소문, 가족, 전쟁, 역병). 공유 관심 주제면 효과 +
- 실제 문장 대사: 머리 위는 웅얼거림 + 주제 아이콘. 조작 인물의 대화와 장면은 **대사창**(27-13)에 지문 + 대사로 보여 줌. AI가 없으면 규칙 기반 문장 풀, 켜져 있으면 25장 방식으로 생성

## 14-4. 구애와 혼인

중세의 혼인은 개인의 사랑만이 아니라 **가문의 일**

### 두 가지 길

| 길 | 과정 |
| --- | --- |
| 연애혼 | 로맨스 50 → 고백 → 연인 → 청혼 → **양가 부모(가장)의 승낙** 판정 → 약혼 → 교회 혼례 |
| 중매혼 | 가장이 "혼처 찾기" (중매인 NPC 또는 편지) → 후보 목록 (신분, 지참금, 가문 명성, 나이, 특성 일부 표시) → 협상 (지참금, 거주지, 성씨) → 약혼 → 혼례. 당사자 호감은 낮을 수 있음 |

- **부모 승낙 판정**: 신분 차이, 지참금, 가문 관계, 상대 명성, 부모 특성. 거절되면 "사랑의 도피" 선택 가능 (명예 크게 하락, 연대기에 극적인 삽화)
- **지참금/신부값**: 신분별 기준 금액 = 신부 가문 신분의 한 인생 저축 목표 S × 1/4, 한 단계 위 가문과 혼인하면 상대 기준 × 1.5 (17-4 역산표). 재산이 부족하면 빚, 땅, 가보로 대신할 수 있음 (가보는 상대 가문 가보가 됨, 16-5)
- **혼례**: 특별한 날. 교회 예식 → 잔치. 하객 수와 잔치 점수가 가문 명성에 반영
- **거주**: 신부가 신랑 집으로 가는 것이 기본. 데릴사위(신랑이 신부 가문으로, 성을 바꿈) 협상 가능. 두 가족이 합칠 때 누구의 집으로 갈지 선택. 들어가는 가정이 인원 상한(15-8)이면 분가해서 새 가정을 꾸림
- **신분**: 혼인한 배우자와 자녀의 신분, 농노와 자유민의 혼인은 16-2 두 층 규칙
- 혼인 가능 나이 16세 이상 (청소년 후반부터). 혼인한 청소년도 임신 가능 (15-1). 근친 혼인 불가 (4촌 이내)

### 혼인 이후

- 부부 관계는 로맨스와 우정이 따로 움직임. "정 없는 부부"(우정 높고 로맨스 낮음) 같은 상태도 자연스럽게 생김
- **불륜**: 기혼자가 다른 사람과 연인 관계. 목격되거나 소문이 나면 배우자 "배신" 기억 (우정 -60, 로맨스 -50), 가문 명예 하락, 교회 평판 하락
- **사생아**: 불륜에서 태어난 아이. 가문 계승권 규칙(16장)에서 뒤로 밀림, 소문 대상
- **혼인 무효/별거**: 이혼은 교회가 허락하지 않음. 대신 혼인 무효 청원(돈 + 교회 평판 + 사유 필요) 또는 별거(한 명이 집을 나감)
- **사별과 재혼**: 배우자 사망 후 애도 기간(게임 7일, `lifespan`)이 지나기 전 재혼하면 소문. 죽은 배우자가 유령이어도 재혼 가능 (유령 질투 사건, 20-6)

## 14-5. 원한과 결투

- 우정 -60 이하가 되면 **원한** 관계. 원한은 가문 단위로 번질 수 있음 (가문 간 관계, 16장)
- 원한의 자율 행동: 험담, 모욕, 기물 파손(밤에 몰래), 고발
- **결투**: 기사/귀족/용감한 인물. 결투 신청 → 수락/거절(거절 시 개인 명예와 가문 명성 하락) → 결투. 조작 가문 인물이 참가하면 32-2 교전 방식(라운드마다 자세 선택, 차단 장면)으로 진행하고, NPC끼리는 같은 판정식의 간이 전투(32-2)로 즉시 계산 → 패배 시 부상, 영구 부상, 사망 (사망 설정 행렬 "전투", 20-7. 현실적 기본 켬)
- **주먹다짐**: 평민 버전. 여관에서 자주 일어남. 부상, 벌금. 32-2 교전 방식

## 14-6. 소문 네트워크 (인조이에서 가져온 사회 전체 규칙)

- **소문**: `{대상 인물/가문, 내용 종류, 진실 여부, 좋음/나쁨, 세기, 퍼진 사람 목록}`
- 발생: 누군가 사건을 목격 (불륜, 도둑질, 망신, 선행, 걸작, 기적) / 거짓 소문을 퍼뜨림 (교활함, 심술궂음)
- 전파: LOD와 상관없이 **장소별 하루 접촉 수 기반 확률 전파**로 하루 1회 계산 (전체 LOD 인물의 실제 대화는 추가 전파). 장소 v에 그날 들른 인물 N명 중 소문을 아는 사람이 k명이면, 모르는 사람 각자의 전파 확률 = 1 − (1 − p)^(하루 접촉 수 × k / N). p = 기본 0.15 × 장소 배수(여관, 장터, 교회 앞, 우물가 2배) × 전하는 쪽 수다쟁이 2배. 목표: 큰 추문이 인구 절반에 3~7일 (29-1)
- 효과: 소문을 들은 인물의 대상에 대한 존중/우정 변화, 가문 명예 변화
- 소멸: 시간이 지나면 약해짐. 더 큰 소문이 덮으면 빨리 잊힘
- **대응**: 해명하기, 소문 낸 사람 찾아가 따지기, 선행으로 덮기, 교회에서 공개 참회
- 화면: "마을 소문" 패널에 우리 가문 관련 소문과 퍼진 정도(몇 명이 아는지) 표시. 자기 소문은 누군가 전해 줘야 알 수 있음

## 14-7. 편지

- 문해력(읽기 스킬 1 이상)이 있으면 편지 쓰기/읽기 가능. 없으면 사제나 서기에게 돈 주고 대필/대독
- 용도: 먼 친척과 교류, 초대장, 연서, 중매, 청원서, 협박장
- 전달: 전령 NPC가 하루 뒤 전달. 편지함 UI
- AI 대화가 켜져 있으면 편지 본문 생성 (25장), 아니면 문장 틀 조합
