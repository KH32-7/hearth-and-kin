# 16. 가문과 신분

## 16-1. 가문

플레이어가 조작하는 단위는 결국 **가문**. 인물은 죽어도 가문은 이어짐. 가문(성씨 단위)은 가정(집 단위) 여러 개를 가질 수 있음 (15-8)

| 요소 | 내용 |
| --- | --- |
| 가문명 | 자유민 이상이 가짐. 농노는 신분 상승 때 가문명을 얻는 연출 |
| 문장 | **문장 편집기**: 방패 모양 6, 분할 12, 문양 40(사자, 독수리, 망치, 밀 이삭, 물고기 등), 색 8 (문장학 색 규칙: 금속색 위에 금속색 금지 경고). 옷, 깃발, 방패, 편지 봉인, 연대기 표지, 집 문패에 표시 |
| 가훈 | 직접 입력 (최대 20자). 가훈에 맞는 소원이 가족에게 가끔 생김 (키워드 태그를 골라서 연결) |
| 가장 | 가문의 결정권자. 혼사, 상속, 재산 처분, 교육 경로. 조작 인물과 다를 수 있음. 살아 있는 인물만 가장이 됨 (유령 불가, 20-6) |
| 가문 명성 | 0~1000. 마을이 이 가문을 어떻게 보는가 (명예). 평판 수치 전체는 16-4 |
| 가문 재산 | 가정들의 돈과 저장고 + 가문 공동 재산(집, 땅, 가게, 가축, 가보). 영주 금고는 별도 계정 (18-4) |
| 가보 | 대를 잇는 물건 (16-5) |
| 가문 보상 | 가문 명성 단계별로 해금되는 가문 전체 효과 (예: "대장장이 명가" → 가족 전원 공예 분류 스킬 경험치 +10%) |
| 가계도 | 5대까지 한 화면에, 이전 세대는 펼쳐 보기. 초상화, 생몰년, 칭호, 사인 |

## 16-2. 신분 7단계

| 신분 | 뜻 | 가능한 것 | 제약 |
| --- | --- | --- | --- |
| 농노 | 영주 땅에 매인 농민 | 영주 밭 노동, 가내 생산, 장터 소매 | 이사 불가(영주 허락 필요), 영주에게 부역일(주 1일 강제 래빗홀), 혼인에 영주 허락, 가문명 없음 |
| 자유민 | 자유 농민, 품팔이 | 이사, 직업 자유 선택, 도제 입문 | 세금 |
| 장인 | 길드에 속한 수공업자 | 가게 운영, 도제 받기, 길드 회의 | 길드 규칙(가격, 품질) 준수 |
| 상인 | 교역, 대금업 | 원거리 교역(여정), 대출, 가게 여러 개 | 교회의 이자 비난 (교회 평판) |
| 성직자 | 사제, 수사, 수녀 | 성사 집전, 교육, 교회 재산 관리 | 혼인 불가 (수도회 규칙), 자녀는 추문 |
| 기사 | 무장 기사, 향사 | 마상시합, 전쟁 소집, 영주 궁정 출입 | 영주에 대한 군역 의무 |
| 귀족 | 영주 가문 | 영지 수입, 재판, 세금 부과, 마을 정책 (18장) | 명예 관리 부담, 사치 요구 (신분에 맞는 저택/옷/연회 안 하면 명예 하락) |

### 신분의 두 층: 개인 신분과 가정 대표 신분

- 모든 인물은 **개인 신분** 필드를 가짐. 각 가정은 **가정 대표 신분**(= 가장의 개인 신분)을 가짐
- 사치 금지법, 출입, 처벌, 말투, 이름 풀, 인사 상호작용은 **개인 신분**을 읽음. 세금, 부역, 가계 목표(17-4), 집 종류, 시작 프리셋은 **가정 대표 신분**을 읽음
- 성직자는 항상 개인 신분만 바뀜 (가정 대표 신분은 그대로)

| 상황 | 규칙 |
| --- | --- |
| 혼인 | 배우자는 혼인 시 가장의 신분을 따름. 농노 배우자가 자유민 이상 가정으로 들어오면 혼인 때 해방금 절반(4은화, 17-4) + 영주 허락. 자유민 이상이 농노 가정으로 들어가면 농노가 됨 (연애혼에서 경고 표시) |
| 데릴사위 | 신부 가문이 가장 가문이므로 데릴사위는 신부 가장의 신분을 따르고 성을 바꿈 |
| 자녀 | 출생 시 가정 대표 신분 |
| 사생아 | 어머니의 개인 신분. 계승 순위는 16-5 |
| 성직자의 자녀 (추문) | 어머니의 개인 신분, 사생아와 같은 처리 |
| 기사 서임, 작위 | 본인 + 배우자 + 미성년(18세 미만) 자녀. 성인 자녀는 같은 가정에 살면 다음 가장 계승 때 반영 |
| 해방 | 해방금을 낸 가정 전체 (도시 도망 해방은 본인만) |
| 파산 하락 | 가정 전체 (분가한 다른 가정은 그대로) |
| 길드 제명 | 본인만 (장인 → 자유민). 본인이 가장이면 가정 대표 신분도 바뀜 |
| 중죄 신분 박탈 | 본인만, 재산 몰수는 가정 전체 |
| 분가 | 분가 시점 신분 유지 |

### 시작 신분 선택

심즈처럼 **원하는 형편에서 시작**함. 밑바닥에서 올라가는 것은 여러 플레이 방식 중 하나일 뿐

| 시작 신분 | 필수 자산 (모든 형편 공통) | 이 신분의 플레이 |
| --- | --- | --- |
| 농노 | 영주가 준 오두막(경작권, 소유 아님), 밭 구획 2, 닭 3 | 살아남기, 해방금 모으기, 자식 교육 |
| 자유민 | 작은 집 또는 농가, 밭 구획 3 (또는 품팔이) | 도제 입문, 땅 늘리기, 여관/소매 |
| 장인 | 공방 겸 집, 직업 도구, 길드 회원 자격, 도제 1명 | 걸작, 길드장, 가게 확장 |
| 상인 | 가게가 딸린 집, 교역 자본 3금화, 하인 1명 | 교역, 대출, 작위 매입 |
| 성직자 (개인) | 교구 사제관 또는 수도원 방 (교회 소유) | 교구 돌보기, 주교 경로, 교회 정치 |
| 기사 | 작은 장원(장원 2, 소작 농가 4), 군마, 갑옷, 종자 1명 | 마상시합, 전쟁, 영주 궁정, 혼인 동맹 |
| 귀족 | 영주 저택 또는 성의 거주동, 영지(장원 12, 소작 12가구, 마을 정책권, 18-4), 하인 4명 이상 | **가진 것을 지키는 게임**: 영지 경영, 민심, 명예, 사치 요구, 상속 분쟁, 가문 간 정치 |

- **시작 형편 3종**: 필수 자산 위에 현금을 그 신분 "한 인생 저축 목표 S"(17-4)의 배수로 줌. 몰락 = −0.5S(빚, 상환일 28일), 보통 = 0.3S, 부유 = 1.5S. S가 수명 배수를 따르므로 설정이 바뀌어도 상대 가치가 유지됨 (예: 몰락 귀족 = 빚 3,840동화, 부유한 농노 = 216동화)
- **기본 가족 구성**(7 × 3 = 21 프리셋 공통): 청년 부부(가장 표시 나이 22세 안팎) + 아동 1~2명. 성직자는 본인 + 같은 가문 형제 부부 + 아동 1명
- 프리셋 데이터(`start_presets.json`): 신분, 형편, 현금 배수, 필수 자산, 가족 구성. 29-1 생존 목표는 21개 프리셋 × 기본 설정으로 측정
- **미리 만든 가문**(18-2)으로 시작하면 해당 가문의 신분, 이야기, 형편 그대로 (형편 선택 없음)
- 샌드박스 옵션: 시작 자금 직접 입력, 신분 규칙(사치 금지법, 출입 제한) 끄기
- 신분마다 인생 목표 추천이 다름: 귀족은 "가문 번영", "복수", "평생의 사랑" 쪽, 농노는 "신분 상승", "부의 축적" 쪽. 강제는 아님
- **귀족 전용 인생 목표 2개 추가**: "영지의 번영" (민심 80 이상, 인구 증가, 추수 3번 동안 흉년 아사 0), "궁정의 실력자" (왕실 관직, 가문 명성 전설) → 성인 인생 목표 총 14개 (12장. 아동 목표 4개는 따로)
- 신분이 정하는 것: 옷 염료와 옷감, 방 점수 체감, 들어갈 수 있는 장소(성 안뜰/대전), 결혼 가능 범위(두 단계 이상 차이면 승낙 판정 크게 불리), 사회 상호작용(절하기/명령하기), 처벌 무게, 이름 풀, 말투

### 사치 금지법

- **소유는 합법, 판정은 공공 장소 착용/휴대에만**. 집과 자기 부지 안에서는 무엇을 입든 판정 없음
- 신분보다 높은 등급의 옷감, 염료, 무기, 갑옷을 공공 장소에서 착용/휴대하면 "분수를 모름" 판정 대상
- **발견 판정**: 집행관(NPC 역할) 또는 사제의 시야 안에 있을 때만. 확률 = 20% × 등급 격차 × 명성 보정(명망/전설 0.5, 불명예 1.5), 게임 1시간마다. 발견되면 벌금(격차 × 2은화) + 가문 명성 하락, 반복되면 몰수
- 반대로 귀족이 너무 초라하게 입으면 "체면 손상"
- 선물이나 상속으로 받을 때 "입으면 위험한 옷/물건" 표시
- 샌드박스에서 신분 규칙을 끄면 NPC를 포함해 아무도 판정하지 않음

| 등급 (공공 착용/휴대 최소 신분) | 옷감 | 염료 | 무기 | 갑옷 |
| --- | --- | --- | --- | --- |
| 모두 (농노부터) | 거친 모직, 삼베 | 생성, 갈색, 회색 | 단검, 곤봉, 도끼, 창, 활, 지팡이 | 누비옷 |
| 자유민 | 고운 모직 | 청색, 녹색 | 검, 석궁 | 가죽 |
| 장인 | 고운 리넨 | 적색 | | |
| 상인 | 비단 장식, 모피 테두리(여우) | 짙은 청색 | | 사슬 |
| 기사 | 비단 옷 | 문장 색 | | 판금 |
| 귀족 | 벨벳, 담비 모피 | 진홍색, 자주색 | | |

- **예외**: 사육제 기간(뒤집힌 세상, 19-4) 전체 / 혼례 당일 본인 예복은 한 등급 위까지 / 하인 제복은 주인 신분 −1 등급까지 / 신분 하락 후 달력 1계절(`season`) 유예 / 경비병, 종자 등 직무 장비(직업이 지급한 무기와 갑옷)

## 16-3. 신분 이동 경로 (올라가기)

금액은 전부 17-4 역산표 (`lifespan`)

| 경로 | 조건 | 비용/위험 |
| --- | --- | --- |
| 해방 | 농노 → 자유민. 영주에게 해방금 지불 / 도시에서 달력 1년 + 1일 살기(도망, 들키면 처벌. 기간은 min(달력 1년 + 1일, 29일 × 수명 배수)) / 영주 은혜 사건 | 해방금 8은화 |
| 길드 가입 | 자유민 → 장인. 도제(10일) → 직인(최소 8일) → 걸작 제출 → 장인 인정 (`lifespan`) | 도제 기간, 길드 가입비 6은화 |
| 상업 | 자유민/장인 → 상인. 자본 3금화 이상 + 상인 조합 가입 | 교역 실패로 파산 위험 |
| 기사 서임 | 종자 → 기사. 무예 스킬 + 영주의 추천 + 마상시합 우승 또는 전공 | 부상, 전사 위험 |
| 혼인 | 한 단계 위 가문과 혼인 (지참금 = 상대 신분 기준 × 1.5). 신분 반영은 위 두 층 규칙 | 지참금, 상대 가문에서의 낮은 존중 |
| 작위 매입 | 상인 → 귀족. 왕실에 헌금 20금화 (상인 2~3세대 저축) + 가문 명성 "명망" 이상 | 돈, 귀족들의 멸시(존중 낮게 시작) |
| 성직 | 누구나 → 개인 성직자. 주교까지 오르면 가문 명성 크게 상승 | 혼인 불가 |

### 신분 하락

- 파산 (빚을 못 갚음, 17-6) → 재산 압류 → 가정 전체 한 단계 하락 가능
- 중죄 (절도, 반역, 이단 판결) → 재산 몰수, 추방, 본인 신분 박탈 (처형은 18-6)
- 길드 제명 (규칙 위반) → 본인만 장인 → 자유민
- 기사 자격 박탈 (비겁, 불명예) → 본인과 배우자, 미성년 자녀

신분 변경은 연대기의 가장 큰 삽화 트리거

## 16-4. 명예와 평판 수치

### 평판 수치 표

| 수치 | 범위 | 단위 | 무엇이 읽는가 | 감쇠 |
| --- | --- | --- | --- | --- |
| 가문 명성 | 0~1000 | 가문 | 혼사 후보 질, 대출 이율(17-6), 영주 호의, 마을 첫인상, 작위 매입 조건, 가문 보상 | 없음 (사건으로만) |
| 개인 명예 | −500~+500 | 인물 | 그 인물이 가문 명성에 더한 누적 기여분. 칭호, 존중 첫인상, 결투 거절 판정, 인생 목표 "복수"(원수의 명예) | 없음. 사망 후 기록으로 남음 |
| 존중 | −100~100 | 인물 쌍 (14-1) | 관계 이름, 신분 상호작용 성공률 | 없음 |
| 교회 평판 | −100~100 | 인물 (가문 표시는 평균) | 혼인 무효, 수도원 입회, 장례 규모, 사제 도움, 이단 재판 (21-1) | 0 쪽으로 하루 0.5 (`lifespan` 속도) |
| 업보 | −100~100 | 인물 | 사후 판정, 유령 (20-6) | 없음 |
| 민심 | 0~100 | 마을 | 폭동/반란 사건, 영주 가문 명예, 구휼 발동 (18-4, 17-9) | 50 쪽으로 하루 1 |

- **개인 명예의 정의**: 가문 명성을 바꾸는 사건이 특정 인물의 행동에서 나오면, 그 변화량이 그 인물의 개인 명예에도 같은 부호로 쌓임. "명예 −"라고 적힌 특성/보상 효과(12장)는 이 값을 바꾸는 배수 (예: 기사도 = 개인 명예와 가문 명성 감소 절반)
- **사건 결과 스키마**: 사건 카드와 상호작용 결과는 평판 4종(가문 명성, 교회 평판, 업보, 민심) 변화량 필드를 가짐. 존중은 소문(14-6)과 관계로만 바뀜. 예: 불륜 발각 = 가문 명성 −40, 교회 평판 −15, 업보 −10, 배우자 존중 −30
- **명예 단계** (가문 명성 경계): 불명예 0~99 / 수상함 100~249 / 평범 250~499 / 존경 500~699 / 명망 700~899 / 전설 900~1000. 보통 형편 시작 명성은 300 (몰락 200, 부유 400, 미리 만든 가문은 데이터 값)
- 명예를 올리는 것: 잔치, 기부, 교회 건축 헌금, 걸작, 마상시합 입상, 좋은 혼인, 공적인 선행, 좋은 소문
- 명예를 깎는 것: 추문(불륜, 사생아), 빚, 범죄, 망신, 결투 거절, 사치 금지법 위반, 나쁜 소문, 신분에 맞지 않는 생활(귀족이 초라한 집), 영주 금고 사적 유용(18-4)

## 16-5. 상속과 가보

### 상속법 (가문 만들 때 선택, 귀족은 영지 법을 따름)

| 법 | 규칙 |
| --- | --- |
| 장자상속 | 첫째가 집과 재산 대부분. 나머지는 소액 + 분가 |
| 균분상속 | 자녀들이 나눔. 집은 한 명, 나머지는 돈 |
| 지명상속 | 가장이 유언장으로 지정 (유언장 쓰기 상호작용, 문해력 또는 사제 필요) |

- 사생아, 성직자, 출가한 딸은 기본 계승 순위에서 뒤로 (설정 가능)
- 유언은 사망 시점에 확정. 유령의 "남겨진 비밀"은 상속을 다시 판정하지 않고 상속 분쟁 카드로만 영향 (20-6)
- **상속 분쟁**: 형제 간 관계가 나쁘고 재산 차이가 크면 분쟁 사건 (소송, 원한, 가문 분열)
- 가장이 죽으면 → 장례 → 유언 공개 연출(차단 장면) → 새 가장 → 플레이어는 조작 인물 선택

### 가보

- 특정 물건을 "가보로 지정" (최대 10개). 가보는 **이야기를 쌓음**: 누가 만들었고, 누가 썼고, 어떤 사건에 있었는지 (기억 시스템과 연결)
- 가보 예: 할아버지가 만든 모루, 결혼 반지, 가문 검, 성서 사본, 류트
- 효과: 가보를 쓰면 "선조의 기억" 무드렛, 관련 스킬 경험치 보너스. 팔면 가족 전원 슬픔 + 가문 명성 하락
- **가보 지정 해제**: 가문 명성 −20 (조상을 저버림)
- 연대기 부록에 가보 목록과 이력

| 가보에 닿는 사건 | 규칙 |
| --- | --- |
| 화재 (23-5), 내구도 고장 (23-4) | 파괴되지 않고 **손상** 상태 ("그을린 가보", "금 간 가보"). 이력에 기록, 수리(목공/대장일/바느질) 가능, 수리 전에는 효과 절반 |
| 도난 (하인 도둑질 16-7, 고블린 33-3), 압류 (16-3), 중죄 몰수 | 가문의 **"잃어버린 가보" 목록**으로 옮김 (최대 10개 칸에서 빠짐). 되찾기 사건 카드가 연결됨 (장물 발견, 경매, 도둑 추적) |
| 지참금 대체 (14-4) | 상대 가문의 가보가 되고 이전 이력 유지 ("○○ 가문에서 온 반지") |
| 상속 (장자, 지명) | 가장 계승자가 가보 전부를 받음 |
| 상속 (균분) | 가보는 나누지 않음. 가장이 지정한 사람이 받고, 지정이 없으면 새 가장 |
| 분가 | 분가하는 가정이 가져가려면 가장의 허락. 가져간 가보는 가문 가보로 남음 (같은 가문) |
| 되팔기 경매 (23-4) | 판매 = 위 "팔면" 규칙. 이력은 산 쪽 가문으로 이어짐 |

## 16-6. 가문 간 관계

- 마을의 주요 가문 10~15개가 서로 관계를 가짐 (동맹, 우호, 중립, 경쟁, 원수)
- 혼인은 동맹을 만들고, 원한과 추문은 원수를 만듦
- 원수 가문의 자율 행동: 험담, 거래 거부, 혼사 방해, 고발
- 가문 동맹의 효과: 혼사 우대, 빚 보증, 잔치 참석, 어려울 때 도움 사건 (17-9 친척 도움과 같은 방식)

## 16-7. 하인과 가솔

- 상인 이상은 하인을 고용할 수 있음: 하녀, 요리사, 유모, 마부, 집사, 경비 (NPC 역할 직업, 17-2). 가정 인원 상한(15-8)에 포함
- 하인은 자율로 담당 일을 함 (청소, 요리, 아기 돌보기, 말 돌보기). 급여 주간 지급 (1주 = 7일)
- 하인 제복은 주인 신분 −1 등급까지 사치 금지법 예외 (16-2)
- 하인과의 관계, 하인의 충성도 (급여, 대우). 충성이 낮으면 도둑질(가보 포함, 16-5), 소문 유출
- 하인과 주인 가족의 로맨스는 추문 사건
