# 24. 사건과 연대기

시간 흐름은 심즈와 같음 (00장 4절). 한 해를 건너뛰는 기능은 없음. 이야기는 **하루하루 벌어지는 사건**과, 그것을 기록하는 **연대기**로 만들어짐

## 24-1. 사건 카드 (심즈 2 기회 카드의 확장)

하루 모드 도중 짧은 선택 팝업으로 뜨는 이야기 사건. 카드는 **차단 장면**이라 장면 스택(27-7)에 올라가고, 활성이 되면 게임은 자동 일시정지

### 어디서 뜨나

| 출처 | 예 | 대상 상태 (13-8) |
| --- | --- | --- |
| 일터 (래빗홀 중) | "영주의 말이 편자를 잃었다" (17장 일터 사건) | 래빗홀 |
| 집 | 초인종 방문객, 이웃 민원, 가족 갈등, 집요정 흔적 | 가용 |
| 마을 | 장터 흥정, 소문 대면, 경비 검문, 괴물 소문 | 가용 |
| 교회 | 설교 후 사제 면담, 고해 보속 | 가용 |
| 계절/축제 | 5월의 여왕 후보 지명, 추수 잔치 대회 초대 | 가용 |
| 여정 (마을 밖) | 원거리 교역, 순례, 원정 중 사건 (18-5, 32-5). 하루 최대 1장, 알림 카드로 도착 | 여정 |
| 인생 전환 | 생일, 약혼, 출산, 장례 직후 | 가용 |
| 조기 귀가 | 화재, 진통, 가족 사망/위독 (13-9) | 래빗홀, 여정 |
| 연쇄 | 이전 선택의 후속 | 카드별 |

- 빈도: 가족당 한 인생 기대 장수로 정함 (`per_life`). 보통 150장 (하루 약 1.4장), 적게 100장, 많이 220장. 하루 빈도 = 목표 장수 / (104 × 수명 배수). 연속으로 몰려 뜨지 않게 최소 간격 게임 2시간
- 목표 **300장 이상**, `src/data/events/*.json`

### 구조

```
{
  id, 제목, 본문(변수 치환: {이름}, {배우자}, {마을}),
  대상: 개인 | 부부 | 가족 | 가문,
  출처, 조건: { 나이, 생애단계, 신분, 특성, 덕/죄, 직업, 스킬, 관계, 재산, 명성, 업보,
               계절, 날씨, 시간대, 장소, 마을 상태(역병/흉년/전쟁), 마법 설정, 사망 설정, 이전 카드 },
  대상 가용 조건: [가용 | 래빗홀 | 여정 | 무력(잠)] 중 허용 목록 (필수),
  부재 시 처리: 대체 인물(같은 가정의 가용 성인) | 최대 n일 보류 | 소멸 (필수),
  가중치, 1회성 여부,
  재등장 대기: { value, scale: absolute } (필수), 인생당 상한 (필수, 기본 2),
  수위 등급: 전연령 | 15 | 17 (00장 "수위와 톤"),
  선택지: [ { 문구, 선택 가능 조건, 판정(스킬/특성/무작위), 성공 결과, 실패 결과 } ],
  결과 종류: 스탯, 관계, 돈, 재고, 무드렛, 기억, 소문, 특성, 신분, 새 인물(방문객, 연인),
            평판 4종 변화량(가문 명성, 교회 평판, 업보, 민심. 16-4),
            연쇄 카드, 월드 행동(아래 행동 계약), 연대기 삽화
}
```

- 선택지 판정 표시: "잘 될 것 같다 / 반반 / 위험하다" + 관련 스킬/특성 아이콘
- 카드 결과가 **실제 월드에서 이어짐**. 예: "도둑이 들었다 → 쫓아간다"를 고르면 실제로 인물이 달려가고 전투(32장)가 시작됨. 카드가 결과를 글로만 요약하고 끝나지 않음

### 행동 계약 (월드 행동이 있는 결과의 필수 필드)

```
행동 계약: {
  필요 참가자: [ { 역할, 인물 조건, 허용 상태(13-8) } ],
  시작 방식: 상호작용 id | 교전 종류 | 방문객 생성 | 추격,
  최대 지속: 게임분,
  시작 불가 시: { 대체 결과 문장 키, 대체 결과 },
  시간 초과 시: { 대체 결과 문장 키, 대체 결과 }
}
```

- 참가자가 조건을 못 채우거나(래빗홀, 여정, 무력, 이미 다른 장면 중) 경로가 없으면 즉시 "시작 불가 시" 결과로 끝남. 월드 행동이 멈춰 카드가 영원히 열려 있는 경우 없음
- check-data가 모든 카드의 월드 행동에 대체 경로 두 개(시작 불가, 시간 초과)가 있는지 검사
- 대상이 화면 밖이면 월드 행동은 간이 판정(교전은 32-2 간이 전투)으로 즉시 계산

### 톤과 수위

- 분류 비율: 가족/혼인 20%, 일/돈 18%, 사회/소문 15%, 건강 10%, 신앙/미신/마법 10%, 마을/영주/전쟁 10%, 농사/계절 10%, 여정/모험 7%
- 톤: 담백하고 약간 해학적인 중세 민담체. 나쁜 일(죽음, 유산, 굶주림, 처형, 불륜)도 피하지 않고 사실대로 적되 건조한 블랙 유머를 곁들임. 수위는 17세 이용가 기준 (00장 "수위와 톤"): 피, 부상, 죽음의 묘사와 성적 암시는 허용, 노골적인 성행위 묘사는 쓰지 않음. 수위 설정(27-5)이 낮으면 카드 풀에서 등급이 높은 카드를 빼거나 순화 문구로 바꿈
- 예) "옆집 과부가 당신의 닭이 자기 텃밭을 망쳤다며 교회 앞에서 소리친다." → 사과하고 달걀을 준다 / 맞고함친다 / 닭을 탓하며 모른 척한다

## 24-2. 연대기 (가문의 책)

심즈 2의 기억 + BitLife의 리본을 눈에 보이게 만든, 이 게임의 얼굴

### 기록되는 것

- **삽화**: 중요 순간에 게임이 화면을 잘라 저장하고 **필사본 삽화 처리**(테두리 장식, 색 제한, 금박 머리글자)
- 삽화 트리거 **60종 이상**: 출생, 세례, 첫걸음, 첫 입맞춤, 혼례, 신분 상승/하락, 승급, 걸작, 풍년/흉년, 마상시합, 결투, 괴물 퇴치, 원정 귀환, 화재, 역병, 재판, 처형, 가족 사망, 아이의 죽음, 유산, 유령 출현, 새 집, 축제 우승, 가보 획득/손상/분실, 첫 주문 등
- **글**: 문장 틀로 자동 생성 (AI 대화 켜면 25장 방식). 비극도 담담하게, 가끔 건조한 농담으로. 예) "에르덴력 1291년 봄, 대장장이 톰은 마침내 길드 앞에 편자 걸작을 내놓았으니, 늙은 길드장도 고개를 끄덕였다." / "같은 해 겨울 톰의 막내가 열병으로 죽었다. 톰은 사흘 동안 망치를 들지 않았고, 나흘째에는 관 못을 쳤다."
- **하루 한 줄**: 게임 하루가 끝날 때 그날의 가장 중요한 일 한 줄이 기록됨 (없으면 생략)
- 사건 카드 선택은 카드 삽화로 기록. 카드 삽화와 연대기 장식 삽화는 생성형 AI로 채색 필사본풍 일러스트를 만들 수 있음 (28-5)
- 플레이어가 직접 쓰기: 메모, 캡션 수정, 수동 삽화(카메라 버튼)

### 책의 구성

- 표지: 가문 문장, 가문명, 시작 연도
- 장: 가장이 바뀔 때마다 새 장 ("제3장: 앨리스의 시대")
- 부록: 가계도, 가보 이력(손상, 잃어버린 가보 포함), 가문 명성 그래프, 신분 변천, 묘비명 모음
- 책 넘기기 UI (종이 넘김 애니메이션)
- 내보내기: 이미지 묶음/PDF, 갤러리 업로드 (26장)

### 칭호와 묘비명

- 죽으면 인생 요약 **칭호** 판정. **50종 이상**. 예: "강철 손의 명장", "마을의 어머니", "열두 번 약혼한 자", "역병을 이긴 자", "늑대를 쫓은 자", "가난하나 평안했던", "파란만장"
- 칭호 + 인생 목표 달성도 + 기억 상위 3개로 **묘비명 후보 3개** → 선택 또는 직접 입력
- 장 끝에 인물 초상 + 칭호 + 묘비명 페이지

## 24-3. 한 인생이 끝났을 때

- 조작 인물 사망 → 장례 → 연대기 장 마무리 → **후계자 선택** (상속법 추천 표시) → 이어서 플레이
- 살아 있는 가문 구성원이 없으면 **가문 단절** → 연대기 완결 → 새 가문 시작 / 같은 마을 다른 가문으로 이어 하기 (마을은 그대로). 유령은 법적으로 사망했으므로 "살아 있는 구성원"에 들지 않음 (20-6)

## 24-4. 반복 제한과 죽은 카드 검사

- 카드마다 **재등장 대기(게임일, `absolute`)**와 **인생당 상한**(같은 인물 또는 가족 기준, 1회성 카드는 1)이 필수
- 검사 스크립트(check-data): 기본 설정에서 신분 × 생애 단계 × 계절 조합마다 "동시에 자격이 되는 카드 수 ≥ 하루 빈도 × 평균 재등장 대기일"을 확인. 모자라면 그 조합의 카드를 더 쓰거나 대기일을 줄임
- **죽은 카드 3단 검사**
  1. 정적 검사: 조건끼리 모순(예: 아동 + 기혼, 농노 + 작위)인 카드 0
  2. 훅 검사: 테스트 훅(BRIEF 3장)으로 카드 조건 상태를 직접 만든 뒤 `triggerEvent` 없이 자연 발동하는지 확인. 발동 실패 0
  3. 통계 검사: 500인생 가속 헤드리스에서 자격 확률 1% 이상인 카드만 "1회 이상 등장"을 요구. 자격 확률 1% 미만 카드(마녀의 피 출생, 늑대인간 저주, 작위 매입, 주교 승진 등)는 2단 훅 검사로 대신함
