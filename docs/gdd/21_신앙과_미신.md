# 21. 신앙, 교회, 미신

> 실존 종교를 그대로 쓰지 않고, 중세 가톨릭의 구조(성사, 사제, 성인, 십일조, 고해)를 본뜬 가상의 교회 "빛의 교회"로 설정. 교리 논쟁이나 실존 종교 비판은 다루지 않음

## 21-1. 신앙 스킬과 교회 평판

- **신앙 스킬** (1~10): 기도 효과, 설교 이해, 성사 지식. 사제 직업의 핵심
- **교회 평판** (인물, 가문 표시는 평균. 범위와 감쇠는 16-4 평판 표): 교회 출석, 십일조, 기부, 고해, 성사 참여 → +. 불출석, 추문, 이단 의혹, 이자 대금업 → -
- 교회 평판 효과: 혼인 무효 청원, 수도원 입회, 장례 규모, 사제의 도움(치료, 퇴마), 이단 재판에서의 변호

## 21-2. 성사와 의례

| 의례 | 시기 | 게임 내용 |
| --- | --- | --- |
| 세례 | 출생 후 | 대부모 지정, 세례명(수호성인) 선택, 가족 잔치 |
| 견진 | 청소년 진입 | 청소년 단계 전환 행사, 소원 보너스 |
| 혼례 | 14장 | 교회 예식 + 잔치 |
| 고해 | 수시 | 사제와 1:1. 최근 죄(업보 - 행동) 고백 → 업보 일부 회복, 스트레스 감소, 보속(과제: "사흘간 금식"(빵과 물만, 19-4), "기부 은화 1닢") 부여. 보속을 지키면 추가 회복 |
| 미사 | 일요일, 축일 | 13-7 집단 활동. 설교 주제 무작위(사랑, 탐욕, 역병 등) → 들은 인물에게 해당 무드렛/소원 |
| 종부성사 | 임종 | 사제를 부르면 업보 판정 +10 보정 |
| 장례 | 20장 | |

## 21-3. 성인과 축일

- 성인 12명 (가상). 각 성인은 수호 영역을 가짐 (대장장이, 여행자, 산모, 연인, 병자, 농부 등)
- 세례명으로 받은 수호성인 축일: 그 인물에게 행운 무드렛 + 관련 활동 보너스. 성인 축일은 마을 행사가 없는 **개인 행운일** (19-4)
- 성인 유물(교회), 성지 순례(여정 화면)로 소원 성취/치유 확률 보정

## 21-4. 미신과 징조

게임 안에서 **실제로 작동하는 낮은 판타지**. 과하지 않게, 확률 보정 수준. 진짜 마법과 괴물은 33장

| 미신/징조 | 효과 |
| --- | --- |
| 검은 고양이가 앞을 지나감 | 그날 사고 확률 소폭 + (겁쟁이는 긴장 무드렛) |
| 소금 엎지름 | 어깨 너머로 던지면 무효 (상호작용) |
| 붉은 노을 | 다음날 맑음 확률 + (날씨 힌트) |
| 까마귀 떼 | 마을 사망 사건 확률 + |
| 우물에 동전 | 소원 달성 확률 소폭 + |
| 하지 밤 약초 | 효험 2배 |
| 부적 (마녀에게 구입) | 특정 질병 확률 - , 교회 평판 - |
| 혜성 | 한 인생 0.5~1회 (`per_life`). 마을 전체 긴장 무드렛, 큰 사건(역병, 전쟁, 영주 사망) 확률 + |

- 속마음 말풍선으로 징조를 해석하는 대사 ("까마귀가 너무 많아… 누가 죽으려나")

## 21-5. 약초꾼, 마녀, 이단

- **약초꾼(현명한 여인)**: 숲가 오두막 NPC. 약초, 부적, 사랑의 묘약(로맨스 확률 +, 들키면 추문), 점 보기
- 플레이어도 약초학과 "민간 요법" 상호작용으로 약초꾼이 될 수 있음 (치유사 목표와 연결). 실제 주술은 비술 스킬 (33장)
- **마녀 의혹 사건**: 약초꾼 활동 + 나쁜 소문 + 마을 불행(역병, 흉년)이 겹치면 의혹 발생 → 교회 조사 → 재판. 결과는 추방, 벌금, 공개 참회. 화형 같은 잔혹한 결말은 다루지 않음
- **이단 의혹**: 교회 불출석 누적, 이상한 책 소유, 교회 비판 대화 → 조사 사건
