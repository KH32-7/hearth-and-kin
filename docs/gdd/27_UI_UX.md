## 27-2. 하루 모드 화면 배치 (1600×900 목업 기준, 배치는 심즈 4를 따름)

- **좌상단: 시계**. Raven GUI 낮/밤 원판 + 바늘(하루에 한 바퀴). 옆에 시각(크게), 날짜(에르덴력 1287년 봄 3일 수요일), 날씨/기온, 기도 시각 종
- **우상단: 아이콘 띠** (둥근 반투명 판 하나 위에 아이콘 + 작은 글씨, 버튼 틀 없음). 생활 · 건축 | 지도 · 연대기 · 가계부 · 편지 · 메뉴. 켜진 모드는 아이콘이 빛나고 밑줄. 연대기/가계부/편지는 수첩의 그 쪽을 바로 엶
- **우측 알림**: 아이콘 띠 아래로 쌓이는 둥근 반투명 카드 (마을 소식, 편지, 일터 사건, 여정 카드, 대기 중인 장면). 오래되면 흐려지고 사라짐. **위험 알림**(화재, 역병, 영주 소집, 굶주림 무너짐)만 배경이 살짝 붉고 흔들림. 클릭하면 관련 화면
- **좌하단 묶음** (화면 가로 ¼, 세로 ⅓ 안):
  - 왼쪽 가장자리 세로 **행동 대기열**: 아래가 지금 하는 일(크게, 진행 게이지), 위로 예정 2칸, 넘치면 +n. 사람을 상대로 하는 행동은 상대 얼굴 + 행동 아이콘. 클릭으로 취소
  - **조작 인물 상반신**: 틀 없이 그리고 뒤에 **감정색 빛**을 은은하게 깜. 감정 이름은 왼쪽에 세로 글씨 (심즈 4)
  - 머리 옆 **생각 풍선**: 지금 원하는 것 (소원, 13장 속마음)
  - 맨 아래 한 줄: 이름 · 돈(파운드/실링/펜스/파딩) · 가문 명성
  - 초상 오른쪽 **집 + 가족 머리 줄**: 각자 감정색 빛, 욕구 위험은 !, 래빗홀/여정/부재는 흐리게, 유령 슬롯 2개는 줄 끝에 푸른 빛 (20-6). 마우스를 올리면 이름 · 하는 일 · 가장 낮은 욕구 말풍선. 클릭/Space로 조작 전환
- **하단 가운데: 속도** 동그란 버튼 4개(일시정지 · 1 · 2 · 3배). 켜진 속도는 파란 버튼. 자동 가속 · 강제 1배(27-7)는 버튼 위 작은 아이콘으로만 표시 (글씨 없음)
- **우하단: 자주 쓰는 창** 아이콘 띠: 욕구 · 감정 · 관계 · 소원 · 수첩. 누르면 그 위로 반투명 팝업 (27-9). 욕구가 하나라도 30% 밑이면 욕구 아이콘에 빨간 점
- **화면 모서리 그늘**: 좌상단과 좌하단에만 옅은 방사형 그늘(0.5)을 깔아 글자를 읽기 쉽게
- 원형 메뉴: 클릭 위치 기준, 화면 밖으로 안 나가게 보정
- UI 전체 숨기기 H (메뉴에도 있음, 스크린샷용)

## 27-3. 시각 언어

- **메인 UI 팩: Kenmi Cute Fantasy UI.** 버튼, 책, 책갈피, 리본, 바느질 칸, 게이지, 아이콘은 여기서. 없는 것만 다른 팩에서 가져옴: 시계(Raven GUI), 지도·집·돈주머니·작물·음식·성·수레(Raven Fantasy Icons), 무드렛(Elthen Status Effects)
- **하루 모드 HUD는 판을 최소로.** 판은 알림과 같은 둥근 반투명(짙은 갈색 45%, 뒤 흐림) 하나로 통일. 나머지는 아이콘과 외곽선 글씨만 세계 위에 띄움. 네모 틀로 감싸지 않음. 밤에는 판 불투명도를 62%까지 올림
- **픽셀 선명도**: 늘려 붙이는 테두리(9-slice)를 포함한 모든 UI 그림은 `image-rendering: pixelated`. 빠지면 브라우저가 테두리를 부드럽게 뭉개서 해상도가 깨져 보임
- **책(수첩)만 불투명한 물건.** Cute Fantasy Book_UI를 원본 1px = 화면 4px 정수 배율로 쓰고, 안쪽 부품도 전부 4px 격자에 맞춤 (27-8)
- **신분이 UI 장식을 바꿈**: 수첩 표지와 위쪽 탭 색이 가정 대표 신분을 따름 (27-11)
- **UI는 글로 설명하지 않음.** 화면에 붙어 있는 설명문, 조작 안내문을 두지 않음. 글자는 이름 · 수치 · 내용(대사, 알림 본문, 연대기)만. 조작은 아이콘으로: 키 = Raven GUI 키캡(Q · E · Shift · Tab · Esc · F1 · H · Ctrl · S), "다음으로 넘김" = 대사창 오른쪽 아래에서 까딱이는 ▼ (Cute 흰 삼각형을 판 색에 맞게 칠함: 반투명 판은 금색, 책 판은 잉크 갈색. 0.9초 주기로 4px 내려갔다 올라옴), 방향 = 화살표, 상태 = 아이콘(일시정지, 자물쇠/금지, 책갈피 고정). 규칙 설명이 필요하면 마우스를 올렸을 때 툴팁과 도움말 사전(F1)으로
- 폰트: **넥슨 워헤이븐체** (Regular/Bold) 하나로 통일. 제목, 라벨, 본문, 연대기, 사건 카드 모두. 배포 파일을 수정 없이 그대로 사용 (라이선스상 수정/서브셋 금지). 지원하지 않는 글자가 있으면 그 글자만 대체 폰트로 표시하는 폴백 설정 (04장). 이모지는 쓰지 않음
- 아이콘: 16/32px 픽셀 아이콘, 정수 배율만. 욕구 8종 아이콘: 허기(빵) · 기력(달) · 청결 · 용변 · 재미(별) · 교류(말풍선) · 온기(모닥불) · 편안
- 색만으로 정보를 전달하지 않음 (아이콘 + 문구 병행)

## 27-4. 튜토리얼

- 새 게임 첫날 "첫 하루" 튜토리얼: 기상 → 원형 메뉴 → 대기열 → 욕구 → 빵 굽기 → 이웃과 대화 → 잠 → 하루 정산. 건너뛰기 가능
- 이후 기능은 처음 마주칠 때 한 번 짧은 설명 카드 (건축 모드 첫 진입, 첫 사건 카드, 첫 임신, 첫 역병)
- 도움말 사전: 모든 시스템 설명 (게임 안 백과)

## 27-5. 접근성과 편의

- UI 크기 80~150%, 글자 크기 별도 조절
- 색각 보정 팔레트 (욕구 게이지, 관계 색)
- **단축키 기본값** (모두 재설정 가능): 가족 전환 Space(다음) / Shift+Space(이전), 속도 0 또는 P(일시정지) / 1 / 2 / 3, 카메라 인물 추적 F, UI 숨기기 H, 인물 수첩 Tab, 마을 지도 M, 창 닫기 Esc. Space는 가족 전환 전용 (13-2). 구매 중 Q/E는 물건 돌리기
- 자동 일시정지 조건 (사건 팝업, 아기 울음, 화재, 편지) 켜고 끄기. 켜진 조건은 27-7 우선순위의 "일시정지" 단계로 들어감
- 속도 3단계 + 잠/일 건너뛰기 가속
- **저장**: 자동 저장 (게임 하루마다, 슬롯 3개 순환) + 수동 저장 무제한. 저장은 틱 경계에서만 하고 장면 스택 전체를 직렬화 (30-3). 교전 중 수동 저장은 라운드 경계까지 지연, 자동 저장은 활성 차단 장면과 교전이 없을 때까지 미룸 (하루가 바뀐 뒤 첫 가능 틱)
- 되돌리기: 건축/구매 모드 실행 취소/다시 실행
- **수위 설정**: 전연령 / 15세 / 17세 (기본 17세, 00장 "수위와 톤"). 사건 카드 풀(카드의 수위 등급 필드), 연대기 문장 틀의 표현, AI 출력 프롬프트(25-3), 피 효과(선택: 켬/끔)에 적용. 낮출수록 순화 문구와 대체 카드를 씀. 게임 규칙(사망 설정 등)은 바꾸지 않음

## 27-6. 반응형

- 대상 해상도: 1280×720, 1920×1080, 2560×1440, 3440×1440(울트라와이드), 태블릿 가로 1180×820
- 게임 화면 픽셀 정수 배율 유지, UI는 별도 스케일
- UI 배율 기준은 1600×900 = 1.0. 1280×720은 좌하단 묶음 · 팝업 · 아래 판을 0.8, 2560×1440은 1.5. 수첩은 책 격자(원본 1px = 화면 4px)를 지키려고 정수 배율(3·4·5배)만 씀

## 27-7. 장면 스택과 속도 우선순위

속도를 바꾸는 규칙이 여러 장(00장 4절 자동 가속, 27-5 자동 일시정지, 32-2 전투 1배속)에 있어 하나의 스택과 우선순위로 합침

### 장면 스택

- **차단 장면**: 사건 카드, 재판, 출산 연출, 결투, 마상시합(조작 가문 참가), 유언 공개, 임종 "마지막 말". 한 번에 하나만 활성, 나머지는 대기열(발생 순서, 같은 틱이면 우선순위: 출산 > 임종 > 재판 > 결투 > 마상시합 > 유언 공개 > 사건 카드)
- **비차단 장면**: 교전(32-2). 여러 개가 동시에 진행 가능, 차단 장면이 활성이면 일시정지 상태로 대기
- 장면 참가자는 인물 상태 "장면 중"(13-8). 이미 장면 중인 인물이 필요한 새 장면은 대기열에서 기다리고, 대기 한도(카드는 "부재 시 처리", 24-1)를 넘으면 대체 결과로 끝남
- 저장 파일에 스택 전체(활성 장면, 대기열, 진행 단계, 교전 라운드 상태)를 저장 (30-3)

### 속도 우선순위 (위가 이김)

1. **일시정지**: 활성 차단 장면, 사용자 일시정지(0 또는 P), 켜진 자동 일시정지 조건
2. **1배 강제**: 화면 안 교전(32-2), 출산 진통 중 조작 인물
3. **사용자 속도**: 1 / 2 / 3배
4. **자동 가속**: 가정 전원이 래빗홀/여정/무력(잠) 상태면 30배 (00장 4절)

- 화면 밖 교전은 간이 전투로 즉시 계산하므로 속도를 바꾸지 않음 (32-2)
- 헤드리스는 이 우선순위와 무관하게 가속 세밀도로 돔 (BRIEF 4장)

## 27-8. 인물 수첩 (Tab)

심즈의 우하단 패널들을 책 한 권으로 모음. Kenmi Cute Fantasy Book_UI

- **구조**: 위쪽 아이콘 탭 = 큰 분류, 오른쪽 아이콘 책갈피 = 분류 안의 쪽 (한 탭에 최대 5개), 오른쪽 위 X = 닫기. 켜진 탭은 1칸 높고, 켜진 책갈피는 더 길게 튀어나옴
- **격자**: 원본 1px = 화면 4px. 책 896×532, 왼쪽 쪽 내용 칸 x 56~392, 오른쪽 504~840, 위아래 48~456. 위쪽 탭은 왼쪽 쪽 내용 칸 왼쪽 선에서 시작하고 책 뒤로 12px 들어감. 첫 책갈피 위 = 내용 칸 위, 간격 8px
- **부품** (모든 쪽이 같은 것만 씀): 리본 제목(256×80, 쪽 가운데), 바느질 칸(80×80, 4열, 간격 4), 목록 줄(쪽 너비 × 72, 간격 8), 설명 판(모서리 징 판), 게이지(Cute UI_Bars), 버튼(Cute 넓은 버튼)

| | 가계부 | 이번 계절 수입 · 지출 · 세금 · 빚 | 저장고 칸 + 먹을거리 예측 |
| 기록 | 연대기 | 책처럼 넘기는 연대기 본문 (24장) | 이어지는 본문 |
| | 대화 | 대사창에 나온 대화 목록 (최근 게임 7일) | 고른 대화의 지문과 대사 전체 (27-13) |
| | 소문 | 우리 가문 소문 + 퍼진 정도 | 고른 소문 출처 · 할 수 있는 것 |
| | 편지 | 편지 목록 (안 읽음 표시) | 편지 본문, 수락/거절/미루기 |
| | 여정 (여정 중일 때만) | 경로와 머무는 곳 | 길동무, 여정 사건 (하루 모드는 멈추지 않음) |

- 조작: **Tab** 열기/닫기, **Esc** 닫기, 탭/책갈피 클릭. 책이 열려도 시간은 흐름 (심즈 패널과 같음)
- 연출: 열 때 한 번 펄럭이며 올라옴, 쪽을 바꿀 때 짧은 책장 넘김. 새 책갈피가 생기면 첫 열 때 빛남

## 27-9. 자주 쓰는 창 (우하단 팝업)

책을 열지 않고 바로 보는 창. 우하단 아이콘 띠 위로 뜨는 둥근 반투명 판. 같은 아이콘을 다시 누르면 닫힘. 한 번에 하나

| 아이콘 | 내용 |
| --- | --- |
| 욕구 | 욕구 8 게이지 (2열), 30% 밑은 빨강. 제목 줄에 감정 · 무드렛 합계 |
| 감정 | 감정 아이콘 + 이름(감정색), 단계 3칸 (예: 흐뭇함 → 매우 행복 → 환희), 무드렛 목록 (남은 시간, 값) |
| 관계 | 거르기 칩(전체/가족/친구/이웃/원수) + 사람 줄 (얼굴 · 관계 이름 · 우정/애정 게이지). 자세히는 수첩 › 가문 › 관계 |
| 소원 | 생애 소원 단계 게이지 + 다음 단계, 지금 소원 3 (고정 표시, 행복 점수 보상), 행복 점수 |
| 수첩 | 인물 수첩(27-8)을 엶 (= Tab) |

- **스크롤**: 목록이 넘치는 팝업(감정 · 관계 · 소원)은 목록 칸 오른쪽에 얇은 세로 스크롤바 (폭 5px 둥근 막대: 트랙 흰색 10%, 손잡이 흰색 55%, 손잡이 길이 = 보이는 비율). 스크롤바 바깥 여백 = 판 왼쪽 안쪽 여백(16px), 목록과 스크롤바 사이 8px. 목록 아래 끝은 흐리게 사라짐. 욕구 팝업은 8칸 고정이라 스크롤 없음. 수첩(27-8)은 스크롤 대신 ◀ ▶ 쪽 넘김
- 메뉴(우상단 톱니)도 같은 판으로 아래로 펼침: 저장 · 불러오기 · 설정 · 갤러리 · 도움말 사전 · UI 숨기기 · 타이틀로. 단축키는 글자 대신 키캡 아이콘 (Ctrl S · F1 · H). 소원 고정은 책갈피 아이콘(켜짐/흐림), 행복 점수는 별 아이콘 + 숫자

## 27-10. 건축과 구매 화면 (23장)

- **구매는 건축에 합침** (2026-09-26 사용자 결정): 모드 버튼은 생활 | 건축 둘. 건축 판 왼쪽 위에 [물건] [짓기] 탭 (물건이 앞, 건축을 누르면 물건부터). 물건 = 가구 분류 12 + 손수 만든 것, 짓기 = 도구 13

- 들어가면 시간이 멈추고(시계 옆 일시정지 아이콘) 좌하단 묶음, 속도, 자주 쓰는 창은 숨김. 시계와 우상단 아이콘 띠는 그대로 (켜진 모드만 바뀜)
- **위 가운데 도구 띠**: 되돌리기 · 다시 | 층 ▼ 1층 ▲ | 벽 올림/잘라내기/내림 | 지붕 자동/보기/숨김
- **아래 판** (화면 너비, 반투명): 왼쪽 분류/도구, 가운데 물건/재질 칸, 오른쪽 고른 것 설명
  - 구매: 방별/기능별 전환 + 찾기, 분류 12 (침실 · 부엌 · 식당 · 거실 · 씻기 · 작업장 · 장식 · 조명 · 아이 · 가축 · 바깥 · 신앙). 칸 = 물건 그림 · 이름 · 값. 신분 제한(사치 금지법, 16-2)은 흐리게 + 금지 표시. 설명 = 큰 그림, 값, 크기, 쓸 수 있는 신분, 효과(스킬 · 방 점수), 색 변형 견본
  - 건축: 도구 13 (벽 · 방 · 헐기 · 문 · 창 · 바닥 · 땅 · 울타리 · 계단 · 지붕 · 지하 · 방 이름 · 옮기기). 칸 = 재질 견본 · 이름 · 칸당 값. 설명 = 값, 신분, 도움말, 공사 시간 켬/끔 (목수가 며칠에 걸쳐 짓고 가족이 거들면 품삯 절약)
  - 판 위 줄: 동전 아이콘 + 가진 돈, 망치 아이콘 + 이번 공사 비용. 도구 띠(되돌리기 · 다시 · 층 · 벽 높이 3단 · 지붕)는 아이콘만. 물건 돌리기는 유령 옆 Q · E 키캡, 방 한 번에는 Shift 키캡, 공사 시간은 토글 + 망치 · 달 아이콘. 크기는 칸 그림(1×2), 쓸 수 있는 신분은 금지 아이콘
- 세계 위: 놓는 물건 유령 + 발자리 칸 (놓을 수 있으면 초록, 없으면 빨강), 끄는 벽/바닥은 점선 칸 + 작은 반투명 말풍선(칸 수 · 값 · 공사 일수)

| 신분 | 표지 · 탭 | 수첩 | 하루 모드 |
| --- | --- | --- | --- |
| 농노 | 거친 나무 (칙칙한 갈색) | 가문 › 명성과 가훈 → **해방** (해방금 진행, 부역일, 이사/혼인 허락, 가문명 없음). 생업 › 직업 → **부역과 일** | 부역일엔 대기열 맨 앞에 부역 고정, 명성 옆에 해방금 진행 |

## 27-12. 머리 위 표시 (감정 효과와 말풍선)

픽셀 캐릭터는 몸짓이 작아서 심즈만큼 행동과 감정이 보이지 않음. 머리 위 표시와 대사창(27-13)이 그 몫을 나눠 맡음

- **아이콘 말풍선** (Cute Fantasy 색 말풍선 + 16px 아이콘, 스프라이트): 색이 종류를 뜻함. 베이지 = 새 행동(1.2초 톡), 파랑 = 대화 주제 · 맞장구(14-3), 빨강 = 위급 욕구(깜박임), 초록 = 좋은 결과(품삯 · 수확 · 좋은 물건), 분홍 = 로맨스 주제, 노랑 = 소원 이룸
- **감정 효과** (Elthen Status Effects 32px 8프레임, 말풍선 없이 머리 위에서 움직임):

| 효과 | 쓰는 곳 |
| --- | --- |
| 겹하트 | 포옹 · 입맞춤 · 사랑 고백 · 설렘 강함 이상 |
| 하트 | 칭찬 · 선물 · 좋은 대화 결과 (지금의 금 하트 대신) |
| 번개 | 짜증 · 화남 · 격노 (단계가 오를수록 오래) · 대화 실패 (지금의 💢 대신) |
| 물방울 | 울적함 · 우울 · 절망, 눈물 |
| 물음표 | 어리둥절, 모르는 말 |
| 소용돌이 | 술 취함, 멍함 |
| 별 | 어지러움 · 쓰러짐 · 기절 |
| Z | 잠 (지금의 Zzz 대신) |
| 초록 거품 | 병 (역병 · 열병) |
| 붉은 방울 | 다침 · 싸움 |
| 초록 + | 치료 · 회복 |
| 입김 | 온기 낮음 |
| 해골 | 임종 · 위독 (조작 가문에게만) |
| … 말풍선 | 대화 중인데 대사가 없을 때 (웅얼웅얼) |

- **글자 풍선** (DOM, 넥슨 워헤이븐체): 흰 말풍선 = 대사(AI 또는 규칙 대사, 3초, 한 줄 최대 24자), 회색 말풍선 + 방울 꼬리 = 속마음(11-5). 대사창이 열린 대화의 대사는 머리 위에 겹쳐 띄우지 않음
- 겹칠 때: 글자 풍선이 위, 감정 효과는 그 오른쪽 위. 한 사람에게 아이콘 말풍선 하나 + 감정 효과 하나까지
- 배율: 세계와 같은 정수 배율(원본 1px = 세계 2px), 감정 효과만 읽히도록 3배까지 허용. 시간대 색 보정을 받지 않음 (밤에도 읽힘)
- **위치**: 감정 효과는 캐릭터 머리 바로 위. Elthen 그림은 32px 칸 안에서 치우쳐 있으므로 칸이 아니라 **그림 영역**의 아랫변을 머리 꼭대기 2px 위에, 가로 가운데를 머리 가운데에 맞춤 (효과별 그림 영역 표를 아트팩에 둠). 아이콘 말풍선 · 글자 풍선도 꼬리 끝이 머리 꼭대기 4px 위

## 27-13. 대사창

머리 위 풍선으로 다 못 보여 주는 **동작과 말**을 화면 아래 가운데 창에 글로 보여 줌. 애정 표현, 다툼, 청혼처럼 픽셀 몸짓만으로는 약한 장면을 **지문(동작 묘사) + 대사**로 채움

- **자리와 모양**: 속도 버튼 바로 위, 가운데. 둥근 반투명 판(HUD와 같음). 말하는 사람 상반신(감정색 빛)이 왼쪽, 듣는 사람은 오른쪽에 흐리게 좌우 반전. 이름(관계 · 감정) → 지문(옅은 색) → 대사(크게) 순서. 바로 전 대사 한 줄이 위에 흐리게 남음
- **모양은 종류에 따라 나눔**: 한마디 · 대화 · 말 걸기(자주, 시간 흐름)는 **반투명 판** (HUD와 같은 짙은 반투명 + 밝은 외곽선 2px로 좌하단 인물 묶음과 구분, 듣는 사람 초상은 오른쪽 위에 붙이고 ▼는 그 아래 모서리라 겹치지 않음, 상반신은 틀 없이 감정색 빛, 밝은 외곽선 글씨). **장면**(드묾, 시간 멈춤)만 **양피지 판**: 직접 찍은 양피지 판(Cute Fantasy 틀의 명암 순서를 따르되 아주 얇게: 갈색 외곽선 → 밝은 테두리 1px → 바탕 → 아래 두께 1px, 계단 모서리, 안쪽 장식선) + 같은 방식의 바느질 테두리 초상 칸 + 직접 찍은 카드 선택지(판과 같은 얇은 명암, 선택은 외곽선과 밝은 테두리가 초록) + 휘어진 한 겹 리본 제목(Cute UI_Ribbons 78×21), 잉크색 글씨. 판 자체가 "지금 멈춘 중요한 장면"이라는 신호
- **장면 판 배율**: 모든 조각을 원본 1px = 화면 3px 정수 배율로 통일 (리본 234×63으로 판 윗변에 반쯤 걸침, 판 테두리 30px, 초상 칸 120px 안에 초상 108px, 선택지 줄 높이 48px). 바느질 초상 칸은 9-slice로 늘리지 않고 **목표 크기 그대로 원본 해상도에서 찍은 뒤 3배로만 표시** (한 땀 5px 규칙 무늬, `tools/ui/draw-cards.py`). 늘려 붙이면 바느질 무늬가 일그러져 해상도가 깨져 보임. 그래서 카드 크기는 3의 배수로만 잡음. 곡선 리본은 늘리지 않음. 이름은 리본이 아니라 판 안 잉크 글씨 (리본은 장면 제목 전용). 작은 아이콘은 2배(32px)
- **배경 어둡게**: 대사창이 열리면 세계를 살짝 어둡게 깜 (한마디 · 대화 · 말 걸기 14%, 장면 25%). HUD는 어둡게 하지 않음
- **카메라**: 대사창이 열리면 두 사람이 창 위쪽에 오도록 카메라를 부드럽게 옮김 (사람이 창에 가리지 않게). 두 사람 머리 위에는 감정 효과만 (글자 풍선 없음)

| 종류 | 언제 | 모양 | 시간 |

- **문장 출처**: AI가 켜져 있으면 25장 방식(지문 + 대사, 최대 2왕복). **AI가 없을 때도 대사창이 동작하도록 규칙 기반 문장 풀을 둠**: 상호작용(14장) × 결과(성공/실패) × 관계 단계 × 신분 말투(11-5)별 대사, 상호작용별 지문 문장. 모자라면 대사 없이 지문만 보여 줌 (웅얼거림 대신)
- **결정론**: 지문과 대사는 표시와 기억/연대기 저장에만 씀. 선택지 결과와 수치는 게임 판정. AI 문장은 입력 로그를 거침 (25-3)
- **기록**: 창에 나온 대화는 수첩 › 기록 › 연대기 옆 책갈피 "대화"에 날짜순으로 남음 (최근 게임 7일, 중요한 장면은 기억으로 영구)
- **설정**: 대사창 끔 / 장면만 / 장면 + 대화 (기본) / 전부 (한마디 포함). 글자 속도 (바로 · 보통 · 느리게). 수위 설정(27-5)이 지문 표현에도 적용
- 17세 수위: 애정 지문은 포옹 · 입맞춤 · 동침 암시까지. 노골적인 묘사는 쓰지 않음 (00장)
