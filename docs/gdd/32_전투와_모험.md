# 32. 전투와 모험

중세에서 빠질 수 없는 싸움을 넣되, **심즈식 해결**. 액션 게임처럼 캐릭터를 직접 조작해 칼을 휘두르지 않음. 전투는 상호작용이고, 인물의 스킬, 특성, 감정, 장비가 결과를 만들며, 플레이어는 **전술을 고르는 지휘** 역할

## 32-1. 전투가 일어나는 곳

| 종류 | 계기 | 결과 무게 |
| --- | --- | --- |
| 주먹다짐 | 분노 극단, 여관 말다툼, 모욕 | 가벼운 부상, 벌금, 소문 |
| 대련/훈련 | 훈련 허수아비, 친구와 대련 상호작용 | 무예 경험치, 부상 거의 없음 |
| 결투 | 결투 신청 수락 (14장) | 명예, 부상, 사망 설정 행렬(20-7)에 따라 사망 |
| 마상시합 | 축제, 기사 행사 (19장) | 상금, 명성, 부상 |
| 사냥 | 숲 (허가 필요, 밀렵은 범죄) | 고기, 가죽, 멧돼지/곰에게 부상 위험 |
| 도적/산적 | 밤길, 여정, 드물게 마을 외곽 습격 | 재산, 부상, 영웅 칭호 |
| 괴물 조우 | 깊은 숲, 밤, 안개, 겨울 (33장) | 부상, 전리품, 이야기 |
| 전쟁 | 영주의 소집 | 원정 (32-5) |

## 32-2. 교전 방식

1. 교전 시작: 두 편이 마주 섬 (마을 지도 위 그 자리에서. 별도 화면 전환 없음). 교전은 비차단 장면이고 참가자는 "장면 중" 상태 (27-7, 13-8)
2. **라운드**: 한 라운드 약 3초. 화면 안 교전은 속도 우선순위의 "1배 강제" 단계 (27-7)
3. 매 라운드 각 인물이 **자세**를 정함. 기본은 자율(특성, 감정, 스킬로 AI가 고름). 조작 가문 인물은 플레이어가 전술 버튼으로 바꿀 수 있음

| 자세 | 강한 상대 | 약한 상대 |
| --- | --- | --- |
| 공격 | 방어 태세가 아닌 상대 | 반격 |
| 방어 | 공격 | 기술 |
| 기술 (무기별: 찌르기, 방패 밀치기, 조준 사격, 전투용 주문 33-2 허용 목록만) | 방어 | 공격 |
| 후퇴 | - | 성공하면 교전 종료 (속도, 지형, 말) |
| 항복 | - | 상대가 받아들이면 종료 (명예 하락) |

4. 판정: 자세 상성 + 무예 스킬 + 무기/갑옷 품질 + 체력 + 감정(분노 공격 +, 긴장 전체 -, 용감함/겁쟁이) + 부상 상태 + 기마 여부 + 무작위
5. 결과: 우세 게이지가 한쪽으로 기울고, 끝까지 가면 상대가 **쓰러짐(기절)**, **부상**(영구 부상 포함, 20-4), 또는 사망 설정 행렬(20-7)에 따라 **사망**
6. 애니메이션: LPC 생성기의 베기/찌르기/쏘기/주문/다침 동작 + 무기 레이어. 타격 번쩍임, 흙먼지, 작은 화면 흔들림

- 여러 명이 싸우면 짝을 지어 동시에 진행. 수적 우세는 보정
- 비전투원(아이, 노인)은 자동으로 피신 자율 행동
- **간이 전투 (화면 밖)**: 화면 밖 교전(산적 습격, 여관 주먹다짐, 여정 중 전투, NPC끼리 결투)은 위와 같은 판정식을 라운드 묶음으로 즉시 계산. 자세는 자율 선택 규칙으로 고름. 교전 중 카메라가 떠나도 이미 시작한 교전은 화면 안 방식으로 끝까지 진행 (LOD 강등 금지, 13-6)
- 검증: 두 방식 각각 1만 판 승률 테스트, 같은 조건 승률 차 3%p 이내 (29-1)

## 32-3. 장비

| 분류 | 종류 | 비고 |
| --- | --- | --- |
| 무기 | 단검, 곤봉, 도끼, 창, 칼(검), 활, 석궁, 지팡이 | 공공 장소 휴대 신분 규칙은 사치 금지법 표와 같은 표로 관리 (16-2). 검은 자유민 이상 |
| 방패 | 둥근 방패, 연 모양 방패 (문장 그려짐) | 가문 문장 표시 |
| 갑옷 | 누비옷, 가죽, 사슬, 판금 | 판금은 기사 이상 (16-2 표). 무거우면 이동/후퇴 불리 |
| 말 | 22장 | 기마 보정, 마상시합 필수 |

- 장비는 **대장장이가 만듦** (17장). 품질(초라함~걸작)이 전투 보정. 대장장이 가문과 기사 가문이 서로 필요해지는 경제 고리
- 장비는 궤짝/무기 걸이에 보관, 외출 복장에 따라 자동 착용(경비, 기사, 사냥)

## 32-4. 마상시합

- 축제 행사 또는 영주 주최. 참가비, 상금, 명성
- 조작 가문 인물이 참가하면 차단 장면(27-7)으로 아래 방식대로 진행. NPC끼리의 경기는 같은 판정식의 간이 계산
- 한 판 = 세 번 달리기. 매번 **겨누는 곳(높게/가운데/낮게)**과 **방패 위치**를 고름 (상대 성향이 힌트로 보임: "상대는 늘 높게 겨눈다더라") → 명중/빗나감/낙마
- 승자 진출식 대진표. 결승은 관중 환호 연출, 연대기 대형 삽화
- 활쏘기 대회: 바람 방향 힌트 + 조준 선택

## 32-5. 전쟁과 원정

- 영주가 전쟁에 나서면 **소집**: 기사는 의무, 자유민 남성은 추첨 징집 (대신 돈을 내고 빠질 수 있음)
- 원정은 **여정**(다일 래빗홀, 18-5)으로 진행: 행군 → 사건 카드 2~4장(하루 최대 1장) → 전투 1~3회 (32-2 간이 전투, 부대 규모로 확대) → 귀환
- 집에 남은 가족: 걱정 무드렛, 편지 주고받기, 일손 부족, 전사 통지 사건
- 결과: 전리품, 몸값(포로를 잡으면), 훈장/작위(기사 서임 경로, 16장), 부상, 트라우마, 전사
- 전쟁 빈도: 설정 (없음/드묾/보통). 기본 드묾 = 한 인생 0.2~0.4회, 보통 0.5~0.8회 (`per_life`, 29-1). 5대 플레이(약 한 인생의 2.5배 기간)에서 드묾 기준 전쟁을 한 번 이상 볼 확률 약 50%

## 32-6. 부상과 결과

- 부상 종류와 치료는 20장. 큰 흉터와 영구 부상(절름발이, 외눈, 외손)은 외형과 능력에 남음 (20-4)
- 결투/마상시합 승패는 명예와 존중에 반영, 기억과 연대기 삽화
- 사람을 죽이면 업보 하락 (정당한 결투/전쟁은 적게, 살인은 크게) + 범죄 처리 (18-6)
- 사망 설정: 사망 설정 행렬(20-7)의 "전투" 원인을 따름 (현실적 기본: 결투, 전쟁, 괴물, 산적 켬, 주먹다짐은 드물게). 꺼진 경우 기절 + 중상 + 흉터로 대체

## 32-7. 스킬

- **무예**: 자세 판정, 기술 해금 (레벨 3 방패 밀치기, 5 반격, 7 무장 해제, 10 명검술)
- **궁술**: 활/석궁/사냥 (17-1 스킬 `archery`)
- **승마**: 기마 전투, 마상시합
- **체력**: 지구력 (긴 교전에서 우세 유지)
