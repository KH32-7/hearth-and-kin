# 20. 건강, 질병, 부상, 죽음, 사후

기본 수위는 림월드 수준 (00장 "수위와 톤"). 아이의 죽음, 출산 사망, 유산, 굶주림, 처형, 영구 부상이 기본 설정에서 일어남. 심즈식으로 순하게 하려면 사망 프리셋 "관대" (20-7)

## 20-1. 건강

- 인물마다 **건강** 0~100 (숨김 아님, 인물 정보에 표시). 나이, 식사 품질, 위생, 온기, 체력 스킬, 질병 이력, 획득 특성(알코올 의존, 대식가)이 영향
- 건강이 낮으면 질병 감염 확률과 중증화 확률 증가, 노환 위험 증가 (29-2 노환 곡선의 건강 보정)
- **체액설 표시**: 중세 의학식으로 "다혈질/담즙질/흑담즙질/점액질" 체질 기울기를 보여 줌. 실제 효과는 특정 음식/약초의 효과 배수 (예: 점액질이 강하면 따뜻한 음식이 회복 +). 게임적 재미와 분위기용

## 20-2. 질병 12종

| 질병 | 전염 | 증상/효과 | 치료 | 위험 |
| --- | --- | --- | --- | --- |
| 감기 | 접촉, 겨울 + | 재채기 애니메이션, 에너지 감소 1.3배 | 휴식, 따뜻한 수프, 약초차 | 낮음 |
| 오한 | 추위 노출 | 온기 감소 2배, 떨림. 악화하면 "저체온" 상태 | 화롯가, 이불 | 노인/아기 중간 |

| 우울 | 정신 (11장) | 슬픔 지속, 자율 행동 무기력 | 가족 돌봄, 순례, 약초, 신앙 | 중간 (자해와 자살 소재는 다루지 않음) |
| 광기 | 정신, 극단 스트레스 | 이상 행동 자율, 소문 | 수도원 요양 | 중간 |

- **전염 모델**: 감염자와 같은 방/같은 대화/같은 물건 사용 시 확률. 위생, 건강, 계절, 영주 역병 정책이 보정
- **역병 유행**: 마을 단위 사건. 보통 설정에서 한 인생 0.3~0.5회 (`per_life`, 29-1). 곡선 목표는 29-1 (발병률 20~40%, 정점 3~6일, 유행 7~14일). 유행 중에는 장터 폐쇄, 교회 기도 행렬, 약초 가격 폭등, 사망자 증가, 연대기 대형 삽화. 가장 극적인 게임 순간
- **전염병 유행**(인생 목표 "치유사"의 조건): 같은 전염 질병 환자가 마을 인구의 10% 이상인 상태. 역병 외에 감기, 열병, 이질도 해당
- 증상은 애니메이션(기침, 재채기, 떨림)과 무드렛, 속마음으로 보임. 정확한 병명은 치유사 진찰로 알게 됨
- 면역: 한 번 앓고 살아남으면 일부 질병 면역 ("역병 생존자" 특성)

### 상태 5종 (질병이 아님)

질병 12종과 따로 관리하는 몸 상태. `conditions.json`. 전염되지 않음

| 상태 | 원인 | 효과 | 회복 |
| --- | --- | --- | --- |
| 쇠약 | 배고픔 0이 12시간 지속, 중병 회복기 | 에너지 감소 1.5배, 건강 −1/시간, 노동 불가 | 제대로 된 식사 3회 + 휴식 1일 |
| 저체온 | 온기 0이 4시간 지속(노인과 아기는 2시간), 눈보라 외출 | 떨림, 건강 −3/시간, 심하면 무력(기절). 사망 설정 "추위" | 화롯가, 이불, 체온 나누기 |
| 심장 발작 | 긴장 극단(노년) | 즉시 쓰러짐(무력), 건강 −30, 사망 판정("질병" 원인) | 치유사, 휴식 2일 |
| 탈수 | 이질, 열병, 한여름 더위에 마실 것 부족 | 에너지 급감, 건강 −2/시간 | 끓인 물, 휴식 |
| 감염 | 치료하지 않은 부상 (20-4) | 열병 확률, 건강 감소 | 치유사, 상처 소독 |

- 금식(19-4, 21-2)은 "빵과 물만"이라 배고픔이 0이 되지 않으므로 쇠약 판정에서 제외

## 20-3. 치료

- **치유사/의사**(직업, 17장): 진찰(병명 판정), 약초 처방, 사혈, 뼈 맞추기, 상처 꿰매기, 산파(의술 스킬, NPC 역할 산파는 17-2)
- **가정 치료**: 약초학 스킬로 약초차, 찜질, 간호(간호받는 쪽 회복 +, 간호하는 쪽 감염 위험)
- **신앙 치료**: 기도, 성인 유물 참배, 순례. 효과는 작지만 경건 무드렛과 스트레스 감소, 극히 드물게 "기적" 사건
- **미신 치료**: 부적, 마녀(약초꾼) 방문. 효과 무작위, 교회 평판 하락 가능

## 20-4. 부상과 영구 부상

- 원인: 대장간/목공 사고, 낙상(계단, 말), 주먹다짐, 결투, 마상시합, 전쟁, 화재, 동물, 태형
- **부상 4종**: 타박상, 베임, 골절, 화상. 부위 표시 없이 무드렛 + 이동/노동 제한 + 회복 일수 (`lifespan`)
- 치료 안 하면 "감염" 상태 → 열병 확률
- **영구 부상 4종** (`injuries.json`): 큰 부상이 남기는 평생 상태. 외형 레이어와 능력 변화가 함께 붙음

| 영구 부상 | 주 원인 | 효과 | 보조구 (대장장이/목수 제작, 치유사 처방) |
| --- | --- | --- | --- |
| 큰 흉터 | 베임, 화상, 결투 | 외형 흉터 레이어, 첫인상 외모 −(기사와 용감함 특성에게는 존중 +) | 없음 |
| 절름발이 | 치료 안 한 골절, 낙상, 전쟁 | 이동 −30%, 무예 판정 −2, 춤 불가 | 목발/나무 의족: 이동 −15%, 춤 가능(서툶) |
| 외눈 | 결투, 전쟁, 대장간 불똥 | 궁술 −3, 무예 −1, 첫인상 외모 − | 안대: 첫인상 불이익 절반 |
| 외손 | 전쟁, 작업 사고, 절도 처벌 | 공예/무예/궁술/악기 판정 −3, 일부 양손 상호작용 불가 | 갈고리 의수: 판정 −1.5, 양손 상호작용 대부분 가능 |

- 영구 부상은 연대기 캡션과 칭호에 언급 ("외눈의 기사 앨런"), 별명(10-4) 후보
- 사망 설정에서 꺼진 원인은 사망 대신 중상 + 영구 부상 판정으로 대체 (20-7)

## 20-5. 죽음

### 사망 원인 8종

노환(노년 매일 판정, 29-2 노환 곡선), 질병, 굶주림, 추위(저체온), 사고(화재, 익사, 낙상, 작업 사고), 출산(산모 사망, 아기 사망, 유산/사산), 전투(결투, 전쟁, 산적, 괴물, 주먹다짐), 처형(재판 판결)

- 어떤 원인이 켜져 있는지는 **사망 설정 행렬** 하나가 정함 (20-7). 다른 장의 사망 관련 문구는 모두 이 행렬을 가리킴
- 기본 프리셋 "현실적(림월드식)"에서는 전부 켜짐. 아이와 아기도 질병, 사고, 굶주림으로 죽을 수 있음 (목표: 18세 전 사망 출생의 5~12%, 29-1)

### 죽음 연출

- 노환: 침대에서 가족이 모이면 "마지막 말" 상호작용(유언, 축복, 비밀 고백) → 조용히 숨을 거둠. 임종은 차단 장면 (27-7)
- 사고/질병: 쓰러짐 → 가족 반응
- 아이의 죽음, 유산, 사산: 연출은 짧고 담담하게 (작은 관, 빈 요람). 부모 모두 기억(중요도 5)과 애도 무드렛, 연대기 기록
- 죽는 인물이 조작 인물이면 → "마지막 하루" 연출 후 후계자 선택

### 장례

- 사망 → 시신 안치(집) → 장례 미사 → 매장(묘지) → 장례 잔치
- 장례 규모(돈)가 가문 명성과 고인의 업보(아래)에 영향
- 묘비: 새길 문구 선택 (칭호 기반 제안, 직접 입력). 묘비는 묘지에 실제로 남아 방문 가능
- 가족 전원 "애도" 무드렛 (관계 깊이에 비례, 3~7일에 걸쳐 약해짐, `lifespan`)
- 유언 공개(차단 장면) → 상속 (16장). 유언은 사망 시점에 확정됨

## 20-6. 업보와 사후

인조이 카르마를 중세 신앙과 엮은 것. 평판류 수치 전체의 관계는 16-4 표

- **업보**: −100 ~ 100. 덕을 지키는 행동, 선행, 기부, 고해 → +. 죄를 따르는 행동, 범죄, 악행 → −
- 죽을 때 판정

| 업보 | 결과 |
| --- | --- |
| 60 이상 | "평안히 잠들다". 묘지에 성스러운 빛 연출, 가문 명성 +, 가족 애도 기간 짧아짐 |
| −20 ~ 59 | 평범한 죽음 |
| −20 미만 **그리고** 풀지 못한 한 1개 이상 | **유령**이 되어 집이나 묘지에 남음 |

- **풀지 못한 한**: 인생 목표 3단계 이상까지 가고 못 이룸, 남겨진 비밀(유언과 다른 사실), 원수 가문이 아직 번성함. 원한 관계 하나만으로는 한이 되지 않음 (업보 조건과 함께여야 함)
- 인생 목표 보상 "영원한 연인"을 가진 인물은 업보와 상관없이 배우자가 살아 있으면 유령이 될 수 있음 (12-4)
- 조작 가문과 NPC(요약 LOD 포함) 모두 같은 판정. **마을 동시 유령 상한 = 인구의 3%** (120명이면 3). 상한이면 새 사망자는 평범한 죽음 + "떠도는 소문" 무드렛만

### 유령

- 밤, 안개, 망자의 날에 나타남. 반투명 스프라이트 + 차가운 빛
- 유령은 욕구가 없고, 기억과 관계를 유지. 살아있는 가족과 상호작용 가능 (겁주기, 속삭이기, 물건 옮기기, 대화)
- 겁쟁이 특성, 아이, 신앙 높은 인물은 반응이 다름 (공포, 기도, 호기심)
- **법적으로 사망**: 유령은 가장권(혼사, 재산, 유언 변경)과 상속권이 없음. 가문 단절 판정(24-3)의 "살아 있는 구성원"에서 빠짐. 인물 상태 "유령" (13-8)
- **유령 조작**: 원하면 유령을 조작 가능. 조작 인원 8명과 별도인 **유령 슬롯 2개** (27-2 가족 줄 끝). 할 수 있는 것은 제한적 (한을 푸는 데 집중)
- **남겨진 비밀**이 유언과 다르면 상속을 다시 판정하지 않고 "상속 분쟁" 사건 카드로만 영향
- **한 풀기**: 유령이 된 이유(못 이룬 목표, 남겨진 비밀, 원수 가문)를 해결하면 "승천" 연출 → 업보 판정 재평가
- **퇴마/구마**: 사제를 불러 축복 → 강제 승천 (가족 관계 문제 사건 가능)
- 유령 배우자가 있어도 재혼 가능. 재혼하면 유령 배우자 "질투" 사건 (물건 옮기기, 새 배우자에게 겁주기)
- 마을 유령 수가 상한에 닿으면 민심 −, 인구 피드백(18-3) 목표 출생 배수 −10%, "저주받은 마을" 소문 → 교회 대규모 미사 사건

## 20-7. 난이도 설정 (건강/죽음 관련)

| 항목 | 선택지 |
| --- | --- |
| 질병 빈도 | 없음 / 낮음 / 보통 / 현실적 |
| 역병 유행 | 없음 / 드묾 / 보통 |
| 사망 설정 | 프리셋 관대 / 보통 / **현실적(림월드식, 기본)** + 세부 행렬 직접 편집 |

### 사망 설정 행렬

원인 8 × 나이 그룹 3(아이 = 아기~청소년, 성인 = 청년~장년, 노년) × 켬/끔. `death_rules.json`. 새 게임 화면(27-1)과 설정 화면에서 프리셋을 고르고 칸마다 바꿀 수 있음

| --- | --- | --- | --- |
| 노환 | 노년 | 노년 | 노년 |
| 질병 | 끔 | 전 연령 | 전 연령 |
| 굶주림 | 끔 | 노년 | 전 연령 |

| 사고 (화재, 익사, 낙상, 작업) | 끔 | 성인, 노년 | 전 연령 |

### 꺼진 원인의 대체 결과

| 원인 | 꺼져 있을 때 |
| --- | --- |
| 노환 | 노화 끄기(10-2)와 같음. 노년이 끝나지 않음 |
| 질병 | 중환(무력 1~2일) 뒤 회복 + "죽을 고비" 기억 |
| 굶주림 | 쇠약 상태 지속 + 교회 구휼 강제 발동 (17-9) |
| 추위 | 저체온 → 기절 → 누군가 발견해 옮김, 오한 |
| 사고 | 중상 + 영구 부상 판정 (20-4) |
| 출산 | 난산 + 합병증 무드렛 + 회복 기간 2배 |
| 전투 | 기절 + 중상 + 큰 흉터 또는 영구 부상 판정 |
| 처형 | 추방 또는 장기 감옥 (18-6) |

- 29-1의 사망 관련 목표는 기본 프리셋(현실적)에서 측정하고, 다른 프리셋은 해당 목표 열(관대 0% 등)로 측정
