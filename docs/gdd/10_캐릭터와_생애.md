# 10. 캐릭터와 생애

## 10-1. 캐릭터 만들기 (가문 만들기 화면)

새 게임은 "인물 하나"가 아니라 **가문 하나**를 만드는 것에서 시작함 (가문 설정은 `16_가문과_신분.md`)

### 편집 항목

| 분류 | 항목 | 구현 방식 |
| --- | --- | --- |
| 기본 | 이름, 성(가문명), 성별, 생애 단계, 신분 | 이름은 직접 입력 또는 신분/성별별 이름 풀에서 무작위 (이름 풀 신분별 60개 이상) |
| 체형 | 체형 (마름/보통/통통/다부짐), 키 (작음/보통/큼) | 체형별 베이스 스프라이트. 키는 에셋이 지원하면 별도 베이스, 아니면 1~2px 오프셋 |
| 피부 | 피부색 12단계, 주근깨, 흉터, 점 | 팔레트 교체(색 조회표) + 오버레이 레이어 |
| 얼굴 | 눈 모양, 눈 색, 눈썹, 수염(성인 남성), 볼 홍조 | 부위 레이어 + 팔레트 교체 |
| 머리 | 헤어스타일, 머리색 (자연색 10 + 백발/회색), 두건/모자와의 조합 | 레이어. 모자를 쓰면 머리 레이어를 잘라내는 마스크 규칙 |
| 옷 | 복장 6벌 (평상복, 작업복, 예복, 잠옷, 겨울옷, 속옷/목욕) | 복장마다 상의/하의/신발/겉옷/장신구 레이어, 색 2~3개 지정 |
| 소리 | 목소리 높낮이, 웅얼거림 유형 3종 | 대화 효과음(알아들을 수 없는 웅얼거림)의 피치와 샘플 세트 |
| 움직임 | 걸음걸이 (느긋/당당/종종/살금) | 걷기 애니메이션 재생 속도와 이동 속도 배수 |
| 내면 | 특성, 덕과 죄, 인생 목표, 좋아하는 것/싫어하는 것 | `12_성격과_목표.md` |

- **색 지정**: 캐릭터 만들기에서 옷은 신분별 허용 염료 팔레트(16-2 사치 금지법 표)에서 고름. 귀족만 자주색, 진홍색 같은 비싼 염료. 게임 중 구매, 염색, 선물, 상속으로 얻는 옷은 소유가 합법이고 공공 장소 착용만 판정함 (16-2)
- **무작위 버튼**: 부위별 무작위, 전체 무작위, "이 가족 닮게" (가족 구성원의 유전자로 생성)
- **가족 한 번에 만들기**: 가정 하나에 최대 8명 (조작 가능 인원 상한. 가정 인원 상한 12명은 하인 포함, 15-8). 관계 지정 (부모, 자녀, 형제, 배우자, 조부모, 사촌, 하인)
- **저장/불러오기**: 인물과 가문을 파일로 저장, 갤러리에 올리기 (26장)
- **미리보기**: 인물이 대기/걷기/앉기/감정 표현을 순환 재생. 배경은 신분에 맞는 방

### 복장 자동 전환

| 상황 | 복장 |
| --- | --- |
| 기상, 일상 | 평상복 |
| 직업 활동, 가내 작업 | 작업복 |
| 교회, 혼례, 장례, 축제, 성 방문 | 예복 |
| 잠 | 잠옷 |
| 기온 5도 이하 외출 | 겨울옷 |
| 목욕, 강에서 수영 | 속옷 |

옷장이나 궤짝에서 "갈아입기"로 직접 바꿀 수 있음. 장례에 평상복으로 가면 "무례함" 소문

## 10-2. 생애 단계 7개

기본은 **보통 수명**. 수명 설정은 짧음(×0.5), 보통(×1), 김(×2), 아주 김(×4). 단계 일수는 `lifespan` 태그 (29-0): 수명 배수를 곱함. 보통 수명 한 인생 = 3+7+13+13+24+24+노년 평균 20 = 104일

| 단계 | 표시 나이 | 보통 수명 일수 | 할 수 있는 것 | 특성 칸 |
| --- | --- | --- | --- | --- |
| 아기 | 0~1세 | 3일 | 없음. 안기고, 먹여지고, 기저귀 갈아짐, 요람에서 잠. 울음으로 욕구 표현 | 기질 1 (순함, 까다로움, 잘 웃음, 겁 많음) |
| 유아 | 1~4세 | 7일 | 걷기(배우기 전엔 기어다님), 말하기, 배변 훈련, 장난감, 부모 따라다니기 | 기질 1 (유지) |
| 아동 | 4~11세 | 13일 | 심부름, 놀이, 수도원 학교 또는 집안일 돕기, 친구 사귀기, 아동 스킬 | 특성 1 |
| 청소년 | 12~17세 | 13일 | 도제 입문, 구애 시작, 16세부터 혼인과 임신 가능(15-1), 반항, 첫 직업, 성인 스킬 | 특성 2 |
| 청년 | 18~29세 | 24일 | 모든 것. 혼인, 출산, 전업 | 특성 3 |
| 장년 | 30~54세 | 24일 | 모든 것. 임신 확률 감소 시작 (여성 40세 이후, 45세까지 가임) | 특성 3 |
| 노년 | 55세~ | 사망 시점 가변 (평균 약 20일, 노환 위험 곡선 29-2) | 느린 걸음, 에너지 감소 빠름, 지혜 관련 상호작용, 은퇴 | 특성 3 + 노년 특성 1 (지혜로움, 고집불통, 망령 등 확률 부여) |

- **표시 나이** = 단계 시작 나이 + (단계 진행 일수 / 단계 전체 일수) × 단계 연수. 노년은 끝이 없으므로 55 + 노년 진행 일수 × 0.6 ÷ 수명 배수 (노년 표시 속도 상수 0.6년/일, 평균 20일 → 약 67세). 달력 연도와 함께 표시
- 표시 나이는 연출용. 규칙의 기간 조건(혼인 기간, 도제 기간 등)은 `lifespan` 일수로 판정 (29-0)
- **생일(명명 축일)**: 단계가 바뀌는 날 아침. 가족이 "축하하기" 상호작용 가능, 잔치를 열면 기분과 관계 보너스. 원하면 하루 미루기 가능 (최대 3일)
- **단계 전환 연출**: 연기 대신 종이 넘기는 효과 + 새 모습. 전환 때 무작위 특성 추가 규칙은 12장
- **노화 끄기**: 설정에서 가문 전체 또는 인물별로 노화 정지 가능 (심즈와 동일한 편의)

### 생애 단계별 외형

- 아기: 요람/품에 안긴 전용 스프라이트
- 유아, 아동, 청소년, 성인, 노년 베이스가 모두 있어야 함. 에셋이 부족한 단계는 `28_아트와_오디오.md`의 보완 규칙을 따름 (예: 노년은 성인 베이스 + 굽은 자세 오프셋 + 흰머리 + 지팡이)
- 임신한 인물은 임신 단계별 배 레이어 (15장)

## 10-3. 유전

### 유전 대상과 방식

| 대상 | 방식 |
| --- | --- |
| 피부색 | 부모 두 값 사이에서 무작위 + 작은 변이(±1단계) |
| 머리색 | 부모 각각 대립 유전자 2개. 짙은 색 우성. 자식은 부모 각각에서 하나씩 받음 → 조부모 머리색이 다시 나올 수 있음 |
| 눈 색 | 머리색과 같은 방식 (갈색 > 초록 > 파랑 > 회색) |
| 눈 모양, 눈썹, 체형, 키 | 부위마다 한쪽 부모 것을 50:50 선택, 10% 확률로 무작위 변이 |
| 헤어스타일 | 유전 안 함. 생애 단계별 기본값에서 무작위 |
| 기질/특성 | 청소년이 될 때 특성 칸 하나는 30% 확률로 부모 특성 중 하나를 물려받음 |
| 선천 특성 | "튼튼한 체질", "허약 체질", "왼손잡이", "쌍둥이 체질", "마녀의 피"(33-1) 등 9종 (12-1). 부모에게 있으면 25% 확률로 유전 |

- 모든 인물은 유전자 레코드를 저장 (표현형과 따로). 그래서 몇 대 뒤 격세유전이 일어남
- **가문 닮음 지표**: 연대기 표지에 "가문의 얼굴"로 가장 자주 나온 외형 조합을 표시

## 10-4. 이름

- 신분별, 성별별 이름 풀. 예: 농민 "톰, 앨리스, 윌", 귀족 "에드먼드, 이졸데, 기욤"
- 성은 가문명. 농노는 성이 없고 "애쉬포드의 톰"처럼 출신지로 불리다가 자유민이 되면 가문명을 얻음 (16장 신분 상승 연출의 일부)
- 별명: 사건으로 붙는 별명 ("대장장이 톰", "용감한 앨리스", "술고래 윌"). 연대기와 NPC 대화에 사용
- 세례명: 세례 때 수호성인 선택 → 해당 성인 축일에 소원 보너스 (21장)
