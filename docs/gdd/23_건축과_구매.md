# 23. 건축 모드와 구매 모드

심즈의 절반은 집 짓기. 2D 탑다운 3/4 시점에서 심즈 수준의 자유도를 목표로 함

## 23-1. 부지

- 부지 크기: 소(12×10), 중(20×16), 대(28×22), 저택(40×30) 타일
- 부지 구입: 빈 부지 구매 / 기존 집 구매 / 임대(계절세: 계절마다 임대료, `season`). 집값은 17-4 역산표 기준 (작은 집 1금화)
- 부지 경계 안에서만 건축. 부지 밖 공공 도로에 문 연결 필요
- **신분 규칙**: 저택 부지는 상인 이상. 농노는 영주가 준 오두막 부지만 (해방 후 이사 가능)

## 23-2. 건축 도구

| 도구 | 내용 |
| --- | --- |
| 벽 | 끌어서 그리기, 방 도구(사각형 방 한 번에), 대각선 벽 없음(2D 제약). 재질: 흙벽, 나무판, 반목조(하프팀버), 돌, 다듬은 돌. 재질마다 단열값이 달라 방 기온을 정함 (11-1) |
| 벽 칠/벽지 | 회칠, 태피스트리 걸기(장식 물건), 돌 노출 |
| 바닥 | 흙, 짚 깔기, 나무 마루, 돌판, 타일. 칠하기, 채우기(방 전체) |
| 문 | 나무문 5종, 아치문, 대문(마구간/창고용), 잠금 설정(가족만/모두/신분 이상) |
| 창문 | 덧문 창, 격자창, 유리창(비쌈, 귀족/상인), 스테인드글라스(교회) |
| 지붕 | 자동 지붕(벽 윤곽 따라 생성) + 수동 조정. 재질: 초가, 나무 널, 슬레이트, 기와. 초가는 화재 위험, 슬레이트는 비싸고 안전 |
| 층 | **2층까지** (저택/성은 3층). 계단 배치 → 위층 바닥 생성. 층 전환 버튼 (심즈처럼 아래층은 흐리게, 위층 편집) |
| 기초와 지하 | 지하 저장고(음식 부패 속도 절반) |
| 굴뚝과 화로 | 화로는 벽 붙이기 물건 + 굴뚝 자동 생성. 굴뚝 없으면 연기 무드렛 |
| 울타리/담 | 나무 울타리, 돌담, 산울타리, 대문 |
| 지형 | 지형 칠하기(흙, 풀, 자갈, 진흙, 꽃밭), 나무/덤불 심기, 우물 파기(비쌈), 연못 |
| 방 인식 | 벽으로 닫힌 공간을 자동 방으로 인식 → 방 이름 지정(부엌, 침실…) → 방 점수 계산 (11장) |

### 시점 처리 (2D에서 심즈 느낌을 내는 핵심)

- **벽 보기 모드**: 벽 올림 / 벽 잘라내기(앞쪽 벽을 낮게) / 벽 내림. 심즈의 벽 모드와 같음. 기본은 인물이 있는 방 앞 벽만 자동으로 낮춤
- **지붕**: 실외 카메라일 때 지붕 보임. 인물이 집 안에 들어가거나 카메라가 가까우면 지붕이 서서히 투명해짐
- **층**: 현재 층만 선명, 다른 층 인물은 실루엣

## 23-3. 건축 비용과 시간

- 모든 건축 요소에 가격 (재료비). 재질별 가격 차이가 신분 차이로 이어짐
- **옵션: 공사 시간**. 설정이 켜져 있으면 건축 모드에서 배치한 것은 "공사 예정"이 되고, 목수/석공 NPC(NPC 역할 직업, 17-2) 또는 목공/석공 스킬 있는 가족이 며칠에 걸쳐 실제로 지음. 공사 중 저장은 공사 진행도를 함께 저장 (30-3). 꺼져 있으면 심즈처럼 즉시 완성 (기본: 즉시)
- 가족이 직접 지으면 인건비 절약 + 목공 스킬 경험치

## 23-4. 구매 모드 (가구와 물건)

- 분류: 침실, 부엌/살림, 식당, 거실, 욕실/위생, 작업장(직업별), 장식, 조명, 아이/아기, 동물, 야외, 종교
- 목표 수량: **구매 가능 물건 300종 이상** (색/재질 변형 포함 시 600 이상). 목록은 30장
- 물건 속성: 가격, 품질(초라함/보통/좋음/훌륭함/걸작), 방 점수 값, 욕구 광고값, 신분 요구, 상태(내구도)
- **회전**: 에셋이 가진 방향만 (대부분 2~4방향). 방향 없는 물건은 좌우 반전 허용 여부를 데이터로 지정
- **색/재질 변형**: 팔레트 교체로 나무색 4종, 천 색 8종
- **겹치기 규칙**: 탁자 위 소품(촛대, 그릇), 벽 걸이(태피스트리, 선반, 방패), 바닥 러그 밑
- **내구도와 고장**: 쓰면 닳음 → 고장(삐걱거리는 침대, 새는 지붕, 막힌 굴뚝) → 수리(목공/손재주) 또는 교체. 가보는 고장 대신 "손상" 상태 (16-5)
- **직접 만든 가구**: 목공 스킬로 만든 가구는 제작자 이름과 품질이 붙은 고유 물건 → 가보 후보
- **되팔기**: 구매가 × 상태 비율 × 0.6. 걸작/가보는 경매 사건 (가보 판매 규칙은 16-5)

## 23-5. 청결과 집 상태

- 더러움: 먼지, 설거지 쌓임, 음식 찌꺼기, 쥐(역병!), 거미줄, 동물 배설물
- 청소 상호작용: 쓸기, 닦기, 설거지(물통), 쥐덫, 짚 갈기
- 화재: 화로 방치, 초가지붕 + 번개, 촛불 넘어짐. 불은 퍼지고, 물통/흙으로 끄기, 이웃이 도우러 옴. 래빗홀/여정 중인 가족에게 조기 귀가 카드 (13-9). 가보는 타 없어지지 않고 "손상" (16-5). 화상과 화재 사망은 사망 설정 행렬 "사고" (20-7). 연대기 삽화
- 집 상태가 방 점수와 질병 확률에 반영

## 23-6. 미리 만든 집

- 신분별 기본 집 20채 이상. **집 등급** 6단계: 오두막 < 농가/작은 집 < 장인 공방 겸 집 < 상인 저택 < 기사 장원 < 영주 성의 거주동. 인생 목표 "부의 축적" 4단계의 "한 등급 위의 집"이 이 순서 (12-4)
- 플레이어가 지은 집은 저장/공유 (26장 갤러리)
