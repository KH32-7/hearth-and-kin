# 31. 농사

중세 생활의 중심이라 제대로 넣음. 다만 **심즈식**으로: 인물을 직접 조종해 타일마다 괭이질하고 물 주는 실시간 농장 루프(스타듀밸리식)가 아니라, **밭 구획이라는 물건에 상호작용을 거는 방식**. 인물은 가서 일하고, 시간이 흐르고, 작물이 자람

## 31-1. 밭의 종류

| 밭 | 위치 | 누가 | 방식 |
| --- | --- | --- | --- |
| 텃밭 | 집 부지 안 | 누구나 | 텃밭 상자/밭 한 뙈기 물건 (크기 1~4칸, 물건은 하나). 채소, 허브, 약초 |
| 가문 몫의 밭 | 마을 공동 경지의 **띠 모양 구획** (마을 지도 위에 실제로 있음) | 자유민, 농노 | 구획 하나 = 물건 하나. 가문이 가진 구획 수만큼 |
| 과수원/포도밭 | 부지 또는 공동 경지 | 자유민 이상 | 나무 물건. 가을마다 수확 (달력 1년 1회) |
| 영주 직영지 | 공동 경지 | 농노 부역, 품팔이 | 래빗홀형 노동 (17장 "영주 밭 농부") |

- **물건 1개 = 상호작용 1세트**: 밭 구획과 텃밭은 크기와 상관없이 물건 하나이고, 상호작용도 물건 단위 한 세트. 칸마다 괭이질하거나 칸마다 씨를 뿌리는 **칸 단위 상호작용은 만들지 않음**
- 구획 크기: 소/중/대. 크기에 따라 작업 시간과 수확량이 달라짐
- 구획은 사고팔고 임대하고 상속할 수 있음 (가문 재산, 16장)

## 31-2. 작업 (상호작용)

구획을 클릭하면 원형 메뉴. 작업마다 인물이 가서 작업 애니메이션을 하며 게임 시간이 흐름 (심즈의 텃밭 가꾸기와 같은 방식)

| 작업 | 시기 | 시간 (중 구획) | 효과 |
| --- | --- | --- | --- |
| 갈기 | 파종 전 | 3시간 (소/말 쟁기 1시간) | 파종 가능 상태 |
| 씨 뿌리기 | 봄/가을 | 1시간 | 작물 선택 (씨앗 재고 필요) |
| 김매기 | 자라는 동안 | 1시간 | 잡초 상태 해소, 품질 + |
| 물 대기 | 가뭄 사건 때만 | 1시간 | 가뭄 피해 방지. **매일 물 주기 없음**. 맑은 날에도 물을 줄 필요가 없음 |
| 거름 주기 | 파종 전후 | 1시간 | 지력 + (가축 거름 재고) |
| 허수아비 세우기 | 한 번 | 30분 | 까마귀 피해 - |
| 수확 | 익으면 | 3시간 (여럿이 하면 빨라짐) | 수확물 → 저장고 (재고) |
| 이삭줍기 | 수확 후 | 1시간 | 가난한 가족의 권리, 소량 곡식 |

- **일 맡기기**: "오늘의 밭일"을 가족, 하인, 품팔이에게 배정하면 자율로 처리. 아이에게 맡기면 느리지만 농사 스킬 경험치
- **함께 일하기**: 수확철에 이웃이 도우러 오면 속도 + 관계 +. 가문 몫 수확 잔치
- 밭에 간 인물은 화면 밖이어도 간이 세밀도로 진행 (13-6)
- **채집**(약초, 버섯, 장작, 야생 열매)도 같은 원칙: 숲의 장소 물건(약초 덤불, 버섯 자리, 쓰러진 나무)에 거는 상호작용이고, 물건마다 **하루 재생 상한**(예: 약초 덤불 하루 3회분)이 있어 반복 노동 루프가 되지 않음
- 가축 돌봄은 우리 물건 1회 상호작용이 전체 개체를 처리 (22-3)

## 31-3. 작물

| 작물 | 파종 | 수확 | 용도 |
| --- | --- | --- | --- |
| 밀 | 가을 | 여름 | 밀가루 → 빵 (방앗간) |
| 보리 | 봄 | 여름 끝 | 에일, 죽 |
| 귀리 | 봄 | 여름 끝 | 죽, 말 먹이 |
| 호밀 | 가을 | 여름 | 거친 빵 |
| 콩/완두 | 봄 | 여름 | 스튜, 지력 회복 |
| 아마 | 봄 | 여름 | 리넨 실 → 옷 |
| 순무, 양배추, 양파, 리크 | 봄/여름 | 여름/가을 | 채소 (텃밭 가능) |
| 허브 (파슬리, 세이지, 타임) | 봄 | 여름 | 요리 품질 +, 약 |
| 약초 (카모마일, 쐐기풀, 쑥) | 봄 | 여름/가을 | 치료, 약초학 |
| 월광초 | 하지 밤 | 가을 | 마법 재료 (33장, 드묾) |
| 포도 | 나무 | 가을 | 포도주 |
| 사과, 배 | 나무 | 가을 | 과일, 사과주 |

## 31-4. 성장과 품질

- 성장 단계 5 (싹 → 어린 줄기 → 성장 → 이삭/열매 → 익음). 스프라이트로 구획 모습이 바뀜
- 성장은 **계절 진행률 + 날씨**로 진행 (`season` 태그, 29-0). 작물마다 "필요 성장 계절 수"(예: 밀 2.5계절, 순무 0.8계절)를 가지므로 계절 길이 설정이 바뀌어도 달력상 파종/수확 시기는 같음. 겨울에는 대부분 멈춤
- 수확량은 계절 길이에 비례 (기본량 × 계절 일수 / 7). 계절이 길어져도 하루당 식량 생산과 소비의 비율이 같게 유지됨
- 수확량/품질 = 기본값 × 지력 × 관리도(김매기, 거름) × 날씨 × 농사 스킬 × 재해
- **지력과 윤작 (삼포제)**: 구획마다 지력 0~100. 같은 곡물을 연달아 심으면 지력 감소. 곡물 → 콩 → 휴경 순환을 지키면 회복. 마을 공동 경지는 마을 전체가 삼포제를 따르고, 어기면 이웃과 마찰 사건

## 31-5. 재해와 사건

- 까마귀, 들쥐, 고블린(33장, 드묾)이 곡식을 훔침
- 병충해, 곰팡이 (습한 여름)
- 가뭄 (물 대기 필요), 우박, 홍수(강가 구획)
- 흉년: 마을 전체 수확 감소 → 장부 재고 감소로 식량 가격 폭등(17-8) → 굶주림 사건 → 구휼과 영주 곡물 배급 탄원 (17-9)
- 풍년: 가격 하락, 추수 잔치 규모 +

## 31-6. 경제 연결

- 수확물은 저장고 재고 (17장). 팔거나, 방앗간에서 빻거나, 양조하거나, 가축 먹이로
- **현물 납부**: 십일조와 영주 지대 일부를 수확물로 낼 수 있음 (가을 세금일)
- 방앗간 사용료 (빻은 밀가루의 일부)
- 씨앗은 수확물에서 남기거나 장터에서 구입. 좋은 씨앗은 품질 +

## 31-7. 스킬

- **농사** 스킬 (`farming`, 17-1 살림 분류. 텃밭과 밭 모두 이 스킬 하나): 레벨별로 작물 해금, 작업 속도, 품질, 재해 예측 속마음("구름이 심상치 않은데… 우박이 올지도")
