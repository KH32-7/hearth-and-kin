# 15. 가족, 임신, 출산, 육아

## 15-1. 임신

- 계기: 연인/배우자 "동침" 상호작용 (침대, 연출은 이불 속 암시까지. 00장 "수위와 톤"). 임신 확률은 동침 1회당 기본 18% (29-2) × 나이, 건강, 계절(일부 미신 반영: 봄 +), 선천 특성, "아이를 원한다" 소원 여부. 판정은 생애 판정기가 하루 1회 (18-3)
- 부부가 아이를 원하는지 설정 가능 (원함 / 상관없음 / 원치 않음 → 확률 크게 감소)
- **혼인한 청소년(16~17세)도 임신 가능**. 혼인 가능 나이는 16세 이상 (14-4). 가임 나이는 16~45세, 40세부터 확률 감소 (10-2)
- **임신 3단계** (보통 수명 기준 게임 3일, 단계당 1일, `lifespan`)

| 단계 | 외형 | 효과 | 상호작용 |
| --- | --- | --- | --- |
| 초기 | 변화 없음 | 입덧 (아침에 방광/배고픔 급변, 속 울렁임 무드렛), 임신 사실은 산파나 증상으로 알게 됨 | 산파 찾아가기, 가족에게 알리기 |
| 중기 | 배 레이어 1 | 에너지 감소 1.2배, 이상한 음식 당김(무작위 음식 소원) | 배 쓰다듬기(배우자), 아기 옷 짓기, 요람 만들기 |
| 후기 | 배 레이어 2 | 이동 속도 −30%, 노동 불가, 편안함 감소 2배 | 산파 예약, 출산 준비(깨끗한 천, 물 끓이기) |

- 쌍둥이 확률: 기본 3%, 쌍둥이 체질 +10%

### 임신 위험 판정

- 위험 요인이 생길 때마다 판정: 굶주림(배고픔 10 미만 또는 쇠약), 역병/열병/이질 감염, 큰 충격(가족 사망 목격, 폭행, 화재), 낙상, 과로(후기 노동, 부역), 나이(35세 이상 가중, 16세 미만 없음)
- 판정 결과 (사망 설정 행렬 "출산" 칸이 켜져 있을 때. 기본 켬)

| 결과 | 내용 |
| --- | --- |
| 합병증 | "불안한 태동" 무드렛(긴장 2), 난산 확률 + |
| 조산 | 남은 임신 단계를 건너뛰고 바로 진통. 아기는 허약 체질 확률 + |
| 유산 (초기, 중기) / 사산 (후기) | 임신 종료. 부모 모두 "잃어버린 아이" 기억(중요도 5)과 슬픔 무드렛(3 → 2 → 1, `lifespan` 5일), 연대기 기록, "상처 입은 영혼" 획득 확률 (11-6 트라우마 규칙) |

- 출산 칸이 꺼져 있으면(관대) 위험 판정은 합병증까지만
- 목표: 현실적 기본에서 유산/사산이 임신의 6~12% (29-1)

### 임신 상태 교차 표

| 겹치는 상황 | 규칙 |
| --- | --- |
| 산모가 임신 중 사망 | 후기면 "기적의 출산" 판정(치유사/산파가 있으면 50%, 없으면 20%)으로 아기 생존 가능, 실패하면 함께 사망. 초기/중기면 태아도 사망. 출산 칸이 꺼져 있으면 항상 기적의 출산 |
| 농노 부역일 | 후기는 부역 면제 (영주 호의 소폭 하락). 초기/중기는 부역하되 과로 위험 판정 |
| 역병 격리/도시 봉쇄 중 진통 | 산파 호출 가능 (추가 비용 2배 + 산파와 산모 감염 판정). 산파가 오지 않으면 "가족이 받기"로 진행 |
| 배우자가 전쟁 소집/여정 중 | 진통 시 조기 귀가 카드 (13-9). 귀환하지 못하면 배우자에게 "출산 소식" 편지 |
| 출생으로 가정 인원 상한 초과 | 출생과 쌍둥이는 항상 허용. 초과 상태가 되면 분가 또는 하인 해고 알림 (15-8) |
| 산모가 이미 장면 중(재판 등) | 진통이 생기면 그 장면을 중단하고 출산 장면이 먼저 (27-7 우선순위) |
| 난산 회복 | 2일 (`lifespan`). 아기 단계(3일)보다 짧음 |

## 15-2. 출산

- 진통 사건 → 선택: 산파 부르기(돈) / 가족이 받기 / 혼자
- **출산 장면**: 집 침대에서 짧은 연출 (문 닫힘, 가족이 문 앞에서 서성임, 아기 울음). 차단 장면 (27-7)
- 결과 판정: 받는 사람의 의술 스킬(산파는 의술, 17-1), 위생, 산모 건강, 준비물, 합병증 여부, 사망 설정 행렬
  - 순산 / 난산(산모 회복 2일, 에너지 제한) / 위험(산모 또는 아기 사망 가능)
  - 기본 설정(현실적)에서 산모 사망과 아기 사망이 일어날 수 있음. 산파, 깨끗한 천, 끓인 물, 산모 건강이 위험을 크게 줄임. 관대 프리셋에서는 위험이 난산으로 대체됨 (20-7)
- 이름 짓기 → 세례 예약 (21장). 세례를 미루면 신앙 높은 가족이 긴장
- 연대기 삽화 자동 기록

## 15-3. 아기 (0~1세)

- 아기는 스스로 움직이지 않음. 요람, 부모 품, 바닥 깔개에만 있음
- **아기 욕구**: 배고픔, 에너지, 위생(기저귀), 교류, 온기. 30 아래로 떨어지면 울음 (집 안 전원 "시끄러움" 분노 1, 수면 방해)
- **상호작용**: 젖 먹이기 / 유모 부르기(귀족, 돈), 죽 먹이기(후반), 기저귀 갈기, 안아서 달래기, 자장가 부르기, 요람 흔들기, 까꿍, 이야기 들려주기, 세례 데려가기
- **방치하면**: 욕구 0이 이어지면 질병(오한, 이질, 열병)과 저체온, 쇠약 위험이 커지고, 사망 설정 행렬의 아이 칸이 켜져 있으면(기본) 죽을 수 있음. 그 전에 **친척/교회 개입 사건**이 대안 결과로 끼어들 수 있음 (조부모가 데려감, 수녀원이 맡음). 어느 쪽이든 부모 명예와 교회 평판 크게 하락, 부모에게 중요도 5 부정 기억
- 유모, 하녀 고용(16장 하인) 가능 → 자율 돌봄

## 15-4. 유아 (1~4세)

- **유아 기술 5개**: 걷기, 말하기, 배변, 사고(장난감 놀이), 소통(몸짓). 각 5레벨. 부모가 가르치는 상호작용과 스스로 놀기로 오름
  - 걷기 전: 기어다님 (이동 속도 느림)
  - 말하기 3 이상: 부모를 부르는 말풍선, 간단한 요구 표현
  - 배변 훈련 완료 전: 기저귀
- 행동: 장난감(나무 말, 헝겊 인형, 블록), 부모 따라다니기, 떼쓰기, 숨바꼭질, 동물 쓰다듬기
- 위험: 화로, 우물, 계단 근처에 혼자 두면 사고 확률. 사망 설정 행렬의 "사고" 아이 칸을 따름 (기본 켬: 화상, 익사, 낙상 사망 가능. 꺼져 있으면 부상과 영구 부상까지)
- 유아기의 돌봄 질(유아 기술 평균, 부모와 관계)이 아동 특성 선택지에 영향

## 15-5. 아동 (4~11세)

- **교육 경로 선택** (가장이 결정, 아이가 싫어할 수 있음)

| 경로 | 대상 신분 | 내용 | 결과 |
| --- | --- | --- | --- |
| 집안일 돕기 | 농노, 자유민 | 집에서 부모 일 돕기 (가내 생산, 동물 돌보기) | `labor` 묶음 스킬, 가족 관계 +, 문맹 |
| 교구 학교 | 자유민 이상 | 래빗홀 (오전), 사제에게 읽기와 셈 | 읽기/셈 스킬, 교회 평판 + |
| 수도원 학교 | 누구나 (기부금) | 기숙 (주중 집에 없음 = 다일 래빗홀, 13-8) | 읽기, 라틴어, 신앙. 성직 경로 유리 |
| 가정교사 | 상인, 귀족 | 집에서 수업 (NPC 역할 가정교사 방문, 17-2) | 읽기, 아동 스킬 예절, 음악, 무예(남아 기사 경로) |
| 시동(page) 보내기 | 기사, 귀족 | 다른 귀족 집에서 수련 (집에 없음 = 다일 래빗홀) | 아동 스킬 예절, 무예, 인맥 |

- 숙제/과제: 학교 경로면 "과제" 상호작용. 성적 A~F → 청소년 도제/직업 선택지와 목표 보너스
- 아동 스킬 4개: 상상력, 몸놀림, 사교성, 예절. 성인 스킬로 전환 보너스 (예절 → 이야기(화술), 17-1)
- 놀이: 술래잡기, 나무 칼싸움, 인형 놀이, 공차기, 개울 물수제비. 아이들끼리 친구 관계
- 아동 목표 4개 (12장)

## 15-6. 청소년 (12~17세)

- **도제 계약**: 직업 경로의 시작 (17장). 장인 집에 들어가 살거나(떠남) 매일 다님. 도제 10일(`lifespan`) 동안 스킬 빠르게 성장, 급여 없음
- 첫 구애, 첫 입맞춤, 첫 실연. 부모의 반대. 16세부터 혼인과 임신 가능 (15-1)
- **반항**: 스트레스와 부모 관계가 나쁘면 "몰래 여관 가기", "밤에 몰래 나가기", "가출" 자율 행동
- 성인 스킬 해금, 인생 목표 선택
- 부모와의 관계가 성인기 특성 선택지와 "가문에 대한 애정" 수치(상속 분쟁 확률)에 영향

## 15-7. 입양, 양자, 후견

- 교회 고아원/수도원에서 입양 (명예 +, 교회 평판 +)
- 친척 고아 맡기 (사건)
- 대부모: 세례 때 지정. 부모가 죽으면 대부모가 후견인
- 귀족의 양자 들이기: 후계자가 없을 때 계승용
- 입양과 고아 맡기는 가정 인원 상한(15-8)을 넘으면 불가 안내 (분가나 하인 해고 뒤 가능)

## 15-8. 가문과 가정, 가족 구성

- **용어**: 가문(성씨 단위) ⊃ 가정(집 단위). 한 가문은 분가로 여러 가정을 가짐. 인원 상한은 가정 단위
- 한 **가정** 최대 **12명** (하인, 도제, 유모 포함). 그중 조작 가능한 가족 구성원 최대 **8명**. 유령은 별도 슬롯 2개 (20-6)
- **초과 처리**

| 들어오는 경우 | 상한을 넘으면 |
| --- | --- |
| 출생, 쌍둥이 | 항상 허용 (일시 초과). 초과 상태 동안 "집이 비좁다" 무드렛 + 분가/하인 해고 알림 |
| 혼인으로 들어오는 배우자 | 불가 안내. 분가해서 새 가정으로 받거나 거주지 협상(14-4)을 바꿈 |
| 입양, 친척 고아 맡기 | 불가 안내 |
| 하인 고용 | 불가 안내 |
| 조작 가능 8명 초과 (출생 등) | 초과 인원은 가정에 살지만 조작 불가(자율), 분가하거나 자리가 나면 조작 가능 |

- 여러 세대 동거: 조부모, 부모, 자녀, 결혼한 자녀 부부 등
- **분가**: 성인 자녀가 독립해 새 집으로 → 같은 가문의 다른 가정. 조작 대상을 바꿀 수 있음 (가문 단위 플레이). 분가한 가정은 분가 시점의 신분을 유지 (16-2)
- 하인, 도제, 유모는 가족 구성원은 아니지만 집에서 생활하는 인물 (자율 행동, 급여)
