# 가문 연대기 (가제, 영문 Hearth & Kin) 개요

> [!summary] 한 줄 요약
> 중세 왕국의 한 마을에서, 한 가문의 사람들이 태어나 먹고 자고 사랑하고 일하고 늙어 죽는 모든 순간을 심즈처럼 직접 살아가며, 대를 이어 신분을 끌어올리고 그 이야기를 채색 필사본 연대기로 남기는 2D 생활 시뮬레이션

- 장르: 인생/가족 시뮬레이션 (심즈 계열). 농사, 전투, 마법이 있지만 초점은 사람과 가족. 실시간 농장 게임, 액션 RPG가 아님
- 플랫폼: PC (웹 기술로 만들고 데스크톱 앱으로 패키징, 스팀 출시 기준) + 브라우저 빌드
- 언어: 한국어 (문자열 분리, 이후 다국어 확장 가능하게)
- 시점: 2D 탑다운 3/4 픽셀아트
- 레퍼런스: 심즈 2·3·4, 심즈 미디벌, 인조이, BitLife, 크루세이더 킹즈 3 (`01_레퍼런스_분석.md`)

---

## 1. 이 게임이 심즈와 다른 이유

심즈에서 이미 해 본 것(현대 직장, 요리, TV, 연애)을 배경만 바꿔 반복하면 의미가 없음. 중세라는 배경이 **게임 규칙 자체를 바꾸는 곳**에 집중함

| 심즈에서의 경험 | 이 게임에서 바뀌는 것 |
| --- | --- |
| 돈만 있으면 누구와도 결혼, 어디든 입장 | **신분제**. 농노, 자유민, 장인, 상인, 성직자, 기사, 귀족. 신분이 입는 옷, 들어갈 수 있는 곳, 결혼 상대, 대화 방식, 처벌을 정함 |
| 개인의 인생 | **가문**. 성(姓), 문장, 가훈, 가보, 가문 명성, 상속법, 가문 간 동맹과 원한. 주인공이 죽어도 게임은 가문으로 이어짐 |
| 냉장고를 열면 음식이 무한 | **살림**. 식료품 저장고의 재고, 상하는 음식, 겨울 대비 저장, 땔감, 빵 굽기, 맥주 빚기, 실잣기, 옷 짓기. 집이 생산 단위 |
| 난방은 자동 | **온기 욕구**. 화로, 땔감, 옷의 두께, 계절. 겨울이 무서움 |
| 병은 가벼운 이벤트 | **질병과 의학**. 마을에 번지는 역병, 체액설 의학, 약초, 산파. 출산에도 위험이 따름 (난이도 설정으로 완화) |
| 평판은 거의 없음 | **소문과 명예**. 마을 사람들 사이로 소문이 퍼지고, 불륜, 사생아, 이단 의혹이 가문 명예를 깎음 |
| 종교 없음 | **신앙과 미신**. 세례, 혼례, 장례 같은 성사, 십일조, 고해, 축일, 징조. 악행이 쌓이면 죽은 뒤 유령이 되어 집에 남음 |
| 무한한 현재 | **연대기**. 중요한 순간이 필사본 삽화로 기록되고, 가문 대대로 한 권의 책이 됨 |

**심즈 미디벌(2011)과의 차이**: 그 게임은 영웅 캐릭터가 퀘스트를 수행하는 왕국 경영형이었고 샌드박스 생활은 약했음. 이 게임은 퀘스트가 아니라 **샌드박스 생활과 세대**가 중심

**농사와 전투는 넣되, 심즈 방식으로**: 중세에서 농사와 싸움은 빠질 수 없음. 다만 스타듀밸리처럼 인물을 직접 움직여 타일마다 괭이질하는 실시간 농장 조작이나, 액션 게임식 전투 조작은 하지 않음. 농사는 밭 구획 물건에 상호작용을 거는 방식(31장), 전투는 인물의 스킬과 장비로 판정하고 플레이어는 전술을 고르는 방식(32장). 초점은 끝까지 **사람과 가족**

**마법과 괴물은 아주 약하게**: 드물고 작고 대가가 있는 마법, 전설처럼 가끔 나타나는 괴물과 요정 (33장). 하이판타지로 가지 않음

### 수위와 톤 (림월드 수준, 17세 이용가)

심즈식 검열을 하지 않는 것이 이 게임의 차별점. 가혹한 일이 실제로 일어나고, 연대기는 그것을 담담하게, 가끔 건조한 블랙 유머를 섞어 기록함 (24-2)

- **등급 목표: 17세 이용가 (M/Mature)**. 피, 부상, 죽음의 묘사와 성적 암시, 농담, 불륜 묘사는 허용. 노골적인 성행위 묘사와 성기 노출만 제외 (19금 성적 콘텐츠 없음. 동침 연출은 이불 속 암시까지)
- **기본 게임에 들어가는 것**: 유산, 사산, 난산으로 인한 산모 사망, 영아/아이 사망(질병, 사고, 굶주림), 영구 부상과 장애(흉터, 절름발이, 한쪽 눈이나 손을 잃음 + 목발/의족, 안대, 갈고리 의수 같은 중세 보조구), 중독(알코올 의존), 정신 붕괴(스트레스 무너짐, 광기), 결투/전쟁 사망, 처형(재판 판결), 굶주림, 농노제
- **다루지 않는 것**: 자살과 자해, 고문, 노예, 마녀 화형(마녀 재판 결과는 추방, 벌금, 공개 참회), 실존 종교/인물 비방
- 기본 사망 프리셋은 "현실적(림월드식)"으로 위 죽음이 전부 켜져 있음. 심즈처럼 순하게 하고 싶은 플레이어를 위해 "관대" 프리셋 제공 (20-7)
- **수위 설정**: 전연령 / 15세 / 17세 (기본 17세). 사건 카드 풀, 연대기 문장 표현, AI 출력, 피 효과에 적용 (27-5). 게임 규칙(사망 설정)은 따로 정함

## 3. 핵심 루프

**순간 루프 (5~30초)**: 인물 상태 확인 → 원형 메뉴로 행동 지시 → 인물이 이동해 수행 → 욕구/무드렛/스킬 변화 → 속마음 말풍선으로 반응

**하루 루프 (게임 하루 = 실제 약 24분, 2배속 8분, 3배속 약 2.4분)**: 새벽 종소리에 기상 → 씻고 먹고 → 일터(래빗홀 또는 집 작업장)나 학교 → 저녁 가족/이웃과 교류 → 소원 달성 → 잠. 하루 끝에 연대기 한 줄

**계절 루프 (게임 약 1~4주)**: 계절 축제, 세금과 십일조, 겨울 식량과 땔감 대비, 계절 병, 계절 옷

**생애 루프**: 아기 → 유아 → 아동 → 청소년 → 청년 → 장년 → 노년. 교육/도제 → 직업과 결혼 → 자녀와 상속 → 죽음과 장례 → 후계자로 이어 하기

**가문 루프 (여러 세대)**: 시작 신분 선택 → 가문 명성과 재산 축적 → 상승/유지 경로 선택 (길드, 교회, 기사, 혼인, 작위 매입, 영지 경영) → 가문 간 동맹/원한 → 연대기 완성

## 4. 시간 흐름 (심즈와 같음)

- 게임 1분 = 실제 1초 (1배속). 속도: 일시정지 / 1배 / 2배(3분/초) / 3배(10분/초)
- 가족 전원이 자거나 일터/학교(래빗홀)나 여정에 있으면 자동 가속 (심즈의 잠 건너뛰기)
- 속도가 겹칠 때 우선순위: 일시정지(사건 카드 같은 차단 장면) > 1배 강제(화면 안 전투) > 사용자 속도 > 자동 가속 (`gdd/27_UI_UX.md` 27-7 장면 스택)
- 나이는 **생애 단계별 일수**로 흐름. 수명 설정: 짧음 / 보통 / 김 / 아주 김. 가문 전체나 인물별 노화 끄기 가능
- 계절 길이 설정: 7 / 14 / 28일. 1주 = 7일
- 한 해를 건너뛰는 기능은 없음. 보통 수명 기준 한 인생은 약 104게임일 (3+7+13+13+24+24+노년 평균 20, 기본 달력으로 약 3.7년)
- 모든 기간 수치는 스케일 태그(게임일 고정 / 계절 비례 / 수명 비례 / 한 인생당 횟수)를 가짐. 수명과 계절 설정을 바꿔도 밸런스가 ±20% 안에서 유지되게 함 (`gdd/29_밸런스_수치표.md` 29-0)
- 이야기는 하루 중 벌어지는 사건 카드와 연대기로 쌓임 (`gdd/24_연대기와_사건.md`)
