# 에셋 목록: Epic RPG World 세계 + LPC 사람

> [!summary] 한 줄 요약
> **세계**(마을, 건물, 집 내부, 지형, 괴물 일부)는 사용자가 이미 가진 **Epic RPG World Collection** (32px), 여기에 없는 것(작물, 가축, 계절, 일부 내부)은 **LPC**로 채움. **사람**(신분 7단계, 임산부, 아이, 노인)은 **LPC 캐릭터 생성기**. 둘 다 32px 격자라 **같은 2배 배율**로 바로 섞임. 그래픽 추가 비용 0원

> [!note] 생성형 AI 이미지 (2026-09-25 사용자 허용)
> 연대기/사건 카드 삽화, 초상화, UI 장식, 아이콘, 부족한 스프라이트 초안에 생성형 AI를 씀 (GDD 28-5). 만든 파일은 `assets/AI_GENERATED.md`에 기록. Epic RPG World와 LPC는 AI와 함께 쓰는 것을 막지 않음

- Mana Seed는 **보류** (`04M_ManaSeed_보류.md`). Epic RPG World로 부족하다고 판단될 때만 다시 검토
- 2026-09-25에 스토어/라이선스 페이지를 열어 확인함. **파일을 받아 열어 본 건 아님**
- 받는 방법: **itch.io**는 `Buy Now` 후 `Download`, **GitHub**는 `Code` → `Download ZIP`, **OpenGameArt**는 페이지 아래 `File(s)` 목록

### 크기

| 항목 | Epic RPG World | LPC |
| --- | --- | --- |
| 타일 | 32×32 | 32×32 |
| 화면 배율 | **2배** | **2배** |

- 같은 격자, 같은 배율이라 크기 문제 없음. 캐릭터 키는 타일 약 1.5칸
- **화풍 차이 확인 필요**: Epic RPG World는 채도와 대비가 높은 액션 RPG풍, LPC는 조금 차분한 색. M0에서 LPC 사람을 Epic RPG World 마을/집 안에 세운 스크린샷으로 확인하고, 튀면 **LPC 사람 쪽 팔레트를 Epic RPG World 쪽으로 맞추는 색 보정**(색 조회표)을 적용
- LPC 세계 에셋(작물, 가축 등)을 섞을 때도 같은 색 보정으로 Epic RPG World 톤에 맞춤

### Epic RPG World 파일 꺼내기 (유니티 없이 또는 유니티로)

사용자는 **유니티 에셋 스토어**에서 샀으므로 `.unitypackage` 형식으로 받게 됨

1. 방법 A (유니티 사용): Unity Hub → 아무 빈 2D 프로젝트 → `Window > Package Manager > My Assets` → Epic RPG World Collection `Download` → `Import` → 프로젝트의 `Assets/` 아래 PNG와 Tiled 파일을 `assets/vendor/epic-rpg-world/`로 복사
2. 방법 B (유니티 없이): 한 번 받아 둔 `.unitypackage` 파일(Windows 기본 위치 `%AppData%\Unity\Asset Store-5.x\RafaelMatos\`)은 tar.gz 압축 파일. 압축을 풀면 폴더마다 `pathname`(원래 경로)과 `asset`(파일 본체)이 있어서, 스크립트로 원래 이름의 PNG로 복원 가능 (에이전트에게 맡기면 됨)
3. 같은 제작자의 itch.io 판([Complete Collection](https://rafaelmatos.itch.io/epic-rpg-world-collection))은 PNG/Tiled로 바로 받을 수 있지만, 유니티에서 산 것과는 별개 구매이므로 다시 살 필요는 없음

### 라이선스

| 항목 | 내용 |
| --- | --- |
| 유니티 에셋 스토어 | 표준 에셋 스토어 EULA(Single Entity). 제한(Restricted) 에셋이 아니면 **유니티가 아닌 엔진에서도 사용 가능**. 조건: 에셋만 따로 재배포하지 않고 게임 안에 넣어서 쓸 것 ([EULA FAQ](https://assetstore.unity.com/browse/eula-faq), [해설](https://gamefromscratch.com/using-asset-store-assets-in-other-engines-is-it-legal/)) |
| 제작자(RafaelMatos) 조건 | 개인/상업 사용 가능, **AI 학습 금지**, 재포장/재배포/재판매 금지(수정본 포함), NFT 금지, 표기 불필요(권장) |

| 레포 | 원본 PNG는 공개 레포에 올리지 않음 (`assets/vendor/`는 .gitignore) |
