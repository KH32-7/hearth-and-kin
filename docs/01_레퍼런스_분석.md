# 레퍼런스 분석

> [!info] 확인 범위
> - 게임 사실관계는 2026-09-25에 위키백과, 공식 페이지, 리뷰로 확인. 심즈 미디벌 세부(직업, 노화, 욕구)는 공식 자료가 아니라 서로 일치하는 팬 위키/가이드 기준
> - 우리 게임의 수치는 원작 수치가 아니라 새로 정한 값

---

## 1. 생활 시뮬레이션 계열

### 1-1. 심즈 2 (2004)

- 욕구 8개 (배고픔, 편안함, 화장실, 에너지, 즐거움, 교류, 위생, 공간)
- **열망 + 소원/두려움**: 성향에 맞는 소원 4칸과 두려움 3칸. 이루면 열망 게이지 상승, 바닥나면 무너짐
- **기억**: 첫 키스, 승진, 가족의 죽음이 기억으로 쌓이고 이후 소원과 대화에 반영
- **세대와 유전**: 생애 단계별 노화, 외형 유전, 몇 대에 걸친 가문 플레이
- 잘한 점: 성격과 이야기에 묶인 소원, 기억 덕분에 플레이가 이야기로 남음
- 약점: 수동 관리 부담, 로딩

### 1-2. 심즈 3 (2009)

- **오픈 월드** + 이웃의 **스토리 진행** (알아서 취업, 연애, 이사)
- **특성 5개**가 자율 행동과 전용 상호작용을 만듦
- **무드렛**: 기분의 원인을 하나하나 보여 줌
- 평생 소원 + 약속한 소원 → 평생 행복 포인트 → 보상 특성
- 래빗홀 (직장, 학교, 상점)
- 잘한 점: 특성 조합의 창발, 기분 원인이 보임
- 약점: 성능

### 1-3. 심즈 4 (2014)

- **감정**: 가장 강한 무드렛 쪽이 감정이 되고, 감정이 전용 상호작용과 스킬 보너스를 엶
- 멀티태스킹, 특성 3개 + 열망 단계, 소원/두려움 부활(2022), 호불호, 방 단위 건축, 조형식 CAS, 갤러리
- 잘한 점: 감정 → 상호작용 → 스킬의 연결, 매끄러운 UI
- 약점: 너무 쉬운 행복, 비슷비슷한 심들

### 1-4. 인조이 (Krafton, 2025년 3월 28일 얼리 액세스)

- 언리얼 엔진 5 사실적 비주얼, 세밀한 캐릭터 스튜디오. 첫 주 100만 장 이상 판매
- 도시: 도원(서울), 블리스 베이(산타모니카), 이후 쿠찡쿠(발리)
- **카르마**: 죽을 때 판정. 카르마가 낮으면 유령이 되고, 유령이 너무 많으면 새 출생과 새 가족이 막힘
- **스마트 조이**: RTX GPU에서 도는 소형 언어 모델(NVIDIA ACE)이 속마음을 만들고 텍스트 지시를 받음 (선택 기능)
- **도시 관리**: 외관(날씨, 청결 등)과 안정도(건강 수준, 질병 확률, 범죄율, 카르마 빈도) 설정
- 약점: "보기엔 좋은데 관계와 상호작용이 얕다", "먹고 자고 일하는 반복"이라는 평 (GameSpot "Pretty Vacant")

### 1-5. BitLife (2018)

- "나이 +1" 버튼으로 1년씩. 행복/건강/지능/외모 + 숨겨진 카르마
- 매년 무작위 사건과 선택지. 죽으면 리본(칭호). 자녀로 이어 하기
- 잘한 점: 한 인생이 한 판. 반복 동기
- 약점: 캐릭터가 안 보임, 사건 반복

## 2. 중세 계열

### 2-1. 심즈 미디벌 (2011) ★ 가장 가까운 선례

- 영웅 심 10종(군주, 기사, 마법사, 음유시인, 대장장이, 상인, 의사, 첩자, 사제 2종)에게 **퀘스트**를 주고, 왕국 야망을 달성하는 구조. 매일 할 일(책임) 2개
- 기분 대신 **집중도(Focus)**, 욕구는 **배고픔과 에너지 2개뿐**
- 특성 + 치명적 결점 1 + 전설적 특성 1
- **노화 거의 없음**: 아기만 자라고, 아이는 부모 영웅이 죽어 역할을 물려받을 때만 성인이 됨
- **건축 불가**: 실내 꾸미기만 되고 건물 구조는 못 바꿈
- 평: PC 메타크리틱 77. "퀘스트 위주라 샌드박스 자유가 없다", "남의 모험담을 듣는 느낌"(GameSpot)

**우리에게 주는 교훈**: 중세 심즈를 퀘스트 게임으로 만들면 심즈 팬이 원하는 것(자유 건축, 세대, 일상)을 잃음. 우리는 정반대로 **샌드박스 일상 + 자유 건축 + 세대**를 중심에 두고, 중세다움은 신분, 살림, 신앙, 질병 같은 **규칙**으로 표현함

### 2-2. 크루세이더 킹즈 3 (2020)

- 인물이 죽으면 후계자로 이어 하는 **가문(왕조)** 플레이
- 성격/교육/유전 특성. **성격에 반하는 행동을 하면 스트레스**가 쌓이고 한계에서 정신적으로 무너짐
- 생활 방식 6종, 음모(친교, 유혹, 암살 등), 혼인 동맹
- 확장: 마상시합과 대혼례(Tours & Tournaments), 땅 없는 모험가로 사는 Roads to Power
- 가져올 것: 가문 단위 플레이, 스트레스, 혼인 동맹, 유전 특성, 명성
- 차이: CK3는 지도 위 전략. 우리는 집 안의 하루

### 2-3. 노를란드 (Norland, 2024년 7월 얼리 액세스)

- "크루세이더 킹즈 + 림월드". 귀족 가문의 특성, 연애, 질투, 암살, 계승 위기. 스팀 평가 매우 긍정적(82%)
- **가장 가까운 경쟁작이지만 콜로니 시뮬**. 인물을 직접 조작하지 않고 명령을 내림. 가문은 귀족으로 고정
- 차이: 우리는 인물을 직접 조작하는 심즈식, 신분 사다리를 오르는 평민 가문 이야기

### 2-4. 그 밖에

| 게임 | 무엇 | 우리와의 관계 |
| --- | --- | --- |
| 메디블 다이너스티 (2021) | 1인칭 생존 + 마을 건설 + 결혼/후계 | 생존/농사 중심. 가문은 부가 요소 |
| 고잉 메디블 (2026 정식) | 림월드식 콜로니 | 가족 생활 아님 |
| 킹덤 컴: 딜리버런스 2 (2025) | 사실적 1인 RPG | 가족 생활 아님 |
| 오스트리우 | 18세기 마을 도시 건설 | 가족을 마을 규모로만 시뮬 |
| 라이프 이즈 퓨달 | 하드코어 생존 샌드박스 | 가족 생활 아님 |
| 스타듀밸리류 | 실시간 농장 조작, 채집, 관계 | 농사는 넣되 **실시간 타일 조작 방식은 피함**. 우리는 밭 구획에 상호작용을 거는 심즈식 (31장) |

- 조사 범위에서 **2D 중세 가족 생활 시뮬(심즈식 직접 조작)** 으로 이름난 게임은 찾지 못함. 빈자리로 보임 (전수 조사는 아님)

## 4. 가져올 것

| 원작 | 가져올 것 |
| --- | --- |
| 심즈 2 | 소원/두려움, 기억, 세대와 유전, 공간 욕구(방 점수) |
| 심즈 3 | 오픈 월드, 스토리 진행, 특성이 만드는 자율 행동, 무드렛, 보상 특성, 래빗홀 |
| 심즈 4 | 감정 → 상호작용/스킬, 원형 메뉴, 멀티태스킹, 호불호, 방 단위 건축, 갤러리, 현장형 직업 |
| 심즈 미디벌 | 직업별 하루 과제(일터 목록), 중세 직업 구성 |
| 인조이 | 속마음, 카르마와 유령, 마을 전체 설정(정책), 언어 모델 활용 |
| BitLife | 1년 단위 사건 카드, 칭호, 자녀로 이어 하기 |
| CK3 | 가문 단위 플레이, 스트레스, 혼인 동맹, 명성, 상속법 |

## 5. 반드시 피할 것

- 심즈 미디벌처럼 **퀘스트가 일상을 대체**하는 구조
- 심즈 4처럼 **너무 쉬운 행복** (부정 무드렛은 원인을 해결해야 사라짐)
- 인조이 초기처럼 **보이는 것에 비해 얕은 상호작용** (상호작용 430개 이상, 사회 80개 이상 목표)
- 스타듀밸리처럼 **실시간 농장 조작 루프**가 게임의 중심이 되는 것 (농사와 전투는 있지만 초점은 사람과 가족)
- 마법과 괴물이 하이판타지로 커지는 것
- 노를란드처럼 **인물을 명령 단위로만 다루는 것**
